# 用户角色清单

| 角色中文名 | 角色标识 | 核心定位 |
|---|---|---|
| 访客 | Guest | 未登录的公开访问者，仅可浏览公开页面（定价、排行榜、关于）与完成注册、登录、密码重置、OAuth 登录。 |
| 普通用户 | User | 系统的主要终端使用者。管理自己的 API 令牌、查看个人用量与日志、充值与订阅、试用 Playground，并通过令牌调用 AI API。 |
| 管理员 | Admin | 运营与运维人员。继承普通用户全部能力，额外管理用户、渠道、模型、定价、兑换码、订阅计划与全局日志统计。 |
| 超级管理员 | Root | 系统负责人。继承管理员全部能力，独占系统级配置（站点、支付、OAuth 提供商）、性能与多节点运维、上游费率同步，以及渠道密钥查看等最高敏感操作。 |
