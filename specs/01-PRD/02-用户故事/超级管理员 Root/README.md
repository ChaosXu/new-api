# 超级管理员（Root）用户故事

> 角色定义：系统负责人。继承管理员全部能力，独占系统级配置（站点、支付、OAuth 提供商）、性能与多节点运维、上游费率同步，以及渠道密钥查看等最高敏感操作。通过 `RootAuth()` 鉴权（role ≥ 100）。

共 12 个用户故事，按用例分组组织。每个故事遵循 Mike Cohn 用例格式 + Gherkin 验收标准。

## 鉴权与安全说明

- **`RootAuth()`**：仅超级管理员（role=100）可访问。
- **渠道密钥查看**：独占最高敏感操作，4 重保护（RootAuth + CriticalRateLimit + DisableCache + SecureVerificationRequired），需 2FA/Passkey 二次验证。
- **支付合规确认**：不可用 API access token，必须 Dashboard 会话。
- **管理员权限任免**：提升用户为管理员（promote）和授予细粒度 RBAC 权限仅超管可用。
- 所有 Root 写操作自动留审计日志（仅记键名不记值，防密钥泄漏）。

## RootAuth 端点统计

共 7 个路由组 + 独立端点，约 33 个 HTTP 端点：
- 系统配置 `/api/option/*`（11 个端点）
- 自定义 OAuth `/api/custom-oauth-provider/*`（6 个）
- 性能运维 `/api/performance/*`（6 个）
- 倍率同步 `/api/ratio_sync/*`（2 个）
- 系统任务 `/api/system-task/*`（4 个）
- 系统实例 `/api/system-info/*`（3 个）
- 渠道密钥 `POST /api/channel/:id/key`（1 个）
- 管理员任免/权限授予逻辑内嵌于 AdminAuth 端点（`/api/user/`、`/api/user/manage`）
