# 使用用户名密码注册账号

## 摘要

让访客通过用户名和密码创建新账号，开始使用站点的 AI API 服务。

## 用例：
- **作为** 访客
- **我想要** 使用用户名和密码（可选邮箱验证）注册一个新账号
- **以便** 我能登录站点、管理令牌并调用 AI API

## 验收标准：

### 场景：访客使用用户名密码注册（无邮箱验证）
- **假设：** 站点已开启注册（`RegisterEnabled`）和密码注册（`PasswordRegisterEnabled`）
- **而且假设：** 站点未启用邮箱验证（`EmailVerificationEnabled=false`）
- **当：** 访客提交 `POST /api/user/register`（`controller/user.go` `Register`）提供合法用户名和密码
- **则：** 系统创建新用户（普通用户角色、启用状态），注册成功

### 场景：注册关闭被拒绝
- **假设：** 站点关闭了注册（`RegisterEnabled=false`）或密码注册（`PasswordRegisterEnabled=false`）
- **当：** 访客提交注册请求
- **则：** 请求被拒绝并提示注册已禁用（`MsgUserRegisterDisabled` / `MsgUserPasswordRegisterDisabled`）

### 场景：启用邮箱验证时未提供验证码被拒绝
- **假设：** 站点启用了邮箱验证（`EmailVerificationEnabled=true`）
- **当：** 访客未提供邮箱或验证码即提交注册
- **则：** 请求被拒绝并提示需要邮箱验证（`MsgUserEmailVerificationRequired`）

### 场景：验证码错误被拒绝
- **假设：** 站点启用了邮箱验证
- **当：** 访客提供了错误的验证码
- **则：** 请求被拒绝并提示验证码错误（`MsgUserVerificationCodeError`）
