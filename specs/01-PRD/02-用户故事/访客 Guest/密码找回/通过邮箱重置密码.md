# 通过邮箱找回并重置密码

## 摘要

让忘记密码的访客通过邮箱接收重置链接并重置密码，重新获得账号访问权。

## 用例：
- **作为** 访客
- **我想要** 通过注册邮箱找回并重置密码
- **以便** 我在忘记密码时能重新登录账号，而不必放弃该账号

## 验收标准：

### 场景：访客请求发送密码重置邮件
- **假设：** 访客提供了格式合法的邮箱地址
- **而且假设：** 若启用了 Turnstile 人机验证，访客已通过验证
- **当：** 访客请求 `GET /api/reset_password?email=<邮箱>`（`controller/misc.go` `SendPasswordResetEmail`）
- **则：** 无论邮箱是否存在账号，系统均返回成功（防止邮箱枚举）；若邮箱存在账号，则向其发送含重置链接的邮件（有效期由 `VerificationValidMinutes` 控制）

### 场景：访客通过重置链接重置密码
- **假设：** 访客从邮件中获得了有效的重置 token
- **当：** 访客提交 `POST /api/user/reset`（`controller/misc.go` `ResetPassword`）携带邮箱和 token
- **则：** 系统验证 token 有效后为该账号生成一个随机新密码并返回，同时删除该 token 使其失效，访客可用新密码登录

### 场景：重置链接无效或已过期
- **假设：** 访客提交的 token 不正确、已过期或已被使用
- **当：** 访客提交重置请求
- **则：** 请求被拒绝并提示重置链接无效（`MsgUserPasswordResetLinkInvalid`），密码不变
