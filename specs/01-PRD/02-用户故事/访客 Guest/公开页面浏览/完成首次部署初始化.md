# 完成首次部署初始化

## 摘要

让首次部署站点的访客创建超级管理员账号完成初始化，使站点进入可用状态。

## 用例：
- **作为** 访客
- **我想要** 在站点首次部署时创建超级管理员（Root）账号完成初始化
- **以便** 我能接管站点并开始配置和管理系统

## 验收标准：

### 场景：访客查询初始化状态
- **假设：** 站点刚部署，尚未初始化
- **当：** 访客请求 `GET /api/setup`（`controller/setup.go` `GetSetup`）
- **则：** 返回站点是否已完成初始化的状态，前端据此判断是否展示初始化引导

### 场景：访客执行首次初始化
- **假设：** 站点尚未初始化（`constant.Setup == false`）
- **当：** 访客提交 `POST /api/setup`（`controller/setup.go` `PostSetup`）提供 Root 账号信息
- **则：** 系统创建超级管理员账号并标记站点为已初始化，访客（现 Root）可使用该账号登录管理系统

### 场景：已初始化后再次尝试被拒绝
- **假设：** 站点已完成初始化（`constant.Setup == true`）
- **当：** 访客提交初始化请求
- **则：** 请求被拒绝，无法重复初始化或创建额外 Root
