# 访客（Guest）用户故事

> 角色定义：未登录的公开访问者，仅可浏览公开页面（定价、排行榜、关于）与完成注册、登录、密码重置、OAuth 登录。

共 16 个用户故事，按用例分组组织。每个故事遵循 Mike Cohn 用例格式 + Gherkin 验收标准。
