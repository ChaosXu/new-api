# 使用微信扫码登录

## 摘要

让访客通过微信扫码登录或注册站点，为微信用户提供原生便捷的接入方式。

## 用例：
- **作为** 访客
- **我想要** 使用微信扫码登录或注册站点
- **以便** 我能以惯用的微信身份快速接入，无需另建账号

## 验收标准：

### 场景：访客使用微信扫码登录
- **假设：** 站点已启用微信登录（`WeChatAuthEnabled`）
- **而且假设：** 访客已在微信中扫码授权并被重定向回带 `code` 与有效 `state` 的回调
- **当：** 访客访问 `GET /api/oauth/wechat`（`controller/wechat.go` `WeChatAuth`）
- **则：** 系统校验 state、用 code 换取微信用户信息，找到或创建用户后创建登录会话，返回访问令牌，登录成功（method=wechat）
