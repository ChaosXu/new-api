# 管理兑换码

## 摘要

让管理员批量生成和管理兑换码，用于向用户发放额度。

## 用例：
- **作为** 管理员
- **我想要** 批量生成兑换码，并查看、搜索、更新、删除兑换码
- **以便** 我能向用户发放额度兑换码（如活动赠送、代理商分销），并管理兑换码生命周期

## 验收标准：

### 场景：管理员批量生成兑换码
- **假设：** 管理员已登录（AdminAuth），且平台已完成支付合规确认（`IsPaymentComplianceConfirmed`）
- **当：** 管理员提交 `POST /api/redemption/`（`AddRedemption`）提供名称（1-20 字符）、数量（1-100）、额度与过期时间
- **则：** 系统生成对应数量的兑换码（UUID key），返回成功

### 场景：未完成支付合规被拒绝
- **假设：** 平台尚未由超管确认支付合规
- **当：** 管理员尝试生成兑换码
- **则：** 请求被拒绝（需超管先确认支付合规）

### 场景：管理员查看与搜索兑换码
- **假设：** 管理员已登录
- **当：** 管理员请求 `GET /api/redemption/`（`GetAllRedemptions`）或 `GET /api/redemption/search`（`SearchRedemptions`，按 keyword+status）
- **则：** 分页/搜索返回兑换码列表

### 场景：管理员更新兑换码
- **假设：** 管理员已登录
- **当：** 管理员提交 `PUT /api/redemption/`（`UpdateRedemption`，支持 `?status_only=` 仅改状态）
- **则：** 系统更新兑换码信息

### 场景：管理员删除兑换码
- **假设：** 管理员已登录
- **当：** 管理员提交 `DELETE /api/redemption/:id`（`DeleteRedemption`）或 `DELETE /api/redemption/invalid`（`DeleteInvalidRedemption` 批量清理无效码）
- **则：** 系统删除指定或无效兑换码
