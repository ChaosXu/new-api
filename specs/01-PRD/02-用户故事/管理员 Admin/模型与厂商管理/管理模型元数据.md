# 管理模型元数据

## 摘要

让管理员管理平台模型元数据（CRUD、同步上游、发现缺失模型），维护准确的模型目录与定价。

## 用例：
- **作为** 管理员
- **我想要** 创建、编辑、删除模型元数据，发现缺失模型并从上游同步
- **以便** 我能维护准确的模型目录与计费信息，确保用户能看到正确的可用模型与价格

## 验收标准：

### 场景：管理员查看与搜索模型
- **假设：** 管理员已登录（AdminAuth）
- **当：** 管理员请求 `GET /api/models/`（`GetAllModelsMeta`）或 `GET /api/models/search`（`SearchModelsMeta`）
- **则：** 分页/搜索返回模型元数据（含供应商、绑定渠道、分组、计费类型等）

### 场景：管理员创建模型
- **假设：** 管理员已登录
- **当：** 管理员提交 `POST /api/models/`（`CreateModelMeta`）
- **则：** 系统校验模型名称唯一后创建，并刷新定价表（`RefreshPricing`）

### 场景：管理员更新模型
- **假设：** 管理员已登录
- **当：** 管理员提交 `PUT /api/models/`（`UpdateModelMeta`，支持 `?status_only=true` 仅改状态）
- **则：** 系统校验名称唯一后更新，并刷新定价表

### 场景：管理员删除模型
- **假设：** 管理员已登录
- **当：** 管理员提交 `DELETE /api/models/:id`（`DeleteModelMeta`）
- **则：** 系统删除模型并刷新定价表

### 场景：管理员发现缺失模型
- **假设：** 渠道引用了某些模型但元数据中未配置
- **当：** 管理员请求 `GET /api/models/missing`（`GetMissingModels`）
- **则：** 返回渠道引用但元数据缺失的模型列表，提示管理员补全

### 场景：管理员从上游同步模型
- **假设：** 管理员已登录
- **当：** 管理员先请求 `GET /api/models/sync_upstream/preview`（`SyncUpstreamPreview`）预览，再提交 `POST /api/models/sync_upstream`（`SyncUpstreamModels`）执行
- **则：** 系统从上游元数据源拉取模型，按 locale（en/zh-CN/zh-TW/ja）创建/更新/跳过模型
