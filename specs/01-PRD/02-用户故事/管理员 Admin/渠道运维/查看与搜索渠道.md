# 查看与搜索渠道

## 摘要

让管理员浏览和搜索全部上游渠道，掌握渠道配置与运行状态。

## 用例：
- **作为** 管理员
- **我想要** 分页查看全部渠道、搜索渠道并查看渠道详情与变更历史
- **以便** 我能了解渠道配置全貌、定位特定渠道并追踪渠道变更

## 验收标准：

### 场景：管理员查看渠道列表
- **假设：** 管理员已登录（AdminAuth + ChannelRead 权限）
- **当：** 管理员请求 `GET /api/channel/`（`controller/channel.go` `GetAllChannels`）
- **则：** 分页返回渠道列表（密钥脱敏）

### 场景：管理员搜索渠道
- **假设：** 管理员已登录
- **当：** 管理员请求 `GET /api/channel/search`（`SearchChannels`），支持按标签聚合
- **则：** 返回匹配的渠道

### 场景：管理员查看渠道详情
- **假设：** 管理员已登录
- **当：** 管理员请求 `GET /api/channel/:id`（`GetChannel`）
- **则：** 返回该渠道的详细配置（不含完整密钥）

### 场景：管理员查看渠道变更操作记录
- **假设：** 管理员已登录
- **当：** 管理员请求 `GET /api/channel/ops`（`GetChannelOps`）
- **则：** 返回渠道变更操作历史

### 场景：管理员查看渠道可用模型
- **假设：** 管理员已登录
- **当：** 管理员请求 `GET /api/channel/models` 或 `/models_enabled`
- **则：** 返回渠道支持的模型列表
