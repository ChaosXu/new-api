# 查看全平台数据与流量趋势

## 摘要

让管理员查看全平台额度消耗与流量趋势，支撑运营分析。

## 用例：
- **作为** 管理员
- **我想要** 查看全平台额度消耗趋势、按用户聚合的额度以及流量数据
- **以便** 我能分析平台整体用量、识别高消耗用户并做容量规划

## 验收标准：

### 场景：管理员查看全平台额度日期数据
- **假设：** 管理员已登录（AdminAuth）
- **当：** 管理员请求 `GET /api/data/`（`controller/usedata.go` `GetAllQuotaDates`）
- **则：** 返回按日期聚合的全平台额度消耗数据（按用户名）

### 场景：管理员按用户聚合查看额度
- **假设：** 管理员已登录
- **当：** 管理员请求 `GET /api/data/users`（`GetQuotaDatesByUser`）
- **则：** 返回按用户维度聚合的额度数据

### 场景：管理员查看全平台流量趋势
- **假设：** 管理员已登录
- **当：** 管理员请求 `GET /api/data/flow`（`GetAllFlowQuotaDates`）并提供合法的 start_timestamp/end_timestamp（end≥start）
- **则：** 返回按日期聚合的流量数据（按角色过滤）

### 场景：流量统计时间参数不合法被拒绝
- **假设：** 管理员未提供时间参数，或 end < start
- **当：** 管理员请求流量数据
- **则：** 请求被拒绝并提示参数错误
