# 管理充值订单与人工补单

## 摘要

让管理员查看全平台充值订单并在支付回调失败时人工补单，保障用户充值到账。

## 用例：
- **作为** 管理员
- **我想要** 查看全平台充值订单并在支付已成功但回调失败时人工完成补单
- **以便** 我能核对充值流水并为用户解决充值未到账问题

## 验收标准：

### 场景：管理员查看全平台充值订单
- **假设：** 管理员已登录（AdminAuth）
- **当：** 管理员请求 `GET /api/user/topup`（`controller/topup.go` `GetAllTopUps`）
- **则：** 分页返回全平台充值订单（支持 keyword 搜索）

### 场景：管理员人工补单
- **假设：** 管理员已登录
- **当：** 管理员提交 `POST /api/user/topup/complete`（`AdminCompleteTopUp`）提供 trade_no
- **则：** 系统按订单号（`LockOrder`）加互斥锁防并发，调用 `ManualCompleteTopUp` 为该订单充值，记录审计日志
