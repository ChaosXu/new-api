# 查看全局日志与统计

## 摘要

让管理员查看全平台调用日志与统计、异步任务，掌握平台运营全貌。

## 用例：
- **作为** 管理员
- **我想要** 按多维度查看全平台日志、统计消费数据，以及 Midjourney 和异步任务
- **以便** 我能监控平台运行状况、排查问题用户和核对全局账目

## 验收标准：

### 场景：管理员查看全平台日志
- **假设：** 管理员已登录（AdminAuth）
- **当：** 管理员请求 `GET /api/log/`（`controller/log.go` `GetAllLogs`）
- **则：** 分页返回全平台日志，支持按类型、时间、用户名、令牌名、模型、渠道、分组、requestId、upstreamRequestId 过滤

### 场景：管理员查看全平台日志统计
- **假设：** 管理员已登录
- **当：** 管理员请求 `GET /api/log/stat`（`GetLogsStat`）
- **则：** 返回指定区间的额度消费、RPM、TPM 汇总

### 场景：管理员查看全平台 Midjourney 与异步任务
- **假设：** 管理员已登录
- **当：** 管理员请求 `GET /api/mj/`（`GetAllMidjourney`）或 `GET /api/task/`（`GetAllTask`）
- **则：** 返回全平台 Midjourney 任务或异步任务列表
