# 管理分组与预填分组

## 摘要

让管理员查看分组列表并管理预填分组，控制用户可用的计费分组。

## 用例：
- **作为** 管理员
- **我想要** 查看分组列表并创建、编辑、删除预填分组
- **以便** 我能为用户分组配置提供可选分组，管理用户分组分配的预设

## 验收标准：

### 场景：管理员查看分组列表
- **假设：** 管理员已登录（AdminAuth）
- **当：** 管理员请求 `GET /api/group/`（`controller/group.go` `GetGroups`）
- **则：** 返回所有倍率分组名列表（用于下拉选择）

### 场景：管理员查看预填分组
- **假设：** 管理员已登录
- **当：** 管理员请求 `GET /api/prefill_group/`（`controller/prefill_group.go` `GetPrefillGroups`，可按 `?type=` 过滤）
- **则：** 返回预填分组列表

### 场景：管理员创建预填分组
- **假设：** 管理员已登录
- **当：** 管理员提交 `POST /api/prefill_group/`（`CreatePrefillGroup`）
- **则：** 系统校验名称+类型非空且名称唯一后创建

### 场景：管理员更新预填分组
- **假设：** 管理员已登录
- **当：** 管理员提交 `PUT /api/prefill_group/`（`UpdatePrefillGroup`）
- **则：** 系统校验名称唯一后更新

### 场景：管理员删除预填分组
- **假设：** 管理员已登录
- **当：** 管理员提交 `DELETE /api/prefill_group/:id`（`DeletePrefillGroup`）
- **则：** 系统删除该预填分组
