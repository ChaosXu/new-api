# 管理订阅套餐

## 摘要

让管理员创建和管理订阅套餐（CRUD、上下架），定义面向用户的订阅方案。

## 用例：
- **作为** 管理员
- **我想要** 创建、编辑、上架/下架订阅套餐
- **以便** 我能为用户提供结构化的订阅方案，灵活运营订阅业务

## 验收标准：

### 场景：管理员查看套餐列表
- **假设：** 管理员已登录（AdminAuth）
- **当：** 管理员请求 `GET /api/subscription/admin/plans`（`AdminListSubscriptionPlans`）
- **则：** 返回全部套餐列表

### 场景：管理员创建套餐
- **假设：** 平台已完成支付合规确认，管理员已登录
- **当：** 管理员提交 `POST /api/subscription/admin/plans`（`AdminCreateSubscriptionPlan`）
- **则：** 系统校验标题非空、价格 0-9999、货币强制 USD、升降级分组存在、重置周期合法后创建套餐

### 场景：管理员更新套餐
- **假设：** 管理员已登录
- **当：** 管理员提交 `PUT /api/subscription/admin/plans/:id`（`AdminUpdateSubscriptionPlan`）
- **则：** 系统校验规则后更新套餐

### 场景：管理员上架/下架套餐
- **假设：** 管理员已登录
- **当：** 管理员提交 `PATCH /api/subscription/admin/plans/:id`（`AdminUpdateSubscriptionPlanStatus`）
- **则：** 系统更新套餐状态（上架/下架），下架后用户不可见
