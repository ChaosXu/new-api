# 查看与搜索用户

## 摘要

让管理员分页浏览和搜索全平台用户，掌握用户全貌以支撑运营决策。

## 用例：
- **作为** 管理员
- **我想要** 分页浏览全部用户并按关键字、分组、角色、状态搜索
- **以便** 我能掌握平台用户全貌，快速定位特定用户进行运营管理

## 验收标准：

### 场景：管理员分页查看用户列表
- **假设：** 管理员已登录（role ≥ 管理员）
- **当：** 管理员请求 `GET /api/user/`（`controller/user.go` `GetAllUsers`，AdminAuth）
- **则：** 分页返回全平台用户列表（支持排序）

### 场景：管理员搜索用户
- **假设：** 管理员已登录
- **当：** 管理员请求 `GET /api/user/search`（`SearchUsers`）按 keyword、group、role、status 过滤
- **则：** 返回匹配条件的用户列表

### 场景：管理员查看用户详情（受角色层级约束）
- **假设：** 管理员已登录
- **当：** 管理员请求 `GET /api/user/:id`（`GetUser`）
- **则：** 系统通过 `canManageTargetRole` 校验：管理员只能查看比自己角色更低（或自己是超管）的用户详情，同级或更高角色被拒绝（`MsgUserNoPermissionHigherLevel`）
