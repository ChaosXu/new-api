# 绑定与管理第三方账号

## 摘要

让已登录用户将自己的账号与第三方（GitHub/Discord/OIDC/微信/Telegram/自定义）绑定，丰富登录方式。

## 用例：
- **作为** 普通用户
- **我想要** 将我的账号绑定到第三方平台（GitHub/Discord/OIDC/LinuxDO/微信/Telegram/自定义 OAuth）
- **以便** 我能用多种方式登录账号，且在丢失某凭据时有备用登录方式

## 验收标准：

### 场景：用户绑定标准 OAuth 提供商
- **假设：** 用户已登录，目标提供商已启用
- **当：** 用户先请求 `POST /api/oauth/state`（intent=`bind`，TryUserAuth），跳转授权后回调 `GET /api/oauth/:provider`（`HandleOAuth` → `handleOAuthBind`）
- **则：** 系统校验 state 与会话一致后，将第三方账号 ID 绑定到当前用户，返回绑定成功

### 场景：第三方账号已被其它用户绑定
- **假设：** 该第三方账号 ID 已关联到系统中的其他用户
- **当：** 用户尝试绑定
- **则：** 请求被拒绝并提示该账号已被绑定（`MsgOAuthAlreadyBound`）

### 场景：用户绑定微信
- **假设：** 管理员已启用微信且用户的微信 ID 未被占用
- **当：** 用户提交 `POST /api/oauth/wechat/bind`（`controller/wechat.go` `WeChatBind`，UserAuth）
- **则：** 系统将微信 ID 绑定到当前用户

### 场景：用户绑定 Telegram
- **假设：** 管理员已启用 Telegram
- **当：** 用户先调用 `POST /api/oauth/telegram/bind/start`（`TelegramBindStart`）获取 flow_token，再由 Telegram 回调 `GET /api/oauth/telegram/bind/:flow_token`（`TelegramBind`）
- **则：** 系统校验 Telegram 签名与 flow 后绑定到当前用户

### 场景：用户查看与解绑自定义 OAuth 绑定
- **假设：** 用户已绑定自定义 OAuth 提供商
- **当：** 用户请求 `GET /api/user/oauth/bindings`（`controller/custom_oauth.go` `GetUserOAuthBindings`）查看列表，或 `DELETE /api/user/oauth/bindings/:provider_id`（`UnbindCustomOAuth`）解绑
- **则：** 系统返回绑定列表或解除指定自定义 OAuth 绑定
