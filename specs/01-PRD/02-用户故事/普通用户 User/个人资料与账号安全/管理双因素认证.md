# 管理双因素认证（2FA）

## 摘要

让普通用户开启或关闭基于 TOTP 的双因素认证，增强账号安全性。

## 用例：
- **作为** 普通用户
- **我想要** 开启、关闭或重置我的双因素认证（2FA）
- **以便** 我能通过二次验证保护账号，或在需要时安全地停用

## 验收标准：

### 场景：用户查看 2FA 状态
- **假设：** 用户已登录
- **当：** 用户请求 `GET /api/user/2fa/status`（`controller/twofa.go` `Get2FAStatus`）
- **则：** 返回 2FA 是否已启用、是否被锁定、剩余备用码数量

### 场景：用户初始化并启用 2FA
- **假设：** 用户已登录且未启用 2FA
- **当：** 用户先请求 `POST /api/user/2fa/setup` 生成 TOTP 密钥与二维码，再用 Authenticenticator 生成验证码提交 `POST /api/user/2fa/enable`（`controller/twofa.go` `Enable2FA`）
- **则：** 系统校验 TOTP 码正确后启用 2FA，返回备用码，并推进 auth version

### 场景：用户关闭 2FA
- **假设：** 用户已启用 2FA
- **当：** 用户提交 `POST /api/user/2fa/disable` 携带正确的 TOTP 码或备用码
- **则：** 系统校验通过后关闭 2FA

### 场景：用户重新生成备用码
- **假设：** 用户已启用 2FA
- **当：** 用户提交 `POST /api/user/2fa/backup_codes` 并通过 TOTP 校验
- **则：** 系统生成一组新的备用码，旧备用码失效
