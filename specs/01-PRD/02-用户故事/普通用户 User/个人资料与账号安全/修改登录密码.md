# 修改登录密码

## 摘要

让普通用户通过校验原密码修改登录密码，并在修改后安全吊销其它会话。

## 用例：
- **作为** 普通用户
- **我想要** 修改我的登录密码
- **以便** 我能定期更换密码以保护账号安全，或在怀疑密码泄露时及时止损

## 验收标准：

### 场景：用户提供正确原密码修改密码
- **假设：** 用户已登录且账号已设置密码
- **当：** 用户提交 `PUT /api/user/self` 携带原密码（`original_password`）和新密码（`Password`）
- **则：** 系统校验原密码正确后更新密码，推进 auth version 以吊销其它会话，并为当前设备下发新的访问令牌，返回成功

### 场景：原密码错误被拒绝
- **假设：** 用户提交的原密码与账号实际密码不匹配
- **当：** 用户提交修改密码请求
- **则：** 请求被拒绝并提示原密码错误，密码不变

### 场景：未设密码的 OAuth 用户无法改密
- **假设：** 用户账号从未设置过密码（如纯 OAuth 注册用户）
- **当：** 用户尝试修改密码
- **则：** 请求被拒绝，提示需先绑定邮箱或通过其它方式设置密码
