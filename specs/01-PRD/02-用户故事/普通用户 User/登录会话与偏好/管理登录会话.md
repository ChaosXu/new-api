# 管理登录会话

## 摘要

让普通用户查看和管理自己的登录会话，及时吊销可疑会话。

## 用例：
- **作为** 普通用户
- **我想要** 查看我所有设备的登录会话并吊销可疑或不需要的会话
- **以便** 我能掌控账号登录状态，在异常登录时及时止损

## 验收标准：

### 场景：用户查看登录会话列表
- **假设：** 用户已登录
- **当：** 用户请求 `GET /api/user/sessions`（`controller/auth_session.go` `GetLoginSessions`）
- **则：** 返回该用户所有登录会话（含设备、IP、登录时间、是否当前会话等）

### 场景：用户吊销指定会话
- **假设：** 用户已登录
- **当：** 用户提交 `DELETE /api/user/sessions/:sid`（`DeleteLoginSession`）
- **则：** 系统吊销指定会话；若吊销的是当前会话则清除 refresh cookie，用户需重新登录

### 场景：用户吊销其它全部会话
- **假设：** 用户已登录
- **当：** 用户提交 `POST /api/user/sessions/revoke-others`（`RevokeOtherLoginSessions`）
- **则：** 系统吊销除当前会话外的所有其它会话

### 场景：用户登出
- **假设：** 用户已登录
- **当：** 用户提交 `POST /api/user/auth/logout`（`AuthLogout`，CriticalRateLimit）
- **则：** 系统吊销当前会话并清除 refresh cookie

### 场景：用户刷新登录态
- **假设：** 用户持有有效的 refresh token
- **当：** 用户提交 `POST /api/user/auth/refresh`（`RefreshAuth`，CriticalRateLimit）
- **则：** 系统颁发新的访问令牌续期登录态
