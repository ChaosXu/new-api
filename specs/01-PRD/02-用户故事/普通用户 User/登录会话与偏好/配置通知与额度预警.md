# 配置通知与额度预警

## 摘要

让普通用户配置额度预警与通知渠道（Webhook/Bark/Gotify/邮件），在额度不足时及时获知。

## 用例：
- **作为** 普通用户
- **我想要** 配置额度预警阈值和通知渠道（如 Webhook、Bark、Gotify、邮件）
- **以便** 我能在额度即将耗尽时及时收到通知并充值，避免服务中断

## 验收标准：

### 场景：用户更新通知与额度预警设置
- **假设：** 用户已登录
- **当：** 用户提交 `PUT /api/user/setting`（`controller/user.go` `UpdateUserSetting`）
- **则：** 系统更新用户的通知类型（email/webhook/bark/gotify）、预警阈值、各通知渠道配置（webhook URL、Bark/Goty 参数）、是否记录 IP 日志等设置

### 场景：额度低于阈值时触发通知
- **假设：** 用户已配置额度预警
- **而且假设：** 用户额度降至预警阈值以下
- **当：** 触发额度预警条件时
- **则：** 系统按用户配置的通知渠道发送预警通知
