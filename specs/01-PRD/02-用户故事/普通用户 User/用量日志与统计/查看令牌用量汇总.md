# 查看令牌用量汇总

## 摘要

让普通用户通过 API 令牌直接查询其用量与额度，便于在第三方工具（如 NextChat）中显示余额。

## 用例：
- **作为** 普通用户
- **我想要** 通过 API 令牌查询该令牌的用量汇总与额度余额
- **以便** 我在第三方客户端（如 NextChat）中直接看到余额与用量，无需登录后台

## 验收标准：

### 场景：用户用令牌查询用量汇总
- **假设：** 用户持有效的只读 API 令牌
- **当：** 用户请求 `GET /api/usage/token/`（`controller/token.go` `GetTokenUsage`，TokenAuthReadOnly）
- **则：** 返回该令牌的用量汇总数据

### 场景：用户用令牌查询额度（兼容 Dashboard）
- **假设：** 用户持有效 API 令牌
- **当：** 用户请求 `GET /dashboard/billing/subscription` 或 `/dashboard/billing/usage`（`controller/billing.go`，TokenAuth）
- **则：** 返回兼容 OpenAI Dashboard 格式的额度与用量信息

### 场景：用户用令牌查询关联日志
- **假设：** 用户持有效的只读 API 令牌
- **当：** 用户请求 `GET /api/log/token`（`controller/log.go` `GetLogByKey`，TokenAuthReadOnly）
- **则：** 返回该令牌关联的调用日志
