# 查看个人调用日志

## 摘要

让普通用户按多维度查看自己的 AI 调用日志，追踪用量明细。

## 用例：
- **作为** 普通用户
- **我想要** 按类别、时间、模型、令牌名等筛选查看我的调用日志
- **以便** 我能追踪用量明细、排查异常调用或核对计费

## 验收标准：

### 场景：用户查看个人日志列表
- **假设：** 用户已登录
- **当：** 用户请求 `GET /api/log/self`（`controller/log.go` `GetUserLogs`，UserAuth）
- **则：** 分页返回该用户的日志，支持按类型（对话/补全/图像/音频等）、时间区间、token_name、model_name、group、request_id 过滤

### 场景：用户查看个人日志统计
- **假设：** 用户已登录
- **当：** 用户请求 `GET /api/log/self/stat`（`GetLogsSelfStat`）
- **则：** 返回指定区间的额度消费、RPM（每分钟请求数）、TPM（每分钟 token 数）等汇总统计

### 场景：用户查看个人额度与流量趋势
- **假设：** 用户已登录
- **当：** 用户请求 `GET /api/data/self`（额度日期，跨度≤1 个月）或 `GET /api/data/flow/self`（流量数据，跨度≤1 个月）
- **则：** 返回按日期聚合的额度消耗或流量趋势数据

### 场景：用户查看异步任务记录
- **假设：** 用户已登录
- **当：** 用户请求 `GET /api/task/self`（异步任务）或 `GET /api/mj/self`（Midjourney 任务）
- **则：** 返回该用户的异步任务/Midjourney 任务记录列表
