# 在 Playground 试用模型

## 摘要

让普通用户在控制台内免创建 API 令牌直接试用模型，降低使用门槛。

## 用例：
- **作为** 普通用户
- **我想要** 在控制台的 Playground 中直接对话试用各种模型
- **以便** 我在创建正式令牌前就能快速测试模型效果与响应质量

## 验收标准：

### 场景：用户在 Playground 发起对话
- **假设：** 用户已登录
- **而且假设：** Playground 接口不允许使用 access token 鉴权（仅用户登录态）
- **当：** 用户提交 `POST /pg/chat/completions`（`controller/playground.go` `Playground`，UserAuth + Distribute）
- **则：** 系统为该用户构造临时令牌并按用户分组调度上游渠道，按用量扣减用户额度，返回模型响应

### 场景：用户尝试用 access token 调用 Playground 被拒绝
- **假设：** 请求携带了 access token（`use_access_token=true`）
- **当：** 用户提交 Playground 对话
- **则：** 请求被拒绝并提示不允许使用 access token
