# 购买与管理订阅

## 摘要

让普通用户浏览订阅套餐、选择计费方式并购买订阅，通过订阅获得额度权益。

## 用例：
- **作为** 普通用户
- **我想要** 浏览订阅套餐、管理计费偏好并购买订阅
- **以便** 我能选择比按量付费更划算的订阅方案，持续获得额度权益

## 验收标准：

### 场景：用户浏览订阅套餐
- **假设：** 用户已登录
- **当：** 用户请求 `GET /api/subscription/plans`（`controller/subscription.go` `GetSubscriptionPlans`）
- **则：** 返回已启用的套餐列表（未通过支付合规则返回空）

### 场景：用户查看我的订阅
- **假设：** 用户已登录
- **当：** 用户请求 `GET /api/subscription/self`（`GetSubscriptionSelf`）
- **则：** 返回计费偏好、当前活跃订阅及历史订阅（含已过期）

### 场景：用户更新计费偏好
- **假设：** 用户已登录
- **当：** 用户提交 `PUT /api/subscription/self/preference`（`UpdateSubscriptionPreference`）
- **则：** 系统更新用户的 `billing_preference` 计费偏好

### 场景：用户用余额购买订阅
- **假设：** 用户已通过支付合规校验，且账户余额充足
- **当：** 用户提交 `POST /api/subscription/balance/pay`（`SubscriptionRequestBalancePay`，CriticalRateLimit）
- **则：** 系统扣减账户余额完成订阅购买，激活订阅权益

### 场景：用户通过在线支付购买订阅
- **假设：** 用户已通过支付合规校验
- **当：** 用户提交 `POST /api/subscription/epay/pay`、`/stripe/pay`、`/creem/pay` 或 `/waffo-pancake/pay`
- **则：** 系统创建对应渠道的订阅支付订单，支付成功后由回调激活订阅
