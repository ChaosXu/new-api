# 创建 API 令牌

## 摘要

让普通用户创建带有额度、模型限制、IP 限制等策略的 API 令牌，用于调用 AI 接口。

## 用例：
- **作为** 普通用户
- **我想要** 创建新的 API 令牌并配置额度上限、过期时间、可用模型与 IP 白名单
- **以便** 我能按用途隔离使用，控制风险和成本

## 验收标准：

### 场景：用户创建一个限定额度的令牌
- **假设：** 用户已登录，且名下令牌数量未达上限（`MaxUserTokens`）
- **当：** 用户提交 `POST /api/token/`（`controller/token.go` `AddToken`）提供名称（≤50 字符）和剩余额度（0 ~ 10 亿×QuotaPerUnit）
- **则：** 系统生成唯一 key 并创建令牌，返回成功

### 场景：令牌数量达上限被拒绝
- **假设：** 用户名下令牌数量已达到系统配置的 `MaxUserTokens` 上限
- **当：** 用户提交创建令牌请求
- **则：** 请求被拒绝并提示已达到最大令牌数量限制

### 场景：额度超限被拒绝
- **假设：** 用户为非无限额度令牌设置了超过上限的剩余额度
- **当：** 用户提交创建请求
- **则：** 请求被拒绝并提示额度超出最大值（`MsgTokenQuotaExceedMax`）

### 场景：创建带模型限制的令牌
- **假设：** 用户希望令牌仅能调用特定模型
- **当：** 用户提交创建请求并启用 `ModelLimitsEnabled`、指定 `ModelLimits` 白名单
- **则：** 系统创建令牌并记录模型白名单，该令牌仅可调用白名单内模型

### 场景：创建使用自动分组的令牌
- **假设：** 用户希望令牌在多个分组间自动调度
- **当：** 用户提交创建请求设置 `Group="auto"` 并提供 `AutoGroups`
- **则：** 系统创建令牌并配置自动分组列表，调用时按多分组策略调度
