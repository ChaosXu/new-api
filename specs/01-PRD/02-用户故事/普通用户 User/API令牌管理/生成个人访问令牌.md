# 生成个人访问令牌

## 摘要

让普通用户生成个人访问令牌（PAT），在 Dashboard 和 Playground 内免创建 API 令牌即可鉴权。

## 用例：
- **作为** 普通用户
- **我想要** 生成一个个人访问令牌（系统访问令牌）
- **以便** 我能在控制台和 Playground 中直接体验模型，无需手动创建并复制 API 令牌

## 验收标准：

### 场景：用户生成个人访问令牌
- **假设：** 用户已登录
- **当：** 用户请求 `GET /api/user/token`（`controller/user.go` `GenerateAccessToken`）
- **则：** 系统生成一个 29~32 位的系统访问令牌并返回，用户可用它在 Dashboard/Playground 鉴权
