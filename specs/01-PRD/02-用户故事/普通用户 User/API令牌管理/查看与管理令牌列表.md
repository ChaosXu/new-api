# 查看与管理令牌列表

## 摘要

让普通用户查看、搜索、更新和删除自己的 API 令牌，掌握令牌使用情况。

## 用例：
- **作为** 普通用户
- **我想要** 查看我的所有令牌、搜索特定令牌，并更新或删除它们
- **以便** 我能管理令牌生命周期、停用泄露的令牌或调整额度

## 验收标准：

### 场景：用户查看令牌列表
- **假设：** 用户已登录
- **当：** 用户请求 `GET /api/token/`（`controller/token.go` `GetAllTokens`）
- **则：** 分页返回该用户名下所有令牌（key 脱敏）

### 场景：用户搜索令牌
- **假设：** 用户已登录
- **当：** 用户请求 `GET /api/token/search`（`SearchTokens`）按关键字过滤
- **则：** 返回匹配关键字的令牌列表

### 场景：用户查看令牌明文 Key
- **假设：** 用户已登录
- **当：** 用户提交 `POST /api/token/:id/key`（`controller/token.go` `GetTokenKey`，受 CriticalRateLimit + DisableCache）
- **则：** 返回该令牌的明文 key（仅归属用户可查）

### 场景：用户更新令牌（仅状态）
- **假设：** 用户希望快速启用/禁用某令牌
- **当：** 用户提交 `PUT /api/token/?status_only=1`（`UpdateToken`）
- **则：** 系统仅更新令牌状态，不修改其它字段

### 场景：用户删除令牌
- **假设：** 用户已登录
- **当：** 用户提交 `DELETE /api/token/:id`（`DeleteToken`）
- **则：** 系统校验令牌归属后删除，该令牌不再可用

### 场景：用户批量删除令牌
- **假设：** 用户已登录
- **当：** 用户提交 `POST /api/token/batch`（`DeleteTokenBatch`）提供多个令牌 ID
- **则：** 系统批量删除这些归属令牌
