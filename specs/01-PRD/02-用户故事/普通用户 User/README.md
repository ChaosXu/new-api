# 普通用户（User）用户故事

> 角色定义：系统的主要终端使用者。管理自己的 API 令牌、查看个人用量与日志、充值与订阅、试用 Playground，并通过令牌调用 AI API。继承访客全部能力。

共 22 个用户故事，按用例分组组织。每个故事遵循 Mike Cohn 用例格式 + Gherkin 验收标准。鉴权中间件：`UserAuth()`（登录态）或 `TokenAuth()`（API 令牌）。

## 权限边界说明

普通用户**不能**访问（需 `AdminAuth()`/`RootAuth()`）：用户管理、兑换码管理、全平台日志/数据、渠道管理、模型元数据、系统设置等管理员功能。
