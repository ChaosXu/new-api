# 权限授权（RBAC）

## 职责

基于 Casbin 的角色权限授权，定义角色、资源、策略执行器，对已鉴权用户做细粒度权限判定（能否访问某资源/执行某操作）。

## 契约（开放能力）

- **细粒度权限判定能力**：对已鉴权用户判定能否访问某资源/执行某操作。
- **角色与策略管理能力**：定义并维护角色、资源与策略分配。
- **多节点策略同步能力**：周期性重载授权策略以传播多节点变更。

## 覆盖代码

`server/internal/service/authz/`（adapter.go/assignment.go 等角色与策略）

## 依赖（内部逻辑模块）

- 数据访问（用户角色/权限分配）
- 通用工具（Casbin 引擎）
