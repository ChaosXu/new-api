# 中继辅助

## 职责

中继链路的辅助函数集合，提供计费/定价、流式扫描与结果收集、模型映射、请求合法性校验等被编排层与适配器共用的能力。

## 契约（开放能力）

- **请求合法性校验能力**：校验各类中继请求（含 max_tokens 族字段的有界性），拒绝越界值。
- **计费/定价辅助能力**：提供按模型/用量计费与定价的共用函数。
- **流式结果收集能力**：扫描并聚合流式响应的结果（token 用量等）。
- **模型映射能力**：在客户端模型名与上游模型名间转换。

## 覆盖代码

`relay/helper/`（valid_request.go 请求校验、计费/定价函数、流式扫描等）

## 依赖（内部逻辑模块）

- 中继上下文（操作 RelayInfo）
- 业务逻辑（调用计费结算、渠道选择）
- 配置（计费倍率、运营设置、计费模式）
- 通用工具、常量、日志
