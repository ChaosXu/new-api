# 渠道选择

## 职责

为请求选择合适的上游渠道，支持按优先级、权重、分组、亲和性等策略分发；管理渠道可用性与自动禁用/启用。

## 契约（开放能力）

- **按策略选择渠道的能力**：按优先级/权重/分组/亲和性为请求选出上游渠道。
- **分组倍率计算能力**：按用户分组计算计费倍率。
- **渠道可用性管理能力**：渠道自动禁用/启用与可用性维护。

## 覆盖代码

`service/channel.go`、`service/channel_select.go`、`service/channel_affinity.go`、`service/group.go`

## 依赖（内部逻辑模块）

- 数据访问（渠道/分组的读写与缓存）
- 配置（渠道亲和设置、运营设置）
- 通用工具（缓存）
