# 计费表达式引擎

## 职责

基于 expr-lang 的分层/动态计费表达式引擎，编译并执行表达式形式的定价规则，支持表达式版本化。供计费结算链路做按表达式定价。

## 契约（开放能力）

- **计费表达式编译与执行能力**：编译并执行表达式形式的定价规则。
- **表达式版本化能力**：以版本机制管理表达式演进。
- **配额取整委托能力**：表达式取整委托通用工具的饱和取整函数。

## 覆盖代码

`pkg/billingexpr/`（compile.go/round.go 等）、设计文档 `pkg/billingexpr/expr.md`

## 依赖（内部逻辑模块）

- 通用工具（配额换算、JSON）

## 项目约束

- 改动前**必须先读 `pkg/billingexpr/expr.md`**（设计哲学、表达式语言、架构、token 归一化、配额换算、版本化）。
