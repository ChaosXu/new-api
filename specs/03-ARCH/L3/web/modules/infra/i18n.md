# 国际化基础

## 职责

基于 i18next 的多语言底座：i18next 初始化、7 种支持语言清单与编码映射、静态翻译键集中登记（兜底正则扫描遗漏的动态键）、locale 资源装配。

## 契约（开放能力）

- **i18next 初始化能力**：装配语言检测器 + react-i18next，localStorage 缓存语言，回退英语，禁用命名空间分隔符以兼容冒号键
- **语言清单与编码映射能力**：提供 7 种语言（简中、英、法、俄、日、越、繁中），浏览器语言到项目编码双向映射（如 `zh-CN`→`zhCN`），及到 BCP-47 的反向转换供 Intl API 使用
- **静态翻译键登记能力**：集中维护导航、侧边栏视图、系统设置、定价常量等动态标签的翻译键，兜底正则扫描遗漏的动态键

## 覆盖代码

`web/src/i18n/config.ts`、`web/src/i18n/languages.ts`、`web/src/i18n/static-keys.ts`、`web/src/i18n/locales/`（7 种语言 JSON）

## 依赖（内部逻辑模块）

- 无（被全站依赖的基础设施）
