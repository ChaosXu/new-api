# 查询模型性能

> `GET /api/perf-metrics`

- **鉴权**：HeaderNavModulePublicOrUserAuth("pricing")（perf-metrics 路由组的公共/用户鉴权）
- **用途**：查询单个模型在指定时间窗口内、按分组拆分的性能时序数据（首 token 延迟、整体延迟、成功率、TPS）。

## 请求

Query 参数：

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| model | string | 是 | 模型名（缺失返回 400） |
| group | string | 否 | 指定分组（不传则聚合全部活跃分组） |
| hours | int | 否 | 统计窗口小时数，默认 `24` |

## 响应

标准信封 `{success, data}`。`data` 为 `QueryResult`：

| 字段 | 类型 | 说明 |
|---|---|---|
| model_name | string | 模型名 |
| series_schema | string | 序列结构标识 |
| groups | array | 各分组的性能序列 |

`GroupResult`（groups 元素）：

| 字段 | 类型 | 说明 |
|---|---|---|
| group | string | 分组名（仅返回活跃分组或 `auto`） |
| avg_ttft_ms | int | 平均首 token 延迟（毫秒） |
| avg_latency_ms | int | 平均整体延迟（毫秒） |
| success_rate | float | 成功率（0~1） |
| avg_tps | float | 平均 TPS |
| series | array | 时间桶序列 |

`BucketPoint`（series 元素）：

| 字段 | 类型 | 说明 |
|---|---|---|
| ts | int | 时间桶起始时间戳 |
| avg_ttft_ms | int | 该桶平均首 token 延迟 |
| avg_latency_ms | int | 该桶平均整体延迟 |
| success_rate | float | 该桶成功率 |
| avg_tps | float | 该桶平均 TPS |

```json
{
  "success": true,
  "data": {
    "model_name": "gpt-4o",
    "series_schema": "default",
    "groups": [
      {
        "group": "default",
        "avg_ttft_ms": 600,
        "avg_latency_ms": 1200,
        "success_rate": 0.99,
        "avg_tps": 45.2,
        "series": [
          { "ts": 1700000000, "avg_ttft_ms": 580, "avg_latency_ms": 1180, "success_rate": 1, "avg_tps": 46 }
        ]
      }
    ]
  }
}
```

## 错误码

| HTTP 状态 | 场景 | 说明 |
|---|---|---|
| 400 | 缺少 `model` | `success=false`，`message=model is required` |
| 500 | 查询失败 | `success=false`，`message=<err>` |
