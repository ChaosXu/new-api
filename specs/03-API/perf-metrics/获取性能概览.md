# 获取性能概览

> `GET /api/perf-metrics/summary`

- **鉴权**：HeaderNavModulePublicOrUserAuth("pricing")（perf-metrics 路由组的公共/用户鉴权）
- **用途**：返回最近若干小时内所有模型（按活跃分组聚合）的性能汇总，用于性能面板总览。

## 请求

Query 参数：

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| hours | int | 否 | 统计窗口小时数，默认 `24` |

## 响应

标准信封 `{success, data}`。`data` 为 `SummaryAllResult`：

| 字段 | 类型 | 说明 |
|---|---|---|
| models | array | 各模型性能汇总列表 |

`ModelSummary`（models 元素）：

| 字段 | 类型 | 说明 |
|---|---|---|
| model_name | string | 模型名 |
| avg_latency_ms | int | 平均延迟（毫秒） |
| success_rate | float | 成功率（0~1） |
| avg_tps | float | 平均每秒生成 token 数 |
| recent_success_rates | array | 近期成功率序列（可省略） |

```json
{
  "success": true,
  "data": {
    "models": [
      {
        "model_name": "gpt-4o",
        "avg_latency_ms": 1200,
        "success_rate": 0.99,
        "avg_tps": 45.2,
        "recent_success_rates": [1, 0.99, 1]
      }
    ]
  }
}
```

## 错误码

| HTTP 状态 | 场景 | 说明 |
|---|---|---|
| 500 | 查询失败 | `success=false`，`message=<err>` |
