# 删除过期实例
> `DELETE /api/system-info/stale-instances`
- **鉴权**：RootAuth（超级管理员）
- **用途**：删除全部已过期（失联）的系统实例。

## 请求
无

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data.deleted_count | int | 删除的实例数量 |

示例：
```json
{ "success": true, "message": "", "data": { "deleted_count": 3 } }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | （错误信息） | 删除失败 |
