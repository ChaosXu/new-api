# 实例列表
> `GET /api/system-info/instances`
- **鉴权**：RootAuth（超级管理员）
- **用途**：列出全部系统实例（节点），含在线状态与最近心跳。

## 请求
无

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data | SystemInstanceResponse[] | 实例列表（node_name、last_heartbeat、online 等） |

示例：
```json
{ "success": true, "message": "", "data": [ { "node_name": "node-1", "online": true } ] }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | （错误信息） | 查询失败 |
