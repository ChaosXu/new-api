# 删除指定实例
> `DELETE /api/system-info/instances/:node_name`
- **鉴权**：RootAuth（超级管理员）
- **用途**：按节点名删除已过期的系统实例（仅当该实例确已过期时才删除）。

## 请求
路径参数：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| node_name | string | 是 | 节点名称 |

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data.deleted_count | int | 成功为 1 |

示例：
```json
{ "success": true, "message": "", "data": { "deleted_count": 1 } }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | node name is required | node_name 为空 |
| 200 | instance is not stale or no longer exists | 实例未过期或不存在 |
| 200 | （错误信息） | 删除失败 |
