# 拉取上游倍率
> `POST /api/ratio_sync/fetch`
- **鉴权**：RootAuth（超级管理员）
- **用途**：从指定上游或渠道拉取倍率数据，与本地比较并返回差异和测试结果。

## 请求
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| upstreams | UpstreamDTO[] | 否 | 显式上游列表（name、base_url 必填；endpoint 可选） |
| channel_ids | int64[] | 否 | 渠道 ID 列表（用其 BaseURL 作为上游） |
| timeout | int | 否 | 每源超时秒数，默认 30 |

UpstreamDTO：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| id | int | 否 | 渠道 ID |
| name | string | 是 | 上游名称 |
| base_url | string | 是 | 基础地址（须 http 开头） |
| endpoint | string | 否 | 倍率端点路径 |

示例：
```json
{
  "upstreams": [ { "name": "OpenAI", "base_url": "https://api.openai.com", "endpoint": "/v1/pricing" } ],
  "channel_ids": [1, 2],
  "timeout": 30
}
```

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data.differences | object | 本地与各上游的差异（按字段） |
| data.test_results | TestResult[] | 各上游连通性测试结果（name、status、error） |

示例：
```json
{
  "success": true,
  "data": { "differences": {}, "test_results": [ { "name": "OpenAI", "status": "ok" } ] }
}
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 400 | 请求参数格式错误 | 请求体解析失败 |
| 500 | 查询渠道失败 | channel_ids 查询失败 |
| 200 | 无有效上游渠道 | 无可拉取的上游 |
| 200 | （错误信息） | 拉取过程失败 |
