# 可同步渠道列表
> `GET /api/ratio_sync/channels`
- **鉴权**：RootAuth（超级管理员）
- **用途**：列出可参与倍率同步的渠道（含已配置 BaseURL 的渠道，并追加内置上游项）。

## 请求
无

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data | SyncableChannel[] | 渠道列表 |

SyncableChannel：
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | int | 渠道 ID |
| name | string | 渠道名称 |
| base_url | string | 基础地址 |
| status | int | 渠道状态 |
| type | int | 渠道类型 |

示例：
```json
{
  "success": true,
  "message": "",
  "data": [ { "id": 1, "name": "OpenAI", "base_url": "https://api.openai.com", "status": 1, "type": 1 } ]
}
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | （错误信息） | 查询渠道失败 |
