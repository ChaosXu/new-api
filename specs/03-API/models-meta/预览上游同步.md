# 预览上游同步
> `GET /api/models/sync_upstream/preview`
- **鉴权**：AdminAuth（管理员）
- **用途**：拉取上游模型数据，预览本地缺失模型与字段冲突，不落库。

## 请求
Query 参数：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| locale | string | 否 | 语言区域，决定上游源 URL |

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data.missing | object[] | 上游存在但本地缺失的模型 |
| data.conflicts | object[] | 与本地存在字段冲突的模型（含字段级差异） |
| data.source.locale | string | 实际使用的 locale |
| data.source.models_url | string | 上游模型源 URL |
| data.source.vendors_url | string | 上游供应商源 URL |

示例：
```json
{ "success": true, "data": { "missing": [], "conflicts": [], "source": { "locale": "zh", "models_url": "...", "vendors_url": "..." } } }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | 获取上游模型失败: ... | 拉取上游失败，data 含 locale/source_urls |
