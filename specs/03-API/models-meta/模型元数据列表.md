# 模型元数据列表
> `GET /api/models/`
- **鉴权**：AdminAuth（管理员）
- **用途**：分页获取模型元数据列表，含供应商计数统计。

## 请求
Query 参数：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| status | string | 否 | 状态筛选 |
| sync_official | string | 否 | 是否官方同步筛选 |
| p / page_size | int | 否 | 分页 |

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data.items | Model[] | 模型列表（已填充附加字段） |
| data.total | int64 | 总数 |
| data.page | int | 当前页 |
| data.page_size | int | 每页数量 |
| data.vendor_counts | object | 各供应商模型计数 |

示例：
```json
{ "success": true, "message": "", "data": { "items": [], "total": 0, "page": 0, "page_size": 10, "vendor_counts": {} } }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | （错误信息） | 查询失败 |
