# 获取模型
> `GET /api/models/:id`
- **鉴权**：AdminAuth（管理员）
- **用途**：按 ID 获取单个模型元数据。

## 请求
路径参数：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| id | int | 是 | 模型 ID |

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data | Model | 模型详情（已填充附加字段） |

示例：
```json
{ "success": true, "message": "", "data": { "id": 1, "model_name": "gpt-4" } }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | （错误信息） | id 解析失败或模型不存在 |
