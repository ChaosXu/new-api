# 搜索模型
> `GET /api/models/search`
- **鉴权**：AdminAuth（管理员）
- **用途**：按关键词、供应商、状态等搜索模型元数据。

## 请求
Query 参数：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| keyword | string | 否 | 关键词 |
| vendor | string | 否 | 供应商 |
| status | string | 否 | 状态 |
| sync_official | string | 否 | 是否官方同步 |
| p / page_size | int | 否 | 分页 |

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data.items | Model[] | 模型列表 |
| data.total | int64 | 总数 |
| data.page / data.page_size | int | 分页信息 |
| data.vendor_counts | object | 供应商计数 |

示例：
```json
{ "success": true, "message": "", "data": { "items": [], "total": 0, "page": 0, "page_size": 10, "vendor_counts": {} } }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | （错误信息） | 搜索失败 |
