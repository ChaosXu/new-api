# 删除模型
> `DELETE /api/models/:id`
- **鉴权**：AdminAuth（管理员）
- **用途**：按 ID 删除模型元数据，并刷新定价缓存。

## 请求
路径参数：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| id | int | 是 | 模型 ID |

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data | null | 删除成功 |

示例：
```json
{ "success": true, "message": "", "data": null }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | （错误信息） | id 解析失败或删除失败 |
