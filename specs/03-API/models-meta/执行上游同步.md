# 执行上游同步
> `POST /api/models/sync_upstream`
- **鉴权**：AdminAuth（管理员）
- **用途**：从上游同步缺失模型，并可指定覆盖字段，最终落库。

## 请求
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| overwrite | overwriteField[] | 否 | 需要覆盖更新的字段列表 |
| locale | string | 否 | 语言区域 |

允许空请求体。

示例：
```json
{ "overwrite": [], "locale": "zh" }
```

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data | object | 同步结果（创建/更新计数、源 URL 等） |

示例：
```json
{ "success": true, "data": { "created": 0, "updated": 0 } }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | 获取模型列表失败，请稍后重试 | 获取缺失模型失败 |
| 200 | 获取上游模型失败: ... | 拉取上游失败，data 含 locale/source_urls |
