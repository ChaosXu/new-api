# 更新模型
> `PUT /api/models/`
- **鉴权**：AdminAuth（管理员）
- **用途**：更新模型元数据；支持 `status_only=true` 仅更新状态。

## 请求
Query 参数：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| status_only | string | 否 | 为 `true` 时仅更新 status |

请求体（Model）：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| id | int | 是 | 模型 ID |
| status | int | status_only 时必填 | 状态 |
| model_name | string | 否 | 名称（非 status_only 时须唯一） |

示例（仅改状态）：`PUT /api/models/?status_only=true`，body `{ "id": 1, "status": 2 }`

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data | Model | 更新后的模型 |

示例：
```json
{ "success": true, "message": "", "data": { "id": 1, "status": 2 } }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | 参数错误 | 请求体解析失败 |
| 200 | 缺少模型 ID | id 为 0 |
| 200 | 模型名称已存在 | 非 status_only 时名称重复 |
