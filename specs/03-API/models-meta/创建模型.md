# 创建模型
> `POST /api/models/`
- **鉴权**：AdminAuth（管理员）
- **用途**：创建新的模型元数据，并刷新定价缓存。

## 请求
Model：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| model_name | string | 是 | 模型名称（唯一） |
| vendor_id | int | 否 | 供应商 ID |
| 其他 Model 字段 | - | 否 | 倍率、状态等 |

示例：
```json
{ "model_name": "gpt-4o", "vendor_id": 1 }
```

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data | Model | 创建后的模型 |

示例：
```json
{ "success": true, "message": "", "data": { "id": 2, "model_name": "gpt-4o" } }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | 参数错误 | 请求体解析失败 |
| 200 | 模型名称不能为空 | model_name 为空 |
| 200 | 模型名称已存在 | 名称重复 |
