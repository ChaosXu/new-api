# 发送密码重置邮件

> `GET /api/reset_password`

- **鉴权**：无登录鉴权；叠加 `CriticalRateLimit`（严格限流）+ `TurnstileCheck`（人机校验）
- **用途**：向邮箱发送密码重置链接邮件（含 token），链接有效期 `VerificationValidMinutes` 分钟。

## 请求

Query 参数：

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| email | string | 是 | 邮箱地址（须通过 `required,email` 校验，经 `NormalizeEmail` 归一化） |

## 响应

> 安全考虑：无论邮箱是否存在对应账号，均返回成功，避免账号枚举。

```json
{ "success": true, "message": "" }
```

## 错误码

| HTTP 状态 | 场景 | 说明 |
|---|---|---|
| 200 | 邮箱格式非法 | `无效的参数`（i18n），`success=false` |

> 发送失败仅记录日志，不影响对调用方的成功响应。限流 / 人机校验失败由中间件处理（通常 429 / 403）。
