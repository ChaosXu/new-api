# 发送邮箱验证码

> `GET /api/verification`

- **鉴权**：无登录鉴权；叠加 `EmailVerificationRateLimit`（邮箱验证码限流）+ `TurnstileCheck`（人机校验）
- **用途**：向指定邮箱发送 6 位注册验证码邮件，验证码在 `VerificationValidMinutes` 分钟内有效。

## 请求

Query 参数：

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| email | string | 是 | 邮箱地址（须通过 `required,email` 校验，经 `NormalizeEmail` 归一化） |

## 响应

成功：

```json
{ "success": true, "message": "" }
```

## 错误码

错误统一返回 HTTP 200，通过 `success=false` 表达：

| HTTP 状态 | 场景 | message |
|---|---|---|
| 200 | 邮箱格式非法 | `无效的参数`（i18n）/ `无效的邮箱地址` |
| 200 | 域名不在白名单 | `The administrator has enabled the email domain name whitelist...` |
| 200 | 邮箱别名含特殊符号（`+`/`.`） | `管理员已启用邮箱地址别名限制...` |
| 200 | 邮箱已被注册 | i18n：邮箱已被占用 |
| 200 | 发送邮件失败 | 由 `common.ApiError` 返回错误信息 |

> 限流与人机校验失败由对应中间件处理（通常 429 / 403）。
