# 创建用户订阅
> `POST /api/subscription/admin/users/:id/subscriptions`
- **鉴权**：AdminAuth（管理员）
- **用途**：管理员为指定用户从计划创建一个订阅（免支付）。需管理员已确认支付合规。

## 请求
路径参数：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| id | int | 是 | 用户 ID |

请求体：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| plan_id | int | 是 | 计划 ID |

示例：
```json
{ "plan_id": 1 }
```

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data | null 或 { message } | 成功为 null；有提示则 data.message |

示例：
```json
{ "success": true, "message": "", "data": null }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | 支付合规声明未确认（MsgPaymentComplianceRequired） | 管理员未确认支付合规 |
| 200 | 无效的用户ID | 用户 id 非法 |
| 200 | 参数错误 | 请求体解析失败或 plan_id 非法 |
