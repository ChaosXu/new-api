# 重置用户订阅
> `POST /api/subscription/admin/users/:id/subscriptions/reset`
- **鉴权**：AdminAuth（管理员）
- **用途**：按计划重置指定用户的订阅额度，并记录审计日志与用户日志。

## 请求
路径参数：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| id | int | 是 | 用户 ID |

请求体：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| plan_id | int | 是 | 计划 ID |
| advance_reset_time | bool | 否 | 是否提前重置时间，默认 true |

示例：
```json
{ "plan_id": 1, "advance_reset_time": false }
```

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data | SubscriptionResetResult | plan_id、plan_title、reset_count、user_count 等 |

示例：
```json
{ "success": true, "message": "", "data": { "plan_id": 1, "plan_title": "月度套餐", "reset_count": 1, "user_count": 1, "advance_reset_time": false } }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | 无效的用户ID | id 非法 |
| 200 | 参数错误 | 请求体解析失败或 plan_id 非法 |
