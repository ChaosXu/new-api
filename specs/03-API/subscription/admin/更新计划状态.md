# 更新计划状态
> `PATCH /api/subscription/admin/plans/:id`
- **鉴权**：AdminAuth（管理员）
- **用途**：单独更新订阅计划的启用状态。需管理员已确认支付合规。

## 请求
路径参数：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| id | int | 是 | 计划 ID |

请求体：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| enabled | bool | 是 | 是否启用 |

示例：
```json
{ "enabled": false }
```

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data | null | 更新成功 |

示例：
```json
{ "success": true, "message": "", "data": null }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | 支付合规声明未确认（MsgPaymentComplianceRequired） | 管理员未确认支付合规 |
| 200 | 无效的ID | id 非法 |
| 200 | 参数错误 | 请求体解析失败或 enabled 为 nil |
