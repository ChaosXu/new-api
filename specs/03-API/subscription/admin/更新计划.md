# 更新计划
> `PUT /api/subscription/admin/plans/:id`
- **鉴权**：AdminAuth（管理员）
- **用途**：更新指定订阅计划的全部字段（map 更新，允许零值）。需管理员已确认支付合规。

## 请求
路径参数：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| id | int | 是 | 计划 ID |

请求体：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| plan | SubscriptionPlan | 是 | 计划对象（覆盖更新） |

示例：
```json
{ "plan": { "title": "年度套餐", "price_amount": 99.99 } }
```

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data | null | 更新成功 |

示例：
```json
{ "success": true, "message": "", "data": null }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | 支付合规声明未确认（MsgPaymentComplianceRequired） | 管理员未确认支付合规 |
| 200 | 无效的ID | id 非法 |
| 200 | 参数错误 | 请求体解析失败 |
| 200 | 套餐标题不能为空 / 价格不能为负数 / 价格不能超过9999 | 字段校验 |
| 200 | 升级分组不存在 / 降级分组不存在 | 分组未配置 |
| 200 | 自定义重置周期需大于0秒 | 重置周期非法 |
