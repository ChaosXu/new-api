# 计划列表
> `GET /api/subscription/admin/plans`
- **鉴权**：AdminAuth（管理员）
- **用途**：管理员获取全部订阅计划（含禁用项），按 sort_order desc、id desc 排序。

## 请求
无

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data | SubscriptionPlanDTO[] | 全部计划，每项含 plan 详情 |

示例：
```json
{
  "success": true,
  "message": "",
  "data": [
    { "plan": { "id": 1, "title": "月度套餐", "enabled": true } }
  ]
}
```

## 错误码
无
