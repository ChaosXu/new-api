# 创建计划
> `POST /api/subscription/admin/plans`
- **鉴权**：AdminAuth（管理员）
- **用途**：创建新的订阅计划。需管理员已确认支付合规。

## 请求
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| plan | SubscriptionPlan | 是 | 计划对象（title、price_amount、duration_unit、duration_value、total_amount、upgrade_group、downgrade_group、quota_reset_period 等） |

示例：
```json
{ "plan": { "title": "月度套餐", "price_amount": 9.99, "duration_unit": "month", "duration_value": 1, "total_amount": 500000 } }
```

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data | SubscriptionPlan | 创建后的计划（含生成的 id） |

示例：
```json
{ "success": true, "message": "", "data": { "id": 2, "title": "月度套餐", "currency": "USD", ... } }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | 支付合规声明未确认（MsgPaymentComplianceRequired） | 管理员未确认支付合规 |
| 200 | 参数错误 | 请求体解析失败 |
| 200 | 套餐标题不能为空 | title 为空 |
| 200 | 价格不能为负数 / 价格不能超过9999 | price_amount 越界 |
| 200 | 购买上限不能为负数 / 总额度不能为负数 | 字段非法 |
| 200 | 升级分组不存在 / 降级分组不存在 | 分组未在 GroupRatio 中 |
| 200 | 自定义重置周期需大于0秒 | quota_reset_period=custom 时 seconds 非法 |
