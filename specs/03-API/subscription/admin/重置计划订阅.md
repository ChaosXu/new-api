# 重置计划订阅
> `POST /api/subscription/admin/plans/:id/subscriptions/reset`
- **鉴权**：AdminAuth（管理员）
- **用途**：重置某计划下所有用户订阅的额度，并记录审计日志与系统日志。

## 请求
路径参数：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| id | int | 是 | 计划 ID |

请求体：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| plan_id | int | 是 | 计划 ID（须与路径一致且大于 0） |
| advance_reset_time | bool | 否 | 是否提前重置时间，默认 true |

示例：
```json
{ "plan_id": 1, "advance_reset_time": true }
```

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data | SubscriptionResetResult | plan_id、plan_title、reset_count、user_count、affected_user_ids、advance_reset_time |

示例：
```json
{
  "success": true,
  "message": "",
  "data": { "plan_id": 1, "plan_title": "月度套餐", "reset_count": 5, "user_count": 5, "advance_reset_time": true }
}
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | 无效的ID | 计划 id 非法 |
| 200 | 参数错误 | 请求体解析失败或 plan_id 非法 |
