# 绑定订阅
> `POST /api/subscription/admin/bind`
- **鉴权**：AdminAuth（管理员）
- **用途**：管理员为指定用户绑定（赠送）一个订阅计划，不经过支付。需管理员已确认支付合规。

## 请求
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| user_id | int | 是 | 目标用户 ID |
| plan_id | int | 是 | 订阅计划 ID |

示例：
```json
{ "user_id": 10, "plan_id": 1 }
```

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data | null 或 { message } | 成功为 null；若 model 返回提示信息则 data.message 携带 |

示例：
```json
{ "success": true, "message": "", "data": null }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | 支付合规声明未确认（MsgPaymentComplianceRequired） | 管理员未确认支付合规 |
| 200 | 参数错误 | user_id/plan_id 非法或解析失败 |
| 200 | （model.AdminBindSubscription 返回错误） | 用户/计划不存在、超上限等 |
