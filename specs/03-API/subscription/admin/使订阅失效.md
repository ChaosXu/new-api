# 使订阅失效
> `POST /api/subscription/admin/user_subscriptions/:id/invalidate`
- **鉴权**：AdminAuth（管理员）
- **用途**：立即将指定的用户订阅置为失效。

## 请求
路径参数：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| id | int | 是 | 用户订阅 ID（user_subscription） |

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data | null 或 { message } | 成功为 null；有提示则 data.message |

示例：
```json
{ "success": true, "message": "", "data": null }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | 无效的订阅ID | id 非法 |
| 200 | （model.AdminInvalidateUserSubscription 返回错误） | 订阅不存在等 |
