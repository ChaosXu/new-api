# 查询用户订阅
> `GET /api/subscription/admin/users/:id/subscriptions`
- **鉴权**：AdminAuth（管理员）
- **用途**：管理员查询指定用户的全部订阅（含已过期）。

## 请求
路径参数：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| id | int | 是 | 用户 ID |

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data | SubscriptionSummary[] | 用户全部订阅 |

示例：
```json
{ "success": true, "message": "", "data": [] }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | 无效的用户ID | id 非法 |
