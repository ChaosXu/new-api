# 更新计费偏好
> `PUT /api/subscription/self/preference`
- **鉴权**：UserAuth（用户登录态）
- **用途**：更新当前用户的计费偏好（如订阅优先或余额优先）。

## 请求
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| billing_preference | string | 是 | 计费偏好，传入后经 NormalizeBillingPreference 标准化 |

示例：
```json
{ "billing_preference": "subscription" }
```

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data.billing_preference | string | 标准化后的计费偏好 |

示例：
```json
{
  "success": true,
  "message": "",
  "data": { "billing_preference": "subscription" }
}
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | 参数错误 | 请求体解析失败 |
