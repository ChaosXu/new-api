# 易支付购买订阅
> `POST /api/subscription/epay/pay`
- **鉴权**：UserAuth（用户登录态）+ CriticalRateLimit
- **用途**：通过易支付（epay）拉起订阅套餐支付。需管理员已确认支付合规。

## 请求
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| plan_id | int | 是 | 订阅计划 ID |
| payment_method | string | 是 | 易支付支付方式（如 alipay/wxpay） |

示例：
```json
{ "plan_id": 1, "payment_method": "alipay" }
```

## 响应
非标准信封（无 `success` 字段）：
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| message | string | 固定 `success` |
| data | object | 易支付提交参数（表单字段） |
| url | string | 易支付网关地址 |

示例：
```json
{
  "message": "success",
  "data": { "out_trade_no": "SUB...", "money": "9.99" },
  "url": "https://epay.example.com/submit.php"
}
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | 支付合规声明未确认（MsgPaymentComplianceRequired） | 管理员未确认支付合规 |
| 200 | 参数错误 | 请求体解析失败 |
| 200 | 套餐未启用 | 计划 disabled |
| 200 | 套餐金额过低 | 金额不满足支付要求 |
| 200 | 支付方式不存在 | payment_method 非法 |
| 200 | 已达到该套餐购买上限 | 超过单用户购买上限 |
| 200 | 回调地址配置错误 | notify/return 未配置 |
| 200 | 当前管理员未配置支付信息 | 易支付未配置 |
| 200 | 创建订单失败 | 订单写入失败 |
| 200 | 拉起支付失败 | 易支付 client 调用失败 |
