# 余额购买订阅
> `POST /api/subscription/balance/pay`
- **鉴权**：UserAuth（用户登录态）+ CriticalRateLimit
- **用途**：使用账户余额购买指定订阅计划。需管理员已确认支付合规。

## 请求
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| plan_id | int | 是 | 订阅计划 ID，须大于 0 |

示例：
```json
{ "plan_id": 1 }
```

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data | null | 购买成功 |

示例：
```json
{ "success": true, "message": "", "data": null }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | 支付合规声明未确认（MsgPaymentComplianceRequired） | 管理员未确认支付合规 |
| 200 | 参数错误 | 请求体解析失败或 plan_id 非法 |
| 200 | （model.PurchaseSubscriptionWithBalance 返回错误） | 余额不足、套餐不可用、超购买上限等 |
