# 订阅计划列表
> `GET /api/subscription/plans`
- **鉴权**：UserAuth（用户登录态）
- **用途**：获取所有启用的订阅计划，供用户浏览购买。需管理员已确认支付合规。

## 请求
无

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data | SubscriptionPlanDTO[] | 计划列表；未确认合规时返回空数组 |

SubscriptionPlanDTO：
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| plan | SubscriptionPlan | 计划详情（id、title、subtitle、price_amount、currency、duration_unit、duration_value、enabled、total_amount 等） |

示例：
```json
{
  "success": true,
  "message": "",
  "data": [
    { "plan": { "id": 1, "title": "月度套餐", "price_amount": 9.99, "currency": "USD", "enabled": true } }
  ]
}
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | 支付合规声明未确认（i18n: MsgPaymentComplianceRequired） | 管理员未确认支付合规时返回空列表（不报错） |
