# 当前用户订阅
> `GET /api/subscription/self`
- **鉴权**：UserAuth（用户登录态）
- **用途**：查询当前用户的计费偏好和全部订阅（含活跃与已过期）。

## 请求
无

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data.billing_preference | string | 计费偏好（经标准化） |
| data.subscriptions | SubscriptionSummary[] | 当前活跃订阅列表 |
| data.all_subscriptions | SubscriptionSummary[] | 全部订阅（含已过期） |

示例：
```json
{
  "success": true,
  "message": "",
  "data": {
    "billing_preference": "subscription",
    "subscriptions": [],
    "all_subscriptions": []
  }
}
```

## 错误码
无
