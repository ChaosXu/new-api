# 获取倍率配置

> `GET /api/ratio_config`

- **鉴权**：无登录鉴权；叠加 `CriticalRateLimit`（严格限流）
- **用途**：当管理员启用「对外暴露倍率配置」时，公开返回当前模型/补全/缓存/价格倍率配置，供前端或第三方展示定价依据。未启用时返回 403。

## 请求

无参数。

## 响应

启用时（HTTP 200），标准信封 `{success, message, data}`。`data` 由 `ratio_setting.GetExposedData()` 返回（30 秒缓存）：

| 字段 | 类型 | 说明 |
|---|---|---|
| model_ratio | object | 模型倍率映射（`{模型名: 倍率}`） |
| completion_ratio | object | 补全倍率映射 |
| cache_ratio | object | 缓存倍率映射 |
| create_cache_ratio | object | 创建缓存倍率映射 |
| model_price | object | 按次计费价格映射 |

```json
{
  "success": true,
  "message": "",
  "data": {
    "model_ratio": { "gpt-4o": 2.5 },
    "completion_ratio": { "gpt-4o": 4 },
    "cache_ratio": {},
    "create_cache_ratio": {},
    "model_price": {}
  }
}
```

## 错误码

| HTTP 状态 | 场景 | 说明 |
|---|---|---|
| 403 | 未启用对外暴露 | `success=false`，`message=倍率配置接口未启用` |

> 限流失败由 `CriticalRateLimit` 中间件处理（通常 429）。
