# 批量删除渠道

> `POST /api/channel/batch`

- **鉴权**：AdminAuth + RequirePermission(ChannelSensitiveWrite)
- **用途**：按 ID 列表批量删除渠道，可选按标签批量。

## 请求

请求体 JSON（`ChannelBatch`）：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| ids | int[] | 是 | 待删除渠道 ID 列表（非空） |
| tag | *string | 否 | 标签（可选） |

## 响应

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data | int | 实际删除数量 |

```json
{
  "success": true,
  "message": "",
  "data": 5
}
```

## 错误码

| 状态 | 说明 |
| --- | --- |
| 200(success=false) | 参数错误、删除失败 |
