# 检测所有上游更新

> `POST /api/channel/upstream_updates/detect_all`

- **鉴权**：AdminAuth + RequirePermission(ChannelOperate)
- **用途**：入队一个手动的 model_update 系统任务，对所有渠道批量检测上游模型更新。

## 请求

无。

## 响应

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| task_id | string | 系统任务 ID |
| status | string | 任务状态 |

```json
{
  "success": true,
  "message": "",
  "data": { "task_id": "t-2", "status": "pending" }
}
```

## 错误码

| 状态 | 说明 |
| --- | --- |
| 409 | 已有 model_update 任务在运行/等待中 |
| 200(success=false) | 入队失败 |
