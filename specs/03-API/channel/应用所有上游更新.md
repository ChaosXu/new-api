# 应用所有上游更新

> `POST /api/channel/upstream_updates/apply_all`

- **鉴权**：AdminAuth + RequirePermission(ChannelWrite)
- **用途**：对所有已开启上游模型更新检查、且有待处理变更的已启用渠道批量应用变更。

## 请求

无。

## 响应

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| processed_channels | int | 已处理渠道数 |
| added_models | int | 新增模型总数 |
| removed_models | int | 移除模型总数 |
| failed_channel_ids | int[] | 失败渠道 ID |
| results | object[] | 每个渠道的明细（channel_id/name/added/...） |

```json
{
  "success": true,
  "message": "",
  "data": { "processed_channels": 3, "added_models": 5, "removed_models": 1, "failed_channel_ids": [], "results": [] }
}
```

## 错误码

无（部分渠道失败会收集到 failed_channel_ids，不中断整体）。
