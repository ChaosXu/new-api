# 更新指定余额

> `GET /api/channel/update_balance/:id`

- **鉴权**：AdminAuth + RequirePermission(ChannelOperate)
- **用途**：更新单个渠道的余额（多密钥渠道不支持）。

## 请求

路径参数：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| id | int | 渠道 ID |

## 响应

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| balance | float64 | 更新后的余额（USD） |

```json
{
  "success": true,
  "message": "",
  "balance": 12.34
}
```

## 错误码

| 状态 | 说明 |
| --- | --- |
| 200(success=false) | 渠道不存在、多密钥渠道不支持、更新失败 |
