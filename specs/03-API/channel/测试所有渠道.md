# 测试所有渠道

> `GET /api/channel/test`

- **鉴权**：AdminAuth + RequirePermission(ChannelOperate)
- **用途**：触发一次全渠道测试的系统任务（异步执行，含通知）。

## 请求

无。

## 响应

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| task_id | string | 系统任务 ID |
| status | string | 任务状态 |

```json
{
  "success": true,
  "message": "",
  "data": { "task_id": "t-1", "status": "pending" }
}
```

## 错误码

| 状态 | 说明 |
| --- | --- |
| 409 | 已有渠道测试任务在运行/等待中 |
| 200(success=false) | 入队失败 |
