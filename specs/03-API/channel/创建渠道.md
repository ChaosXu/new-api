# 创建渠道

> `POST /api/channel/`

- **鉴权**：AdminAuth + RequirePermission(ChannelSensitiveWrite)
- **用途**：新建渠道，支持单条、多 key 合并、批量三种模式。

## 请求

请求体 JSON（`AddChannelRequest`）：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| mode | string | 是 | 添加模式：`single`/`multi_to_single`/`batch` |
| multi_key_mode | string | 否 | 多 key 模式（multi_to_single） |
| batch_add_set_key_prefix_2_name | bool | 否 | 批量模式下用 key 前缀追加到名称 |
| channel | Channel | 是 | 渠道对象（见 README 数据模型表） |

## 响应

```json
{
  "success": true,
  "message": ""
}
```

## 错误码

| 状态 | 说明 |
| --- | --- |
| 200(success=false) | 参数无效、不支持的添加模式、渠道校验失败（key/模型名/VertexAI 区域/Codex 凭证）、批量插入失败 |
