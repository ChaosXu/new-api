# 获取渠道详情

> `GET /api/channel/:id`

- **鉴权**：AdminAuth + RequirePermission(ChannelRead)
- **用途**：按 ID 获取单个渠道详情（敏感信息已脱敏，不含完整 key）。

## 请求

路径参数：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| id | int | 渠道 ID |

## 响应

返回单个 `Channel` 对象（见 README 数据模型表，key 已脱敏）。

```json
{
  "success": true,
  "message": "",
  "data": { "id": 1, "name": "OpenAI", "type": 1, "status": 1 }
}
```

## 错误码

| 状态 | 说明 |
| --- | --- |
| 200(success=false) | ID 无效、查询失败 |
