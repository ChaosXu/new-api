# 复制渠道

> `POST /api/channel/copy/:id`

- **鉴权**：AdminAuth + RequirePermission(ChannelSensitiveWrite)
- **用途**：克隆指定渠道（含密钥），可选追加名称后缀与重置余额。

## 请求

路径参数：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| id | int | 源渠道 ID |

Query 参数：

| 参数 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| suffix | string | `_复制` | 追加到原名称的后缀 |
| reset_balance | bool | true | 是否将余额与已用额度重置为 0 |

## 响应

返回新渠道 ID。

```json
{
  "success": true,
  "message": "",
  "data": { "id": 12 }
}
```

## 错误码

| 状态 | 说明 |
| --- | --- |
| 200(success=false) | ID 无效、获取/克隆失败 |
