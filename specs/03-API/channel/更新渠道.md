# 更新渠道

> `PUT /api/channel/`

- **鉴权**：AdminAuth + RequirePermission(ChannelWrite)（涉及敏感字段变更时要求 ChannelSensitiveWrite）
- **用途**：更新已存在渠道；不允许通过本接口修改 status。

## 请求

请求体 JSON（`PatchChannel`）：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| (Channel 字段) | 各类型 | 见 README 数据模型表，`status` 字段会被拒绝 |
| multi_key_mode | *string | 多 key 模式覆盖 |
| key_mode | *string | 多 key 模式下密钥处理：`append` 追加/覆盖 |

## 响应

```json
{
  "success": true,
  "message": ""
}
```

## 错误码

| 状态 | 说明 |
| --- | --- |
| 200(success=false) | 参数无效（含 status）、渠道校验失败、原渠道不存在、敏感变更权限不足、追加密钥解析失败、更新失败 |
| 403 | 权限不足（敏感变更但无 ChannelSensitiveWrite） |
