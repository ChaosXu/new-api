# 应用上游更新

> `POST /api/channel/upstream_updates/apply`

- **鉴权**：AdminAuth + RequirePermission(ChannelWrite)
- **用途**：对单个渠道应用上次检测到的上游模型变更（新增/移除/忽略）。

## 请求

请求体 JSON（`applyChannelUpstreamModelUpdatesRequest`）：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| id | int | 是 | 渠道 ID（>0） |
| add_models | []string | 否 | 待添加模型 |
| remove_models | []string | 否 | 待移除模型 |
| ignore_models | []string | 否 | 忽略模型 |

## 响应

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | int | 渠道 ID |
| added_models | []string | 实际新增 |
| removed_models | []string | 实际移除 |
| ignored_models | []string | 忽略列表 |
| remaining_models | []string | 剩余待添加 |
| remaining_remove_models | []string | 剩余待移除 |
| models | string | 应用后的 models 字段 |
| settings | string | 应用后的其他设置 |

```json
{
  "success": true,
  "message": "",
  "data": { "id": 1, "added_models": ["gpt-4o"], "removed_models": [] }
}
```

## 错误码

| 状态 | 说明 |
| --- | --- |
| 200(success=false) | id<=0、渠道不存在、应用失败 |
