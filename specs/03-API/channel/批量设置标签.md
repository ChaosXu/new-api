# 批量设置标签

> `POST /api/channel/batch/tag`

- **鉴权**：AdminAuth + RequirePermission(ChannelWrite)
- **用途**：为一批渠道设置标签（tag 为 nil 表示清除标签）。

## 请求

请求体 JSON（`ChannelBatch`）：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| ids | int[] | 是 | 渠道 ID 列表（非空） |
| tag | *string | 否 | 目标标签（nil 清除） |

## 响应

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data | int | 处理数量 |

```json
{
  "success": true,
  "message": "",
  "data": 5
}
```

## 错误码

| 状态 | 说明 |
| --- | --- |
| 200(success=false) | 参数错误（ids 为空）、设置失败 |
