# 删除渠道

> `DELETE /api/channel/:id`

- **鉴权**：AdminAuth + RequirePermission(ChannelSensitiveWrite)
- **用途**：删除单个渠道并刷新缓存。

## 请求

路径参数：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| id | int | 渠道 ID |

## 响应

```json
{
  "success": true,
  "message": ""
}
```

## 错误码

| 状态 | 说明 |
| --- | --- |
| 200(success=false) | 删除失败 |
