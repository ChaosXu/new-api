# 批量更新状态

> `POST /api/channel/status/batch`

- **鉴权**：AdminAuth + RequirePermission(ChannelOperate)
- **用途**：批量启用或手动禁用多个渠道。

## 请求

请求体 JSON（`ChannelStatusBatchRequest`）：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| ids | int[] | 是 | 渠道 ID 列表（非空） |
| status | int | 是 | `1` 启用 / `2` 手动禁用 |

## 响应

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data | int | 实际变更数量 |

```json
{
  "success": true,
  "message": "",
  "data": 4
}
```

## 错误码

| 状态 | 说明 |
| --- | --- |
| 200(success=false) | 参数无效（ids 为空或 status 非法） |
