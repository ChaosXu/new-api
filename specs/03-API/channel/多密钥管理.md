# 多密钥管理

> `POST /api/channel/multi_key/manage`

- **鉴权**：AdminAuth + RequirePermission(ChannelOperate)（disable_key/delete_key/delete_disabled_keys 等敏感动作需 ChannelSensitiveWrite）
- **用途**：对多密钥渠道执行密钥状态查询、启用/禁用/删除等管理操作。

## 请求

请求体 JSON（`MultiKeyManageRequest`）：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| channel_id | int | 是 | 多密钥渠道 ID |
| action | string | 是 | `get_key_status`/`disable_key`/`enable_key`/`delete_key`/`delete_disabled_keys` |
| key_index | *int | 视动作 | disable/enable/delete 指定的密钥索引 |
| page | int | 否 | get_key_status 分页页码 |
| page_size | int | 否 | get_key_status 每页数量（默认 50） |
| status | *int | 否 | get_key_status 状态过滤：1启用/2手动禁用/3自动禁用 |

## 响应

`get_key_status` 返回（`MultiKeyStatusResponse`）：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| keys | KeyStatus[] | 当前页密钥状态 |
| total | int | 过滤后总数 |
| page / page_size / total_pages | int | 分页信息 |
| enabled_count | int | 启用总数 |
| manual_disabled_count | int | 手动禁用总数 |
| auto_disabled_count | int | 自动禁用总数 |

其他动作返回：

```json
{ "success": true, "message": "密钥已禁用" }
```

## 错误码

| 状态 | 说明 |
| --- | --- |
| 200(success=false) | 渠道不存在、非多密钥模式、密钥索引未指定/越界、参数无效 |
| 403 | 敏感动作但无 ChannelSensitiveWrite |
