# 标签下模型

> `GET /api/channel/tag/models`

- **鉴权**：AdminAuth + RequirePermission(ChannelRead)
- **用途**：返回指定标签下模型数量最多的渠道的 models 字符串（用于标签级模型预览）。

## 请求

Query 参数：

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| tag | string | 是 | 标签名 |

## 响应

返回该标签下模型列表最长的 `models` 字符串（逗号分隔）。

```json
{
  "success": true,
  "message": "",
  "data": "gpt-4o,gpt-4o-mini,claude-3-5-sonnet"
}
```

## 错误码

| 状态 | 说明 |
| --- | --- |
| 400 | tag 不能为空 |
| 500 | 查询失败 |
