# 修复渠道能力

> `POST /api/channel/fix`

- **鉴权**：AdminAuth + RequirePermission(ChannelOperate)
- **用途**：扫描并修复渠道能力（abilities）表，使其与渠道实际模型配置一致。

## 请求

无。

## 响应

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| success | int | 成功修复数量 |
| fails | int | 失败数量 |

```json
{
  "success": true,
  "message": "",
  "data": { "success": 120, "fails": 0 }
}
```

## 错误码

| 状态 | 说明 |
| --- | --- |
| 200(success=false) | 修复失败 |
