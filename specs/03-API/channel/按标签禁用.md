# 按标签禁用

> `POST /api/channel/tag/disabled`

- **鉴权**：AdminAuth + RequirePermission(ChannelOperate)
- **用途**：禁用指定标签下的全部渠道。

## 请求

请求体 JSON（`ChannelTag`，仅需 tag）：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| tag | string | 是 | 标签名 |

## 响应

```json
{
  "success": true,
  "message": ""
}
```

## 错误码

| 状态 | 说明 |
| --- | --- |
| 200(success=false) | 参数错误（tag 为空）、禁用失败 |
