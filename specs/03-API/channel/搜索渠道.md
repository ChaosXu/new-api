# 搜索渠道

> `GET /api/channel/search`

- **鉴权**：AdminAuth + RequirePermission(ChannelRead)
- **用途**：按关键字、分组、模型关键字、状态搜索渠道。

## 请求

Query 参数：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| keyword | string | 名称/id 关键字 |
| group | string | 分组过滤 |
| model | string | 模型关键字 |
| status | string | 状态过滤：`1`/`0`/`-1` |
| id_sort | bool | 按 ID 倒序 |
| sort_by | string | 排序字段 |
| sort_order | string | `asc`/`desc` |
| tag_mode | bool | 标签分组模式 |

## 响应

返回渠道数组（不含 key）。

```json
{
  "success": true,
  "message": "",
  "data": [ { "id": 1, "name": "OpenAI", "type": 1 } ]
}
```

## 错误码

| 状态 | 说明 |
| --- | --- |
| 200(success=false) | 搜索失败 |
