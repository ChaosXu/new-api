# 渠道列表

> `GET /api/channel/`

- **鉴权**：AdminAuth + RequirePermission(ChannelRead)
- **用途**：分页查询渠道列表，支持标签分组、分组、状态、类型过滤与排序。

## 请求

Query 参数：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| p | int | 页码 |
| page_size | int | 每页数量 |
| sort_by | string | 排序字段：id/name/priority/balance/response_time/test_time |
| sort_order | string | `asc` 或 `desc` |
| id_sort | bool | 是否按 ID 倒序（兼容旧参数） |
| tag_mode | bool | 标签分组模式：按 tag 聚合返回 |
| group | string | 分组过滤 |
| status | string | 状态过滤：`1` 启用、`0` 禁用、`-1`/空 全部 |
| type | int | 渠道类型过滤 |

## 响应

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| items | Channel[] | 渠道数组（不含 key 字段） |
| total | int64 | 总数 |
| page | int | 当前页 |
| page_size | int | 每页数量 |
| type_counts | map<int,int64> | 按类型统计的数量 |

```json
{
  "success": true,
  "message": "",
  "data": {
    "items": [ { "id": 1, "name": "OpenAI", "type": 1, "status": 1 } ],
    "total": 100,
    "page": 1,
    "page_size": 10,
    "type_counts": { "1": 80, "14": 20 }
  }
}
```

## 错误码

| 状态 | 说明 |
| --- | --- |
| 200(success=false) | 查询失败（标签/数量/列表/类型统计） |
