# 检测上游更新

> `POST /api/channel/upstream_updates/detect`

- **鉴权**：AdminAuth + RequirePermission(ChannelOperate)
- **用途**：检测单个渠道相对上游的模型变更（新增/移除），并持久化检测结果。

## 请求

请求体 JSON（`applyChannelUpstreamModelUpdatesRequest`，主要使用 id）：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| id | int | 是 | 渠道 ID（>0） |

## 响应

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| channel_id | int | 渠道 ID |
| channel_name | string | 渠道名称 |
| add_models | []string | 待新增模型 |
| remove_models | []string | 待移除模型 |
| last_check_time | int64 | 上次检测时间 |
| auto_added_models | int | 本次自动新增数量 |

```json
{
  "success": true,
  "message": "",
  "data": { "channel_id": 1, "channel_name": "OpenAI", "add_models": ["gpt-4o"], "remove_models": [], "last_check_time": 0, "auto_added_models": 0 }
}
```

## 错误码

| 状态 | 说明 |
| --- | --- |
| 200(success=false) | id<=0、渠道不存在、检测失败 |
