# 删除已禁用渠道

> `DELETE /api/channel/disabled`

- **鉴权**：AdminAuth + RequirePermission(ChannelSensitiveWrite)
- **用途**：一次性删除所有处于禁用状态的渠道。

## 请求

无。

## 响应

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data | int64 | 删除行数 |

```json
{
  "success": true,
  "message": "",
  "data": 3
}
```

## 错误码

| 状态 | 说明 |
| --- | --- |
| 200(success=false) | 删除失败 |
