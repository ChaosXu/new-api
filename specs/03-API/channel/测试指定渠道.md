# 测试指定渠道

> `GET /api/channel/test/:id`

- **鉴权**：AdminAuth + RequirePermission(ChannelOperate)
- **用途**：同步测试单个渠道的可用性，并更新响应时间。

## 请求

路径参数：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| id | int | 渠道 ID |

Query 参数：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| model | string | 指定测试模型 |
| endpoint_type | string | 测试端点类型 |
| stream | bool | 是否流式测试 |

## 响应

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| time | float | 耗时（秒） |
| error_code | string | 失败时返回错误码（可选） |

```json
{
  "success": true,
  "message": "",
  "time": 0.85
}
```

## 错误码

| 状态 | 说明 |
| --- | --- |
| 200(success=false) | 渠道不存在、测试失败（message 含错误，time 可能为 0） |
