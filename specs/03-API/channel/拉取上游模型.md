# 拉取上游模型

> `GET /api/channel/fetch_models/:id`

- **鉴权**：AdminAuth + RequirePermission(ChannelOperate)
- **用途**：从已保存渠道的上游拉取可用模型 ID 列表。

## 请求

路径参数：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| id | int | 渠道 ID |

## 响应

返回上游模型 ID 数组。

```json
{
  "success": true,
  "message": "",
  "data": ["gpt-4o", "gpt-4o-mini"]
}
```

## 错误码

| 状态 | 说明 |
| --- | --- |
| 200(success=false) | ID 无效、获取模型列表失败 |
