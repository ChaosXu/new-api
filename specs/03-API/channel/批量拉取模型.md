# 批量拉取模型

> `POST /api/channel/fetch_models`

- **鉴权**：AdminAuth + RequirePermission(ChannelSensitiveWrite)
- **用途**：基于临时输入（类型/key/base_url 等）预览上游模型列表，无需先保存渠道；支持高级自定义渠道预览。

## 请求

请求体 JSON（`fetchModelsRequest`）：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| channel_id | int | 已保存渠道 ID（>0 时按该渠道预览，且须为高级自定义） |
| type | int | 渠道类型（channel_id<=0 时使用） |
| key | string | 密钥 |
| base_url | *string | 自定义 base_url |
| advanced_custom | *string | 高级自定义配置 JSON |
| header_override | *string | 请求头覆盖 JSON |
| proxy | *string | 代理地址 |

## 响应

返回上游模型 ID 数组。

```json
{
  "success": true,
  "message": "",
  "data": ["gpt-4o", "gpt-4o-mini"]
}
```

## 错误码

| 状态 | 说明 |
| --- | --- |
| 400 | 请求无效 |
| 200(success=false) | 高级自定义配置缺失/无效、获取模型列表失败 |
