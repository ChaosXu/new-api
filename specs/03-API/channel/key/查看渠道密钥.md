# 查看渠道密钥

> `POST /api/channel/:id/key`

- **鉴权**：AdminAuth + RootAuth + SecureVerification（需通过安全验证）
- **用途**：在通过安全验证后，查看渠道完整密钥（高危操作，记录审计日志）。

## 请求

路径参数：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| id | int | 渠道 ID |

请求头：

| Header | 说明 |
| --- | --- |
| X-Security-Proof | 安全验证凭据（由安全验证中间件校验） |

## 响应

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| key | string | 渠道完整密钥 |

```json
{
  "success": true,
  "message": "获取成功",
  "data": {
    "key": "sk-xxxxx"
  }
}
```

## 错误码

未通过安全验证中间件时返回 403，error_code 取值：

| error_code | 说明 |
| --- | --- |
| SECURITY_PROOF_REQUIRED | 需要安全验证 |
| SECURITY_PROOF_INVALID | 安全验证状态无效 |
| SECURITY_PROOF_EXPIRED | 安全验证已过期 |
| SECURITY_PROOF_SCOPE_MISMATCH | 安全验证范围不匹配 |
| SECURITY_PROOF_METHOD_MISMATCH | 安全验证方式不匹配 |

业务错误：

| 状态 | 说明 |
| --- | --- |
| 200(success=false) | 渠道 ID 格式错误、渠道不存在 |
