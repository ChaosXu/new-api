# 编辑渠道标签

> `PUT /api/channel/tag`

- **鉴权**：AdminAuth + RequirePermission(ChannelWrite)（修改 param_override / header_override 需 ChannelSensitiveWrite）
- **用途**：按标签批量编辑该标签下渠道的模型映射、模型、分组、优先级、权重、参数/请求头覆盖等。

## 请求

请求体 JSON（`ChannelTag`）：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| tag | string | 必填，目标标签 |
| new_tag | *string | 重命名后的新标签 |
| priority | *int64 | 优先级 |
| weight | *uint | 权重 |
| model_mapping | *string | 模型映射 JSON |
| models | *string | 模型列表 |
| groups | *string | 分组 |
| param_override | *string | 参数覆盖 JSON（敏感） |
| header_override | *string | 请求头覆盖 JSON（敏感） |

## 响应

```json
{
  "success": true,
  "message": ""
}
```

## 错误码

| 状态 | 说明 |
| --- | --- |
| 200(success=false) | 参数错误、tag 为空、param/header override 非合法 JSON、更新失败 |
| 403 | 敏感字段变更但无 ChannelSensitiveWrite |
