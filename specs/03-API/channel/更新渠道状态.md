# 更新渠道状态

> `POST /api/channel/:id/status`

- **鉴权**：AdminAuth + RequirePermission(ChannelOperate)
- **用途**：手动启用或禁用单个渠道（仅允许启用或手动禁用两个状态）。

## 请求

路径参数：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| id | int | 渠道 ID |

请求体 JSON（`ChannelStatusRequest`）：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| status | int | 是 | `1` 启用 / `2` 手动禁用 |

## 响应

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data | bool | 状态是否实际变更 |

```json
{
  "success": true,
  "message": "",
  "data": true
}
```

## 错误码

| 状态 | 说明 |
| --- | --- |
| 200(success=false) | 参数无效（status 非法） |
