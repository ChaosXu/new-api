# 微信登录

> `GET /api/oauth/wechat`

- **鉴权**：无
- **用途**：通过微信授权 code 完成登录或注册。

## 请求

Query 参数：

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| code | string | 是 | 微信授权 code，交由配置的 WeChatServerAddress 兑换 openid |

## 响应

登录成功后建立会话，返回当前用户信息。

```json
{
  "success": true,
  "message": "",
  "data": { }
}
```

## 错误码

| 状态 | 说明 |
| --- | --- |
| 200(success=false) | 管理员未开启微信登录、code 无效/过期、用户已注销、注册已关闭、用户被封禁、该微信账号已被绑定 |
