# 管理员查看用户绑定

> `GET /api/user/:id/oauth/bindings`

- **鉴权**：AdminAuth（需具备管理目标用户角色的权限）
- **用途**：管理员查看指定用户的自定义 OAuth 绑定列表。

## 请求

路径参数：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| id | int | 目标用户 ID |

## 响应

结构与「查询已绑定第三方账号」一致。

```json
{
  "success": true,
  "message": "",
  "data": [
    {
      "provider_id": 1,
      "provider_name": "My SSO",
      "provider_slug": "my-sso",
      "provider_icon": "",
      "provider_user_id": "u-123"
    }
  ]
}
```

## 错误码

| 状态 | 说明 |
| --- | --- |
| 200(success=false) | 用户 ID 无效、无权限管理目标用户 |
