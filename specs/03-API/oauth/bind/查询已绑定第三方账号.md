# 查询已绑定第三方账号

> `GET /api/user/oauth/bindings`

- **鉴权**：UserAuth（当前用户）
- **用途**：返回当前登录用户已绑定的自定义 OAuth 提供商列表。

## 请求

无。

## 响应

返回数组，元素结构：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| provider_id | int | 提供商 ID |
| provider_name | string | 提供商名称 |
| provider_slug | string | 提供商 slug |
| provider_icon | string | 提供商图标 |
| provider_user_id | string | 该提供商侧的用户 ID |

```json
{
  "success": true,
  "message": "",
  "data": [
    {
      "provider_id": 1,
      "provider_name": "My SSO",
      "provider_slug": "my-sso",
      "provider_icon": "",
      "provider_user_id": "u-123"
    }
  ]
}
```

## 错误码

| 状态 | 说明 |
| --- | --- |
| 200(success=false) | 未登录 |
