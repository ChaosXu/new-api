# 绑定微信

> `POST /api/oauth/wechat/bind`

- **鉴权**：UserAuth（已登录用户）
- **用途**：将微信账号绑定到当前登录用户。

## 请求

请求体 JSON：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| code | string | 是 | 微信授权 code，用于兑换 openid |

## 响应

```json
{
  "success": true,
  "message": ""
}
```

## 错误码

| 状态 | 说明 |
| --- | --- |
| 401 | 未登录 |
| 200(success=false) | 管理员未开启微信登录、code 无效/过期、该微信账号已被绑定 |
