# 绑定邮箱

> `POST /api/oauth/email/bind`

- **鉴权**：UserAuth（已登录用户）
- **用途**：为当前登录用户绑定邮箱，需校验邮箱验证码。

## 请求

请求体 JSON：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| email | string | 是 | 待绑定邮箱（会归一化） |
| code | string | 是 | 邮箱验证码 |

## 响应

```json
{
  "success": true,
  "message": ""
}
```

## 错误码

| 状态 | 说明 |
| --- | --- |
| 400 | 请求体无效 |
| 401 | 未登录 |
| 200(success=false) | 验证码错误、邮箱已被占用 |
