# 管理员清除用户绑定

> `DELETE /api/user/:id/bindings/:binding_type`

- **鉴权**：`AdminAuth`（需具备管理目标用户角色的权限）
- **用途**：管理员按绑定类型（binding_type）清除指定用户的某种第三方/邮箱绑定，将对应标识列置空。与「管理员解绑用户账号」不同：后者按自定义 OAuth `provider_id` 解绑，本端点按**内置绑定类型**清空。

## 请求

路径参数：

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| id | int | 是 | 目标用户 ID |
| binding_type | string | 是 | 绑定类型，取值：`email`、`github`、`discord`、`oidc`、`wechat`、`telegram`、`linuxdo` |

无请求体。

## 响应

```json
{
  "success": true,
  "message": "success"
}
```

## 错误码

| 场景 | message | 说明 |
|---|---|---|
| `id` 非数字 或 `binding_type` 为空 | `msg_invalid_params` | 路径参数校验失败 |
| 用户不存在 | DB 错误字符串 | `model.GetUserById` 失败 |
| 权限不足 | `msg_user_no_permission_same_level` | 调用方角色数值不高于目标用户角色（`canManageTargetRole` 校验） |
| 绑定类型非法 | `invalid binding type` | `binding_type` 不在允许集合内 |

> 成功后记录管理审计事件 `user.binding_clear`，含 `bindingType` 与目标 `username`。若清除的是 `telegram` 绑定，同时释放对应的外部身份记录（`ReleaseExternalIdentity`）。
