# 解绑第三方账号

> `DELETE /api/user/oauth/bindings/:provider_id`

- **鉴权**：UserAuth（当前用户）
- **用途**：当前用户解绑指定的自定义 OAuth 提供商。

## 请求

路径参数：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| provider_id | int | 提供商 ID |

## 响应

```json
{
  "success": true,
  "message": "解绑成功"
}
```

## 错误码

| 状态 | 说明 |
| --- | --- |
| 200(success=false) | 未登录、提供商 ID 无效 |
