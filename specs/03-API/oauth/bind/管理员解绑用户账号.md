# 管理员解绑用户账号

> `DELETE /api/user/:id/oauth/bindings/:provider_id`

- **鉴权**：AdminAuth（需具备管理目标用户角色的权限）
- **用途**：管理员解绑指定用户的自定义 OAuth 提供商。

## 请求

路径参数：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| id | int | 目标用户 ID |
| provider_id | int | 提供商 ID |

## 响应

```json
{
  "success": true,
  "message": "success"
}
```

## 错误码

| 状态 | 说明 |
| --- | --- |
| 200(success=false) | 用户/提供商 ID 无效、无权限管理目标用户 |
