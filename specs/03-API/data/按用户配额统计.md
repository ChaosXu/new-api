# 按用户配额统计
> `GET /api/data/users`
- **鉴权**：AdminAuth（管理员）
- **用途**：按时间范围查询额度消耗，按用户分组聚合。

## 请求
Query 参数：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| start_timestamp | int64 | 否 | 起始时间戳（秒） |
| end_timestamp | int64 | 否 | 结束时间戳（秒） |

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data | object[] | 按用户分组的额度统计 |

示例：
```json
{ "success": true, "message": "", "data": [] }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | （错误信息） | 查询失败 |
