# 全局流量配额
> `GET /api/data/flow`
- **鉴权**：AdminAuth（管理员）
- **用途**：按时间范围（必填）与用户名查询全局流量额度统计。

## 请求
Query 参数：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| start_timestamp | int64 | 是 | 起始时间戳（秒，须 >0） |
| end_timestamp | int64 | 是 | 结束时间戳（秒，须 >0 且 ≥ start） |
| username | string | 否 | 用户名筛选 |

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data | object[] | 流量额度统计 |

示例：
```json
{ "success": true, "message": "", "data": [] }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | invalid start_timestamp / invalid end_timestamp / invalid time range | 时间参数非法 |
| 200 | （错误信息） | 查询失败 |
