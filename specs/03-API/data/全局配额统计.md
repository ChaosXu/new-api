# 全局配额统计
> `GET /api/data/`
- **鉴权**：AdminAuth（管理员）
- **用途**：按时间范围与用户名查询全局额度消耗按日统计。

## 请求
Query 参数：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| start_timestamp | int64 | 否 | 起始时间戳（秒） |
| end_timestamp | int64 | 否 | 结束时间戳（秒） |
| username | string | 否 | 用户名筛选 |

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data | object[] | 按日额度统计 |

示例：
```json
{ "success": true, "message": "", "data": [] }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | （错误信息） | 查询失败 |
