# 用户配额统计
> `GET /api/data/self`
- **鉴权**：UserAuth（用户登录态）
- **用途**：查询当前用户在时间范围内的按日额度统计（跨度不超过 1 个月）。

## 请求
Query 参数：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| start_timestamp | int64 | 否 | 起始时间戳（秒） |
| end_timestamp | int64 | 否 | 结束时间戳（秒） |

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data | object[] | 当前用户按日额度统计 |

示例：
```json
{ "success": true, "message": "", "data": [] }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | 时间跨度不能超过 1 个月 | 时间范围 > 2592000 秒 |
| 200 | （错误信息） | 查询失败 |
