# 用户流量配额
> `GET /api/data/flow/self`
- **鉴权**：UserAuth（用户登录态）
- **用途**：查询当前用户在时间范围内的流量额度统计（跨度不超过 1 个月）。

## 请求
Query 参数：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| start_timestamp | int64 | 是 | 起始时间戳（秒，须 >0） |
| end_timestamp | int64 | 是 | 结束时间戳（秒，须 >0 且 ≥ start） |

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data | object[] | 当前用户流量额度统计 |

示例：
```json
{ "success": true, "message": "", "data": [] }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | invalid start_timestamp / invalid end_timestamp / invalid time range | 时间参数非法 |
| 200 | 时间跨度不能超过 1 个月 | 时间范围 > 2592000 秒 |
| 200 | （错误信息） | 查询失败 |
