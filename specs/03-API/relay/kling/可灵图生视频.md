# 可灵图生视频
> `POST /kling/v1/videos/image2video`
- **鉴权**：KlingRequestConvert + TokenAuth + Distribute
- **用途**：提交可灵图生视频任务。`KlingRequestConvert` 检测到 `image` 字段后保持默认 action（图生视频），并转换为统一入参。

## 请求
可灵官方风格请求体：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `model_name` / `model` | string | 是 | 可灵模型 ID |
| `prompt` | string | 否 | 文本提示词 |
| `image` | string | 是 | 源图（URL 或 Base64），触发图生视频判定 |
| `duration` / `width` / `height` / `fps` / `seed` | - | 否 | 规格（透传到 metadata） |
| 其他厂商参数 | any | 否 | 原样保留到 `metadata` |

## 响应
`VideoResponse`：`{task_id, status}`。
