# 查询可灵图生视频
> `GET /kling/v1/videos/image2video/:task_id`
- **鉴权**：KlingRequestConvert + TokenAuth + Distribute
- **用途**：查询可灵图生视频任务状态，走 `RelayTaskFetch`。

## 请求
路径参数：

| 参数 | 位置 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| `task_id` | path | string | 是 | 任务 ID |

## 响应
`VideoTaskResponse`：`{task_id, status, url, format, metadata, error}`，字段同查询文生视频。

## 错误
见 README 任务型错误。
