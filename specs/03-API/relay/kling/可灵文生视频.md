# 可灵文生视频
> `POST /kling/v1/videos/text2video`
- **鉴权**：KlingRequestConvert + TokenAuth + Distribute
- **用途**：提交可灵文生视频任务。`KlingRequestConvert` 将可灵风格请求转换为统一 `/v1/video/generations` 入参，并由 `RelayTask` 分发。

## 请求
可灵官方风格请求体（适配器会读取以下字段）：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `model_name` / `model` | string | 是 | 可灵模型 ID |
| `prompt` | string | 是 | 文本提示词 |
| `duration` / `width` / `height` / `fps` / `seed` / `n` | - | 否 | 规格（透传到 metadata） |
| 其他厂商参数 | any | 否 | 原样保留到 `metadata` |

> 注意：本端点不应传 `image`，否则会被判为图生视频。

## 响应
`VideoResponse`：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `task_id` | string | 任务 ID |
| `status` | string | 提交状态 |

## 错误
见 README。请求体无法解析时适配器放行 `c.Next()`，由后续校验返回错误。
