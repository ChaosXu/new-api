# 即梦任务
> `POST /jimeng/`
- **鉴权**：JimengRequestConvert + TokenAuth + Distribute
- **用途**：即梦官方风格入口，通过 query `Action` 区分提交与查询。`JimengRequestConvert` 将其转换为统一视频流程后由 `RelayTask` / `RelayTaskFetch` 处理。

## 请求
Query 参数：

| 参数 | 位置 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| `Action` | query | string | 是 | `CVSync2AsyncSubmitTask`（提交）或 `CVSync2AsyncGetResult`（查询） |
| `Version` | query | string | 否 | API 版本（如 `2022-08-31`，透传） |

### 提交（Action=CVSync2AsyncSubmitTask）
请求体（即梦官方字段，`req_key` 映射为 `model`）：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `req_key` | string | 是 | 即梦模型 key → 转换为统一 `model` |
| `prompt` | string | 否 | 提示词 |
| `image` | string | 否 | 源图（图生视频），无则文生视频 |
| 其他参数 | any | 否 | 原样保留到 `metadata` |

### 查询（Action=CVSync2AsyncGetResult）
请求体：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `task_id` | string | 是 | 待查询的任务 ID（缺失返回 400） |

示例（提交）：
```
POST /jimeng/?Action=CVSync2AsyncSubmitTask&Version=2022-08-31
{ "req_key": "luma_video", "prompt": "一只奔跑的猫" }
```

## 响应
- 提交：`VideoResponse`：`{task_id, status}`。
- 查询：`VideoTaskResponse`：`{task_id, status, url, format, metadata, error}`。

## 错误
- 适配器阶段（`Action` 缺失 / body 非法 / 查询缺 `task_id`）：
```json
{ "error": { "message": "Action query parameter is required", "type": "invalid_request_error" } }
```
HTTP 400。
- 任务阶段：`dto.TaskError`，见 README。
