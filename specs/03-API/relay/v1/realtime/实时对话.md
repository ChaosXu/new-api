# 实时对话
> `GET /v1/realtime`
- **鉴权**：TokenAuth + ModelRequestRateLimit + Distribute
- **用途**：OpenAI Realtime API 的 WebSocket 入口，子协议 `realtime`。RelayFormat=OpenAIRealtime。

## 请求
WebSocket 握手（Upgrade）。URL query 需带 `model`。握手必须声明子协议 `realtime`，鉴权使用 `Authorization: Bearer sk-xxx`（或 query 参数）。

握手成功后双向收发 Realtime 事件（JSON）。核心事件类型：
| 事件 | 方向 | 说明 |
| --- | --- | --- |
| session.update / session.updated | 双向 | 会话配置/确认 |
| conversation.item.create / .created | 双向 | 新增会话项 |
| response.create / response.done | 双向 | 触发/完成响应 |
| input_audio_buffer.append | 上行 | 追加音频 |
| response.audio.delta | 下行 | 音频增量 |
| response.audio_transcript.delta | 下行 | 转写增量 |
| response.function_call_arguments.delta/.done | 下行 | 函数调用参数 |
| error | 下行 | 错误 |

RealtimeSession 配置含：`modalities`/`instructions`/`voice`/`input_audio_format`/`output_audio_format`/`input_audio_transcription`/`turn_detection`/`tools`/`tool_choice`/`temperature`。

## 响应
WebSocket 文本帧，遵循 OpenAI Realtime 事件规范。usage 在 `response.done` 中通过 `response.usage` 返回（`input_tokens`/`output_tokens`/`total_tokens` 及明细）。

## 错误
WebSocket 错误事件（OpenAI 错误对象）：
```json
{ "type": "error", "error": { "message": "...", "type": "...", "code": "..." } }
```
