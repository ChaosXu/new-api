# 重排序
> `POST /v1/rerank`
- **鉴权**：TokenAuth + ModelRequestRateLimit + Distribute
- **用途**：Cohere 风格的文档重排序，RelayFormat=Rerank。

## 请求
遵循 Cohere Rerank 原生规范。核心字段：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| model | string | 是 | 模型名 |
| query | string | 是 | 查询文本 |
| documents | array | 是 | 待排序文档列表 |
| top_n | int | 否 | 返回前 N 条 |
| return_documents | bool | 否 | 是否返回文档内容 |
| max_chunk_per_doc | int | 否 | 每文档最大分块 |
| overlap_tokens | int | 否 | 分块重叠 token |

## 响应
遵循 Cohere 原生规范。
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| results | array | 排序结果，含 `index`/`relevance_score`/`document` |
| usage | object | `prompt_tokens`/`total_tokens` |

## 错误
```json
{ "error": { "message": "...", "type": "invalid_request_error", "param": "", "code": "..." } }
```
