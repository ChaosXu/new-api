# 模型列表
> `GET /v1/models`
- **鉴权**：TokenAuth（API 令牌 sk-xxx）
- **用途**：列出当前分组/令牌可用模型。按请求头自动分流为 OpenAI / Anthropic / Gemini 协议格式。

## 请求
按请求头分流：
| 条件 | 返回格式 |
| --- | --- |
| 带 `x-api-key` + `anthropic-version` | Anthropic `/v1/models` 格式 |
| 带 `x-goog-api-key` 或 query `key` | Gemini `models` 格式 |
| 其他（默认） | OpenAI `data:[]` 格式 |

无请求体；鉴权使用标准 `Authorization: Bearer sk-xxx`（或上述各家 header）。

## 响应
原生格式（遵循 OpenAI / Anthropic / Gemini 各自规范）。OpenAI 格式核心字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| object | string | 固定 `list` |
| data | array | 模型对象列表 |

模型对象：
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | string | 模型名 |
| object | string | 固定 `model` |
| owned_by | string | 归属（分组所有者） |

> 仅返回当前用户分组启用、且已配置计费比例的模型；令牌若启用模型限制，则进一步过滤。

## 错误
OpenAI 格式：
```json
{ "error": { "message": "...", "type": "...", "code": "..." } }
```
