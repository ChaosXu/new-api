# 获取模型详情
> `GET /v1/models/:model`
- **鉴权**：TokenAuth（API 令牌 sk-xxx）
- **用途**：查询单个模型详情。按请求头分流为 OpenAI / Anthropic 格式。

## 请求
Path 参数：
| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| model | string | 是 | 模型名 |

请求头分流：
| 条件 | 返回格式 |
| --- | --- |
| 带 `x-api-key` + `anthropic-version` | Anthropic 模型对象 |
| 其他 | OpenAI 模型对象 |

## 响应
遵循 OpenAI / Anthropic 原生规范。OpenAI 格式：
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | string | 模型名 |
| object | string | 固定 `model` |
| owned_by | string | 归属 |

## 错误
```json
{ "error": { "message": "The model 'xxx' does not exist", "type": "invalid_request_error", "param": "model", "code": "model_not_found" } }
```
