# 内容审核
> `POST /v1/moderations`
- **鉴权**：TokenAuth + ModelRequestRateLimit + Distribute
- **用途**：调用上游内容审核接口，RelayFormat=OpenAI。

## 请求
遵循 OpenAI Moderations 原生规范。核心字段：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| model | string | 否 | 审核模型（默认 `text-moderation-latest` 等） |
| input | any | 是 | 字符串或字符串数组 |

## 响应
遵循 OpenAI 原生规范。
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | string | 响应 ID |
| model | string | 审核模型 |
| results | array | 含 `flagged` 与各分类 `categories`/`category_scores` |

## 错误
```json
{ "error": { "message": "...", "type": "invalid_request_error", "param": "", "code": "..." } }
```
