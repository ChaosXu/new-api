# 文本补全
> `POST /v1/completions`
- **鉴权**：TokenAuth + ModelRequestRateLimit + Distribute
- **用途**：OpenAI 传统文本补全（非 chat），RelayFormat=OpenAI。

## 请求
遵循 OpenAI Completions 原生规范。核心字段：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| model | string | 是 | 模型名 |
| prompt | any | 是 | 字符串或字符串数组 |
| stream | bool | 否 | 是否流式 |
| max_tokens | uint | 否 | 最大输出 token |
| temperature | float | 否 | 采样温度 |
| top_p | float | 否 | nucleus 采样 |
| n | int | 否 | 生成数量 |
| stop | any | 否 | 停止序列 |
| suffix | string | 否 | 后缀补全 |
| logprobs / echo | - | 否 | 对数概率/回显 |

## 响应
遵循 OpenAI 原生规范。
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | string | 响应 ID |
| object | string | `text_completion` |
| choices | array | 含 `text`、`finish_reason` |
| usage | object | `prompt_tokens`/`completion_tokens`/`total_tokens` |

## 错误
```json
{ "error": { "message": "...", "type": "invalid_request_error", "param": "", "code": "..." } }
```
