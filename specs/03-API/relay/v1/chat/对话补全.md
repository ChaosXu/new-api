# 对话补全
> `POST /v1/chat/completions`
- **鉴权**：TokenAuth + ModelRequestRateLimit + Distribute
- **用途**：OpenAI 对话补全，请求体遵循 OpenAI 原生规范（RelayFormat=OpenAI）。

## 请求
遵循 OpenAI Chat Completions 原生规范。核心字段：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| model | string | 是 | 模型名 |
| messages | array | 是 | 消息列表，元素含 `role`/`content`/`name`/`tool_calls`/`tool_call_id` |
| stream | bool | 否 | 是否流式（SSE） |
| stream_options | object | 否 | 含 `include_usage` |
| max_tokens / max_completion_tokens | uint | 否 | 最大输出 token |
| temperature | float | 否 | 采样温度 |
| top_p | float | 否 | nucleus 采样 |
| top_k | int | 否 | top-k 采样 |
| stop | any | 否 | 停止序列 |
| n | int | 否 | 生成数量 |
| tools | array | 否 | 工具列表（function 等） |
| tool_choice | any | 否 | 工具选择策略 |
| parallel_tool_calls | bool | 否 | 并行工具调用 |
| response_format | object | 否 | 输出格式（json_object/json_schema） |
| reasoning_effort | string | 否 | 推理强度（o 系列/gpt-5） |
| frequency_penalty / presence_penalty | float | 否 | 惩罚项 |
| seed | float | 否 | 随机种子 |
| logprobs / top_logprobs | - | 否 | 对数概率 |
| modalities / audio | any | 否 | 多模态/音频输出 |
| user | any | 否 | 用户标识 |

消息 content 支持多模态数组：`text` / `image_url` / `input_audio` / `file` / `video_url`。

## 响应
遵循 OpenAI 原生规范。
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | string | 响应 ID |
| object | string | `chat.completion` / 流式 `chat.completion.chunk` |
| choices | array | 含 `message`/`delta`、`finish_reason` |
| usage | object | `prompt_tokens`/`completion_tokens`/`total_tokens` |

流式时以 SSE 逐块返回，末块可带 `usage`（需 `stream_options.include_usage`）。

## 错误
```json
{ "error": { "message": "...", "type": "invalid_request_error", "param": "", "code": "..." } }
```
