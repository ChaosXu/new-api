# 视频内容代理
> `GET /v1/videos/:task_id/content`
- **鉴权**：TokenOrUserAuth（接受会话登录或 API Token）
- **用途**：按任务所属渠道代理下载视频内容，透传上游响应头并设置缓存（`Cache-Control: public, max-age=86400`）。含 SSRF 校验。见 `controller/video_proxy.go`。

## 请求
路径参数：

| 参数 | 位置 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| `task_id` | path | string | 是 | 本地任务 ID（非上游 ID） |

## 响应
直接透传视频二进制流，`Content-Type` 透传上游（或 `data:` 解码后按 MIME 设置，默认 `video/mp4`），附加 `Cache-Control: public, max-age=86400`。

按渠道类型回源策略：
- **OpenAI / Sora**：`GET <baseURL>/v1/videos/<upstreamTaskId>/content`，`Authorization: Bearer <channel.Key>`。
- **Gemini**：调用 `getGeminiVideoURL` 解析视频 URL，`x-goog-api-key`（取任务存储的 key）。
- **Vertex AI**：调用 `getVertexVideoURL` 解析视频 URL。
- **其他**：使用任务存储的 `ResultURL`。
- 若 URL 为 `data:` 协议，直接 base64 解码并写出。

## SSRF 校验
- 无代理时：`service.ValidateSSRFProtectedFetchURL(videoURL)`。
- 有渠道代理时：按系统 FetchSetting（`EnableSSRFProtection` / `AllowPrivateIp` / 域名 IP 过滤 / `AllowedPorts` 等）校验。

## 错误
OpenAI 风格 JSON：
```json
{ "error": { "message": "Task not found", "type": "invalid_request_error" } }
```
常见状态：
| HTTP | type | 触发条件 |
| --- | --- | --- |
| 400 | `invalid_request_error` | `task_id` 为空 / 任务未完成 |
| 403 | `server_error` | URL 被 SSRF 拦截 |
| 404 | `invalid_request_error` | 任务不存在 |
| 500 | `server_error` | 创建代理/请求失败 |
| 502 | `server_error` | 上游取流失败 / 视频 URL 为空 |
