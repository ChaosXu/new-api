# 查询视频
> `GET /v1/videos/:task_id`
- **鉴权**：TokenAuth + Distribute
- **用途**：OpenAI 兼容的 Videos API 查询接口，走 `RelayTaskFetch`。

## 请求
路径参数：

| 参数 | 位置 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| `task_id` | path | string | 是 | 任务 ID |

## 响应
`dto.VideoTaskResponse`：`{task_id, status, url, format, metadata, error}`，字段见 README「通用查询响应」。

## 错误
见 README 任务型错误。
