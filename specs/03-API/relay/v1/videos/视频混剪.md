# 视频混剪
> `POST /v1/videos/:video_id/remix`
- **鉴权**：TokenAuth + Distribute
- **用途**：OpenAI 兼容的 Videos API remix 接口，基于已生成视频进行混剪/再创作。走 `RelayTask`。

## 请求
路径参数：

| 参数 | 位置 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| `video_id` | path | string | 是 | 源视频任务 ID |

请求体（`dto.VideoRequest` 子集）：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| `prompt` | string | 是 | remix 提示词 |
| `model` | string | 是 | 模型 ID |
| `duration` / `width` / `height` | - | 否 | 规格 |
| `metadata` | object | 否 | 厂商特有参数 |

## 响应
`dto.VideoResponse`：`{task_id, status}`。

见 README 任务型错误。
