# 创建视频
> `POST /v1/videos`
- **鉴权**：TokenAuth + Distribute
- **用途**：OpenAI 兼容的 Videos API（sora），创建视频任务。走 `RelayTask`。

## 请求
请求体复用 `dto.VideoRequest`（OpenAI 风格字段）：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `model` | string | 是 | 模型 ID（如 sora 系列） |
| `prompt` | string | 是 | 提示词 |
| `image` | string | 否 | 参考图（图生视频） |
| `duration` / `width` / `height` / `fps` | - | 否 | 规格 |
| `n` | int | 否 | 生成数量 |
| `metadata` | object | 否 | 厂商特有参数 |

## 响应
`dto.VideoResponse`：`{task_id, status}`。
