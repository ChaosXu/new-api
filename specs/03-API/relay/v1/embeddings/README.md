# 嵌入向量端点

| 端点 | 方法 | 鉴权 | 用途 | 文件 |
| --- | --- | --- | --- | --- |
| `/v1/embeddings` | POST | TokenAuth + ModelRequestRateLimit + Distribute | 生成嵌入向量 | [嵌入向量.md](嵌入向量.md) |

## 网关特殊行为
- **不走统一响应信封**：使用 OpenAI 原生协议。
- **预扣计费**：按输入 token 估算预扣，失败退还，成功按实际 usage 结算。
- **多渠道重试**：可重试错误触发渠道切换。
- **非流式**：嵌入接口不支持流式。
