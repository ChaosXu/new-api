# 嵌入向量
> `POST /v1/embeddings`
- **鉴权**：TokenAuth + ModelRequestRateLimit + Distribute
- **用途**：生成文本嵌入向量，RelayFormat=Embedding。

## 请求
遵循 OpenAI Embeddings 原生规范。核心字段：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| model | string | 是 | 模型名 |
| input | any | 是 | 字符串或字符串数组 |
| encoding_format | string | 否 | `float`/`base64` 等 |
| dimensions | int | 否 | 向量维度 |
| user | string | 否 | 用户标识 |
| seed | float | 否 | 随机种子 |
| temperature | float | 否 | 采样温度 |
| top_p | float | 否 | nucleus 采样 |
| frequency_penalty / presence_penalty | float | 否 | 惩罚项 |

## 响应
遵循 OpenAI 原生规范。
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| object | string | `list` |
| data | array | 嵌入项，含 `object`=`embedding`、`index`、`embedding` |
| model | string | 模型名 |
| usage | object | `prompt_tokens`/`total_tokens` |

## 错误
```json
{ "error": { "message": "...", "type": "invalid_request_error", "param": "", "code": "..." } }
```
