# 文字转语音
> `POST /v1/audio/speech`
- **鉴权**：TokenAuth + ModelRequestRateLimit + Distribute
- **用途**：文字合成语音（TTS），RelayFormat=OpenAIAudio。

## 请求
遵循 OpenAI 原生规范。核心字段：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| model | string | 否 | 模型名，默认 `tts-1` |
| input | string | 是 | 待合成文本 |
| voice | string | 是 | 音色 |
| response_format | string | 否 | 输出格式（mp3 等） |
| speed | float | 否 | 语速 |
| instructions | string | 否 | 指令 |
| stream_format | string | 否 | `sse` 时为流式 |
| metadata | any | 否 | 元数据 |

## 响应
直接返回音频字节流（`audio/mpeg` 等）。`stream_format=sse` 时以 SSE 返回。

## 错误
```json
{ "error": { "message": "...", "type": "invalid_request_error", "param": "", "code": "..." } }
```
