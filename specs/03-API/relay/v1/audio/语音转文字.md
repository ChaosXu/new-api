# 语音转文字
> `POST /v1/audio/transcriptions`
- **鉴权**：TokenAuth + ModelRequestRateLimit + Distribute
- **用途**：音频转写为文字（whisper），multipart 上传，RelayFormat=OpenAIAudio。

## 请求
multipart/form-data。核心字段：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| model | string | 否 | 模型名，默认 `whisper-1` |
| file | file | 是 | 音频文件 |
| language | any | 否 | 语言 |
| response_format | string | 否 | `json`/`text`/`srt`/`verbose_json`/`vtt` |
| prompt | any | 否 | 提示 |
| temperature | any | 否 | 采样温度 |
| task_type | any | 否 | 任务类型（部分渠道） |

## 响应
遵循 OpenAI 原生规范。`response_format=json`（默认）：
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| text | string | 转写文本 |

`verbose_json` 额外含 `task`/`language`/`duration`/`segments`。

## 错误
```json
{ "error": { "message": "...", "type": "invalid_request_error", "param": "", "code": "..." } }
```
