# 查询视频任务
> `GET /v1/video/generations/:task_id`
- **鉴权**：TokenAuth + Distribute
- **用途**：查询统一视频生成任务的状态，走 `RelayTaskFetch`。

## 请求
路径参数：

| 参数 | 位置 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| `task_id` | path | string | 是 | 任务 ID |

## 响应
`dto.VideoTaskResponse`：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `task_id` | string | 任务 ID |
| `status` | string | `succeeded` / `processing` / `failed` |
| `url` | string | 视频 URL（成功时） |
| `format` | string | 格式（`mp4`） |
| `metadata` | object | `{duration, fps, width, height, seed}` |
| `error` | object | `{code, message}`（失败时） |

## 错误
见 README 任务型错误。
