# 视频生成
> `POST /v1/video/generations`
- **鉴权**：TokenAuth + Distribute
- **用途**：统一入参的视频生成提交接口，由 `RelayTask` 分发到具体渠道（可灵/即梦/Gemini/Sora 等）。

## 请求
请求体 `dto.VideoRequest`：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `model` | string | 是 | 模型/样式 ID，如 `kling-v1` |
| `prompt` | string | 是 | 文本提示词 |
| `image` | string | 否 | 图片输入（URL 或 Base64），图生视频时必填 |
| `duration` | float64 | 否 | 视频时长（秒），如 `5.0` |
| `width` / `height` | int | 否 | 分辨率，如 `512` |
| `fps` | int | 否 | 帧率，如 `30` |
| `seed` | int | 否 | 随机种子 |
| `n` | int | 否 | 生成数量 |
| `response_format` | string | 否 | 响应格式，如 `url` |
| `user` | string | 否 | 用户标识 |
| `metadata` | object | 否 | 厂商特有参数（negative_prompt、style、quality_level 等） |

示例：
```json
{ "model": "kling-v1", "prompt": "宇航员站起身走了", "duration": 5.0, "width": 512, "height": 512 }
```

## 响应
`dto.VideoResponse`：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `task_id` | string | 任务 ID |
| `status` | string | 提交状态 |
