# 图像编辑
> `POST /v1/images/edits`
- **鉴权**：TokenAuth + ModelRequestRateLimit + Distribute
- **用途**：图生图/图像编辑（multipart 上传），RelayFormat=OpenAIImage。

## 请求
multipart/form-data。核心字段：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| model | string | 是 | 模型名 |
| prompt | string | 是 | 编辑提示词 |
| image | file | 否 | 原图（部分渠道支持 `images`） |
| mask | file | 否 | 蒙版 |
| n | uint | 否 | 生成数量 |
| size | string | 否 | 尺寸 |
| response_format | string | 否 | `url`/`b64_json` |
| user | any | 否 | 用户标识 |

## 响应
遵循 OpenAI 原生规范。
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| created | int64 | 创建时间戳 |
| data | array | 图像项，含 `url`/`b64_json` |

## 错误
```json
{ "error": { "message": "...", "type": "invalid_request_error", "param": "", "code": "..." } }
```
