# 图像生成
> `POST /v1/images/generations`
- **鉴权**：TokenAuth + ModelRequestRateLimit + Distribute
- **用途**：文生图，RelayFormat=OpenAIImage。

## 请求
遵循 OpenAI Images 原生规范。核心字段：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| model | string | 是 | 模型名 |
| prompt | string | 是 | 提示词 |
| n | uint | 否 | 生成数量（上限 128） |
| size | string | 否 | 尺寸（如 `1024x1024`） |
| quality | string | 否 | 质量（如 `hd`） |
| response_format | string | 否 | `url`/`b64_json` |
| style | any | 否 | 风格 |
| background | any | 否 | 背景 |
| output_format | any | 否 | 输出格式 |
| moderation | any | 否 | 审核 |
| stream | bool | 否 | 流式 |
| user | any | 否 | 用户标识 |

## 响应
遵循 OpenAI 原生规范。
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| created | int64 | 创建时间戳 |
| data | array | 图像项，含 `url`/`b64_json`/`revised_prompt` |

## 错误
```json
{ "error": { "message": "...", "type": "invalid_request_error", "param": "", "code": "..." } }
```
