# 图像编辑别名
> `POST /v1/edits`
- **鉴权**：TokenAuth + ModelRequestRateLimit + Distribute
- **用途**：`/v1/images/edits` 的短路径别名，RelayFormat=OpenAIImage，行为与图像编辑一致。

## 请求
同 [图像编辑.md](图像编辑.md)：multipart/form-data，含 `model`/`prompt`/`image`/`mask`/`n`/`size` 等。

## 响应
同图像编辑：`{created, data:[{url/b64_json}]}`。

## 错误
```json
{ "error": { "message": "...", "type": "invalid_request_error", "param": "", "code": "..." } }
```
