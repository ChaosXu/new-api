# 微调事件
> `GET /v1/fine-tunes/:id/events`
- **鉴权**：TokenAuth
- **用途**：获取指定微调任务的事件流。**当前未实现**，固定返回 501。

## 请求
Path 参数：
| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| id | string | 是 | 微调任务 ID |

Query（预期）：`stream`/分页等。
