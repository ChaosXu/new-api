# 计费订阅
> `GET /dashboard/billing/subscription`
- **鉴权**：TokenAuth
- **用途**：返回 OpenAI 兼容的订阅信息，用于客户端读取当前可用额度上限与到期时间。见 `controller.GetSubscription`。

## 请求
无请求体。鉴权后从令牌/用户上下文读取额度。

## 响应
`controller.OpenAISubscriptionResponse`（HTTP 200）：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `object` | string | `billing_subscription` |
| `has_payment_method` | bool | 固定 `true` |
| `soft_limit_usd` | float64 | 软上限（= hard_limit_usd） |
| `hard_limit_usd` | float64 | 硬上限（剩余 + 已用，按展示类型换算） |
| `system_hard_limit_usd` | float64 | 系统硬上限（同 hard_limit_usd） |
| `access_until` | int64 | 到期时间戳（开启令牌统计时取令牌过期时间，否则 0） |

示例：
```json
{
  "object": "billing_subscription",
  "has_payment_method": true,
  "soft_limit_usd": 10.0,
  "hard_limit_usd": 10.0,
  "system_hard_limit_usd": 10.0,
  "access_until": 1735689600
}
```

> 无限额度令牌的 `*_usd` 字段返回 `100000000`。

## 错误
查询额度失败时返回 HTTP 200，body：
```json
{ "error": { "message": "<err>", "type": "upstream_error" } }
```
