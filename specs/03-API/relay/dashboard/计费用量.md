# 计费用量
> `GET /dashboard/billing/usage`
- **鉴权**：TokenAuth
- **用途**：返回 OpenAI 兼容的用量信息（累计已用额度）。见 `controller.GetUsage`。

## 请求
无请求体。

## 响应
`controller.OpenAIUsageResponse`（HTTP 200）：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `object` | string | `list` |
| `total_usage` | float64 | 累计用量，单位 **0.01 美元**（= 已用额度换算后 ×100） |

示例：
```json
{ "object": "list", "total_usage": 5234.56 }
```

> 换算：`total_usage = (已用 quota 按展示类型换算后) * 100`。

## 错误
查询用量失败时返回 HTTP 200，body：
```json
{ "error": { "message": "<err>", "type": "new_api_error" } }
```
