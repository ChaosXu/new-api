# 获取图片
> `GET /mj/image/:id`
- **鉴权**：无（在 `TokenAuth` 中间件之前注册，匿名访问）
- **用途**：按任务 ID（mj_id）代理获取 Midjourney 生成的图片。当 `MjForwardUrlEnabled` 开启时，任务列表中的 `imageUrl` 会被改写为 `<ServerAddress>/mj/image/<mj_id>` 形式，由本端点回源。

## 请求
路径参数：

| 参数 | 位置 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| `id` | path | string | 是 | Midjourney 任务 ID（mj_id） |

无请求体。Query/Body 均不解析。

## 响应
直接返回图片二进制流（透传上游 `Content-Type`，通常 `image/png` 或 `image/webp`）。失败时返回文本错误。

## 错误
非 JSON 信封。失败时由 `relay.RelayMidjourneyImage` 直接输出 HTTP 错误（如 404 图片不存在、502 上游不可达）。
