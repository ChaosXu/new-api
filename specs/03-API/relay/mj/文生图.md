# 文生图
> `POST /mj/submit/imagine`
- **鉴权**：TokenAuth + Distribute
- **用途**：提交 Midjourney `imagine`（文生图）任务，返回任务 ID 后异步生成。

## 请求
请求体 `dto.MidjourneyRequest`：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `prompt` | string | 是 | 提示词 |
| `botType` | string | 否 | `MID_JOURNEY` / `NIJI_JOURNEY` |
| `notifyHook` | string | 否 | 回调地址 |
| `base64Array` | []string | 否 | 参考图 Base64 数组 |
| `state` | string | 否 | 透传 state |
| `maskBase64` | string | 否 | 掩码 |

示例：
```json
{ "prompt": "a cute cat --ar 1:1", "botType": "MID_JOURNEY" }
```

## 响应
成功提交返回任务回执（`MidjourneyResponse` 风格）：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `code` | int | `1` 成功 |
| `description` | string | 描述 |
| `result` | string | 任务 ID（mj_id） |
| `properties` | object | 附加属性 |

完成后任务详情字段见 README「通用响应（MidjourneyDto）」。

## 错误
见 README 错误格式。`code=30` 返回 HTTP 429。
