# 图生文
> `POST /mj/submit/describe`
- **鉴权**：TokenAuth + Distribute
- **用途**：提交 Midjourney `describe` 任务，由图片反向生成 4 条候选提示词。

## 请求
请求体 `dto.MidjourneyRequest`：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `base64Array` | []string | 是 | 待描述图片的 Base64 数组 |
| `botType` | string | 否 | 机器人类型 |
| `notifyHook` | string | 否 | 回调地址 |
| `state` | string | 否 | 透传 state |

示例：
```json
{ "base64Array": ["data:image/png;base64,iVBORw0KG..."] }
```

## 响应
返回任务回执。完成后 `properties` / `description` 含生成的 4 条候选提示词文本。

见 README 错误格式。
