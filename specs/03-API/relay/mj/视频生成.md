# 视频生成
> `POST /mj/submit/video`
- **鉴权**：TokenAuth + Distribute
- **用途**：将已生成的 Midjourney 图片转为短视频（对应 Midjourney 的 Video 任务）。

## 请求
请求体 `dto.MidjourneyRequest`：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `customId` | string | 是 | 源任务返回的视频按钮 customId |
| `taskId` | string | 是 | 源图片任务 ID |
| `action` | string | 否 | 动作（通常 `VIDEO`） |
| `notifyHook` | string | 否 | 回调地址 |

## 响应
返回任务回执。完成后 `videoUrl` / `videoUrls` 字段含视频地址。

见 README 错误格式。
