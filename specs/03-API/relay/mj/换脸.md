# 换脸
> `POST /mj/insight-face/swap`
- **鉴权**：TokenAuth + Distribute
- **用途**：基于 InsightFace 的换脸任务，将源人脸替换到目标图片。

## 请求
请求体 `dto.SwapFaceRequest`：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `sourceBase64` | string | 是 | 源人脸图片 Base64 |
| `targetBase64` | string | 是 | 目标图片 Base64 |

示例：
```json
{ "sourceBase64": "data:image/png;base64,...", "targetBase64": "data:image/png;base64,..." }
```

## 响应
返回任务回执（同文生图）。完成后 `imageUrl` 为换脸结果。

## 错误
见 README 错误格式。本端点经 `RelaySwapFace` 处理。
