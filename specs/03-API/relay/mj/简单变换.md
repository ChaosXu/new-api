# 简单变换
> `POST /mj/submit/simple-change`
- **鉴权**：TokenAuth + Distribute
- **用途**：简化版的图像变换接口，允许直接传入 `prompt` / `customId` / `action` / `content` 而无需完整任务上下文（便于上游适配）。

## 请求
请求体（简化字段，沿用 `dto.MidjourneyRequest` 子集）：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `action` | string | 否 | 动作类型 |
| `customId` | string | 否 | 按钮 customId |
| `content` | string | 否 | 内容文本 |
| `prompt` | string | 否 | 提示词 |
| `taskId` | string | 否 | 源任务 ID |

## 响应
返回任务回执（同文生图）。

## 错误
见 README 错误格式。
