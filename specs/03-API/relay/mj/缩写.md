# 缩写
> `POST /mj/submit/shorten`
- **鉴权**：TokenAuth + Distribute
- **用途**：提交 Midjourney `shorten` 任务，对长提示词进行精简并给出可移除词建议。

## 请求
请求体 `dto.MidjourneyRequest`：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `prompt` | string | 是 | 待精简的提示词 |
| `botType` | string | 否 | 机器人类型 |
| `notifyHook` | string | 否 | 回调地址 |
| `state` | string | 否 | 透传 state |

## 响应
返回任务回执。完成后 `properties` / `description` 含精简后的提示词及建议。

## 错误
见 README 错误格式。
