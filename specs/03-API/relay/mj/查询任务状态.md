# 查询任务状态
> `GET /mj/task/:id/fetch`
- **鉴权**：TokenAuth + Distribute
- **用途**：查询单个 Midjourney 任务的最新状态（对应上游 `RelayModeMidjourneyTaskFetch`）。

## 请求
路径参数：

| 参数 | 位置 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| `id` | path | string | 是 | mj_id |

## 响应
返回 `MidjourneyDto`，字段见 README「通用响应」。典型状态：`NOT_START` / `SUBMITTED` / `IN_PROGRESS` / `SUCCESS` / `FAILURE`，`progress` 形如 `50%`。

## 错误
见 README 错误格式。
