# 图像变换
> `POST /mj/submit/change`
- **鉴权**：TokenAuth + Distribute
- **用途**：对已生成图片执行 upscale（放大）、variation（变体）、pan（平移）、reroll（重绘）等变换，需指定按钮 `customId`。

## 请求
请求体 `dto.MidjourneyRequest`：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `action` | string | 是 | 动作：`UPSCALE` / `VARIATION` / `REROLL` / `ZOOM` / `PAN` 等 |
| `customId` | string | 是 | 来自上一任务 `buttons` 的 customId |
| `taskId` | string | 是 | 源任务 ID |
| `index` | int | 否 | 按钮序号（1-4） |
| `prompt` | string | 否 | 追加提示词（如 pan 方向） |
| `notifyHook` | string | 否 | 回调地址 |
| `state` | string | 否 | 透传 state |
| `maskBase64` | string | 否 | 局部重绘掩码（Vary Region） |

示例：
```json
{ "action": "UPSCALE", "taskId": "1680000000000-1", "customId": "MJ::JOB::upsample::1::abc", "index": 1 }
```

## 响应
返回新任务回执（同文生图），含新的任务 ID。完成后字段见 README「通用响应」。
