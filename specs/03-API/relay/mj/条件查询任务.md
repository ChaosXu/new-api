# 条件查询任务
> `POST /mj/task/list-by-condition`
- **鉴权**：TokenAuth + Distribute
- **用途**：按 mj_id 列表批量查询任务详情（对应上游 `RelayModeMidjourneyTaskFetchByCondition`）。系统轮询任务状态时也调用同一上游接口。

## 请求
请求体：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `ids` | []string | 是 | 待查询的 mj_id 列表 |

示例：
```json
{ "ids": ["1680000000000-1", "1680000000000-2"] }
```

## 响应
返回 `MidjourneyDto` 数组，字段见 README「通用响应」。

## 错误
见 README 错误格式。
