# 查询图像种子
> `GET /mj/task/:id/image-seed`
- **鉴权**：TokenAuth + Distribute
- **用途**：查询指定任务生成图片的 seed（随机种子），对应上游 `RelayModeMidjourneyTaskImageSeed`。

## 请求
路径参数：

| 参数 | 位置 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| `id` | path | string | 是 | mj_id |

## 响应
返回含图像 seed 的回执（`MidjourneyResponse` 风格，`result` 为 seed 值）。

## 错误
见 README 错误格式。
