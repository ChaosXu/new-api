# 编辑
> `POST /mj/submit/edits`
- **鉴权**：TokenAuth + Distribute
- **用途**：提交 Midjourney 局部编辑任务（Vary Region / Inpaint），基于源图与掩码重绘指定区域。

## 请求
请求体 `dto.MidjourneyRequest`：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `prompt` | string | 否 | 编辑提示词 |
| `base64Array` | []string | 否 | 源图 Base64 |
| `maskBase64` | string | 否 | 重绘区域掩码 Base64 |
| `customId` | string | 否 | 触发按钮 customId |
| `taskId` | string | 否 | 源任务 ID |
| `notifyHook` | string | 否 | 回调地址 |

## 响应
返回任务回执。完成后字段见 README「通用响应」。

## 错误
见 README 错误格式。
