# 混合
> `POST /mj/submit/blend`
- **鉴权**：TokenAuth + Distribute
- **用途**：提交 Midjourney `blend` 任务，将多张图片混合为一张。

## 请求
请求体 `dto.MidjourneyRequest`：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `base64Array` | []string | 是 | 2-5 张待混合图片的 Base64 |
| `botType` | string | 否 | 机器人类型 |
| `notifyHook` | string | 否 | 回调地址 |
| `state` | string | 否 | 透传 state |
| `prompt` | string | 否 | 维度提示（如 `--ar 2:3`） |

## 响应
返回任务回执。完成后字段见 README「通用响应」。

## 错误
见 README 错误格式。
