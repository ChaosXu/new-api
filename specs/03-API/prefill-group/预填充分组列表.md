# 预填充分组列表
> `GET /api/prefill_group/`
- **鉴权**：AdminAuth（管理员）
- **用途**：获取预填充分组列表，可按类型过滤。

## 请求
Query 参数：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| type | string | 否 | 分组类型筛选 |

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data | PrefillGroup[] | 预填充分组数组 |

PrefillGroup：id、name、type、items（JSON）、description、created_time、updated_time。

示例：
```json
{ "success": true, "message": "", "data": [ { "id": 1, "name": "g1", "type": "token", "items": [] } ] }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | （错误信息） | 查询失败 |
