# 更新预填充分组
> `PUT /api/prefill_group/`
- **鉴权**：AdminAuth（管理员）
- **用途**：更新预填充分组。

## 请求
PrefillGroup：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| id | int | 是 | 分组 ID |
| name | string | 否 | 分组名称（须唯一） |
| type | string | 否 | 分组类型 |
| items | any(JSON) | 否 | 预填项内容 |
| description | string | 否 | 描述 |

示例：
```json
{ "id": 2, "name": "新名称", "type": "token", "items": [] }
```

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data | PrefillGroup | 更新后的分组 |

示例：
```json
{ "success": true, "message": "", "data": { "id": 2, "name": "新名称" } }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | 参数错误 | 请求体解析失败 |
| 200 | 缺少组 ID | id 为 0 |
| 200 | 组名称已存在 | 名称与其他分组重复 |
