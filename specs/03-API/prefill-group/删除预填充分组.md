# 删除预填充分组
> `DELETE /api/prefill_group/:id`
- **鉴权**：AdminAuth（管理员）
- **用途**：按 ID 删除预填充分组（软删除）。

## 请求
路径参数：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| id | int | 是 | 分组 ID |

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data | null | 删除成功 |

示例：
```json
{ "success": true, "message": "", "data": null }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | （错误信息） | id 解析失败或删除失败 |
