# 创建预填充分组
> `POST /api/prefill_group/`
- **鉴权**：AdminAuth（管理员）
- **用途**：创建新的预填充分组。

## 请求
PrefillGroup：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| name | string | 是 | 分组名称（唯一） |
| type | string | 是 | 分组类型 |
| items | any(JSON) | 否 | 预填项内容 |
| description | string | 否 | 描述 |

示例：
```json
{ "name": "默认令牌预设", "type": "token", "items": [], "description": "" }
```

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data | PrefillGroup | 创建后的分组 |

示例：
```json
{ "success": true, "message": "", "data": { "id": 2, "name": "默认令牌预设", "type": "token" } }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | 参数错误 | 请求体解析失败 |
| 200 | 组名称和类型不能为空 | name/type 为空 |
| 200 | 组名称已存在 | 名称重复 |
