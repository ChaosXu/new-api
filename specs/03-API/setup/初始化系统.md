# 初始化系统

> `POST /api/setup`

- **鉴权**：无（公开接口，仅系统未初始化时可用）
- **用途**：首次部署时创建管理员账号、保存运行模式并标记系统为已初始化。已初始化系统调用会直接失败。

## 请求

JSON Body（受 `anonymousRequestBodyLimit` 限制）：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| username | string | 是（根用户不存在时） | 管理员用户名，长度 ≤ 12 |
| password | string | 是（根用户不存在时） | 密码，长度 ≥ 8 |
| confirmPassword | string | 是（根用户不存在时） | 确认密码，须与 password 一致 |
| SelfUseModeEnabled | bool | 是 | 是否启用自用模式 |
| DemoSiteEnabled | bool | 是 | 是否启用演示站点模式 |

```json
{
  "username": "admin",
  "password": "12345678",
  "confirmPassword": "12345678",
  "SelfUseModeEnabled": false,
  "DemoSiteEnabled": false
}
```

## 响应

成功：

```json
{
  "success": true,
  "message": "系统初始化成功"
}
```

## 错误码

错误统一返回 HTTP 200，通过 `success=false` 与中文 `message` 表达（硬编码中文文案）：

| 场景 | message |
|---|---|
| 系统已初始化完成 | `系统已经初始化完成` |
| 请求体解析失败 | `请求参数有误` |
| 用户名长度超过 12 | `用户名长度不能超过12个字符` |
| 两次密码不一致 | `两次输入的密码不一致` |
| 密码长度小于 8 | `密码长度至少为8个字符` |
| 密码哈希失败 | `系统错误: <err>` |
| 创建管理员账号失败 | `创建管理员账号失败: <err>` |
| 保存自用模式失败 | `保存自用模式设置失败: <err>` |
| 保存演示站点模式失败 | `保存演示站点模式设置失败: <err>` |
| 写入 Setup 记录失败 | `系统初始化失败: <err>` |

> 说明：若根用户已存在，仅校验并保存 `SelfUseModeEnabled` / `DemoSiteEnabled`，跳过用户名/密码校验。
