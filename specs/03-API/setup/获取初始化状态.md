# 获取初始化状态

> `GET /api/setup`

- **鉴权**：无（公开接口）
- **用途**：查询系统是否已完成初始化，供前端初始化向导判断是否展示初始化表单。

## 请求

无参数。

## 响应

标准信封 `{success, message, data}`，`data` 字段如下：

| 字段 | 类型 | 说明 |
|---|---|---|
| status | bool | 系统是否已初始化完成（`constant.Setup`） |
| root_init | bool | 根用户是否存在（仅 `status=false` 时有意义） |
| database_type | string | 当前数据库类型，如 `mysql`/`postgres`/`sqlite`（仅 `status=false` 时返回） |

```json
{
  "success": true,
  "message": "",
  "data": {
    "status": false,
    "root_init": false,
    "database_type": "mysql"
  }
}
```

```json
{
  "success": true,
  "message": "",
  "data": {
    "status": true
  }
}
```

## 错误码

无。始终返回 HTTP 200。
