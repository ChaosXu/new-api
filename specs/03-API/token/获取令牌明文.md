# 获取令牌明文
> `POST /api/token/:id/key`
- **鉴权**：UserAuth（用户登录态）+ CriticalRateLimit + DisableCache
- **用途**：获取指定令牌的完整明文 Key（敏感操作，强限流）。

## 请求
路径参数：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| id | int | 是 | 令牌 ID |

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data.key | string | 令牌完整明文 Key |

示例：
```json
{ "success": true, "message": "", "data": { "key": "sk-abcdef123456" } }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | （错误信息） | id 解析失败或令牌不存在 |
