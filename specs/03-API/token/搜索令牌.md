# 搜索令牌
> `GET /api/token/search`
- **鉴权**：UserAuth（用户登录态）+ SearchRateLimit
- **用途**：按关键词或令牌内容模糊搜索当前用户的令牌（Key 脱敏）。

## 请求
Query 参数：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| keyword | string | 否 | 名称关键词 |
| token | string | 否 | 令牌内容片段 |

另含分页参数（p、page_size）。

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data | PageQuery | 分页对象，含 items（tokenResponse[]） |

示例：
```json
{ "success": true, "message": "", "data": { "items": [] } }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | （错误信息） | 搜索失败 |
