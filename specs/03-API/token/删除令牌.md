# 删除令牌
> `DELETE /api/token/:id`
- **鉴权**：UserAuth（用户登录态）
- **用途**：删除指定令牌。

## 请求
路径参数：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| id | int | 是 | 令牌 ID |

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data | null | 删除成功 |

示例：
```json
{ "success": true, "message": "", "data": null }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | （错误信息） | 删除失败 |
