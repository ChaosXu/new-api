# 获取令牌
> `GET /api/token/:id`
- **鉴权**：UserAuth（用户登录态）
- **用途**：获取指定令牌详情（Key 已脱敏）。

## 请求
路径参数：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| id | int | 是 | 令牌 ID |

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data | tokenResponse | 令牌详情（含脱敏 key、auto_groups） |

示例：
```json
{ "success": true, "message": "", "data": { "id": 1, "name": "t", "key": "sk-***", "auto_groups": [] } }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | （错误信息） | id 解析失败或令牌不存在 |
