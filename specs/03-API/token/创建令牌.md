# 创建令牌
> `POST /api/token/`
- **鉴权**：UserAuth（用户登录态）
- **用途**：创建新令牌。

## 请求
tokenRequest（内嵌 model.Token）：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| name | string | 是 | 令牌名称（长度受限） |
| remain_quota | int | 否 | 剩余额度（不能为负，不超上限） |
| unlimited_quota | bool | 否 | 无限额度 |
| expired_time | int64 | 否 | 过期时间戳 |
| model_limits_enabled | bool | 否 | 启用模型限制 |
| model_limits | string | 否 | 模型限制列表 |
| allow_ips | string | 否 | 允许 IP |
| group | string | 否 | 分组（可为 auto） |
| auto_groups | string[] | 否 | 自动分组列表（group=auto 时生效） |

示例：
```json
{ "name": "my-token", "remain_quota": 500000, "expired_time": -1, "group": "default" }
```

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data | tokenResponse | 创建的令牌（含脱敏 key） |

示例：
```json
{ "success": true, "message": "", "data": { "id": 2, "name": "my-token", "key": "sk-***" } }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | （i18n 错误） | 名称过长 / 额度为负 / 超上限 / 生成失败 |
