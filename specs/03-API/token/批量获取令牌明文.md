# 批量获取令牌明文
> `POST /api/token/batch/keys`
- **鉴权**：UserAuth（用户登录态）+ CriticalRateLimit + DisableCache
- **用途**：批量获取令牌完整明文 Key，单次最多 100 个。

## 请求
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| ids | int[] | 是 | 令牌 ID 列表，不能为空，最多 100 个 |

示例：
```json
{ "ids": [1, 2] }
```

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data.keys | map<int,string> | 令牌 ID → 完整明文 Key |

示例：
```json
{ "success": true, "message": "", "data": { "keys": { "1": "sk-aaa", "2": "sk-bbb" } } }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | （i18n: MsgInvalidParams） | 解析失败或 ids 为空 |
| 200 | （i18n: MsgBatchTooMany, Max=100） | ids 超过 100 个 |
