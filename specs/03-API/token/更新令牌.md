# 更新令牌
> `PUT /api/token/`
- **鉴权**：UserAuth（用户登录态）
- **用途**：更新令牌。支持 `status_only=true` 仅更新启用状态。

## 请求
Query 参数：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| status_only | string | 否 | 非空时仅更新 status 字段 |

请求体（tokenRequest）：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| id | int | 是 | 令牌 ID |
| status | int | status_only 时必填 | 启用状态 |
| name | string | 否 | 名称 |
| remain_quota | int | 否 | 剩余额度 |
| expired_time | int64 | 否 | 过期时间戳 |
| group / auto_groups | - | 否 | 分组相关字段 |

示例（仅改状态）：
```json
{ "id": 1, "status": 2 }
```

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data | tokenResponse | 更新后的令牌（脱敏 key） |

示例：
```json
{ "success": true, "message": "", "data": { "id": 1, "status": 2, "key": "sk-***" } }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | （i18n 错误） | 名称过长 / 额度非法 / 已过期不能启用等 |
