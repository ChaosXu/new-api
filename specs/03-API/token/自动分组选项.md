# 自动分组选项
> `GET /api/token/auto-groups`
- **鉴权**：UserAuth（用户登录态）
- **用途**：获取当前用户所属分组可用的自动分组候选列表与数量上限。

## 请求
无

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data.groups | string[] | 可选自动分组列表 |
| data.max_count | int | 自动分组最大数量上限 |

示例：
```json
{ "success": true, "message": "", "data": { "groups": ["default", "vip"], "max_count": 5 } }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | （错误信息） | 获取用户分组失败 |
