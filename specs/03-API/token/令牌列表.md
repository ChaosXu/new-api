# 令牌列表
> `GET /api/token/`
- **鉴权**：UserAuth（用户登录态）
- **用途**：分页获取当前用户的令牌列表（Key 已脱敏）。

## 请求
Query 参数（分页）：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| p | int | 否 | 页码 |
| page_size | int | 否 | 每页数量 |

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data | PageQuery | 分页对象，含 items（tokenResponse[]，key 脱敏）与 total |

示例：
```json
{
  "success": true,
  "message": "",
  "data": { "p": 0, "page_size": 10, "total": 1, "items": [ { "id": 1, "name": "t", "key": "sk-***" } ] }
}
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | （错误信息） | 查询失败 |
