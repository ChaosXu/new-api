# 批量删除令牌
> `POST /api/token/batch`
- **鉴权**：UserAuth（用户登录态）
- **用途**：按 ID 列表批量删除令牌。

## 请求
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| ids | int[] | 是 | 待删除令牌 ID 列表，不能为空 |

示例：
```json
{ "ids": [1, 2, 3] }
```

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data | null | 删除成功 |

示例：
```json
{ "success": true, "message": "", "data": null }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | （i18n: MsgInvalidParams） | 请求体解析失败或 ids 为空 |
