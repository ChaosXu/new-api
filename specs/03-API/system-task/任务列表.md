# 任务列表
> `GET /api/system-task/list`
- **鉴权**：RootAuth（超级管理员）
- **用途**：获取系统任务列表，可限制返回数量。

## 请求
Query 参数：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| limit | int | 否 | 返回数量上限 |

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data | SystemTaskResponse[] | 任务列表 |

示例：
```json
{ "success": true, "message": "", "data": [] }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | （错误信息） | 查询失败 |
