# 创建日志清理任务
> `POST /api/system-task/log-cleanup`
- **鉴权**：RootAuth（超级管理员）
- **用途**：创建一个日志清理系统任务，清理指定时间戳之前的日志。

## 请求
Query 参数：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| target_timestamp | int64 | 是 | 清理此时间戳之前的日志（秒） |

示例：`POST /api/system-task/log-cleanup?target_timestamp=1722000000`

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data | SystemTaskResponse | 创建的任务信息 |

示例：
```json
{ "success": true, "message": "", "data": { "task_id": "...", "type": "log_cleanup", "status": "pending" } }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | target timestamp is required | 未传 target_timestamp |
| 200 | （错误信息） | 启动任务失败 |
