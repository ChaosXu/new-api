# 任务详情
> `GET /api/system-task/:task_id`
- **鉴权**：RootAuth（超级管理员）
- **用途**：按任务 ID 查询系统任务详情。

## 请求
路径参数：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| task_id | string | 是 | 任务 ID |

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data | SystemTaskResponse | 任务详情 |

示例：
```json
{ "success": true, "message": "", "data": { "task_id": "...", "status": "done" } }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | task id is required | 未传 task_id |
| 404 | task not found | 任务不存在 |
| 200 | （错误信息） | 查询失败 |
