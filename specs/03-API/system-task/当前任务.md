# 当前任务
> `GET /api/system-task/current`
- **鉴权**：RootAuth（超级管理员）
- **用途**：查询指定类型的当前活跃系统任务。

## 请求
Query 参数：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| type | string | 是 | 任务类型 |

示例：`GET /api/system-task/current?type=log_cleanup`

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data | SystemTaskResponse 或 null | 当前活跃任务；无则为 null |

示例：
```json
{ "success": true, "message": "", "data": null }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | type is required | 未传 type |
| 200 | （错误信息） | 查询失败 |
