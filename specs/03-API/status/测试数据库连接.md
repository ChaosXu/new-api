# 测试数据库连接

> `GET /api/status/test`

- **鉴权**：AdminAuth（管理员）
- **用途**：探测数据库连接是否正常，并附带 HTTP 中间件统计信息，用于运维健康检查。

## 请求

无参数。

## 响应

成功（HTTP 200）：

| 字段 | 类型 | 说明 |
|---|---|---|
| success | bool | 固定 `true` |
| message | string | `Server is running` |
| http_stats | object | 中间件采集的 HTTP 统计信息 |

```json
{
  "success": true,
  "message": "Server is running",
  "http_stats": {}
}
```

## 错误码

| HTTP 状态 | 场景 | 说明 |
|---|---|---|
| 401 / 403 | 鉴权失败 | 非管理员访问被 AdminAuth 拦截 |
| 503 | 数据库连接失败 | `success=false`，`message=数据库连接失败` |
