# 获取系统状态

> `GET /api/status`

- **鉴权**：无（公开接口）
- **用途**：返回前端运行所需的全部系统配置（登录方式开关、OAuth 配置、品牌信息、功能开关、面板模块、Passkey、自定义 OAuth 提供商等）。前端启动时拉取一次。

## 请求

无参数。

## 响应

标准信封 `{success, message, data}`。`data` 为对象，主要字段分组如下：

### 基础 / 版本

| 字段 | 类型 | 说明 |
|---|---|---|
| version | string | 后端版本号 |
| start_time | int | 进程启动时间戳 |
| setup | bool | 系统是否已初始化 |

### 登录与注册开关

| 字段 | 类型 | 说明 |
|---|---|---|
| register_enabled | bool | 是否允许注册 |
| password_login_enabled | bool | 密码登录开关 |
| password_register_enabled | bool | 密码注册开关 |
| email_verification | bool | 邮箱验证开关 |
| turnstile_check | bool | Turnstile 校验开关 |
| turnstile_site_key | string | Turnstile site key |
| wechat_login | bool | 微信登录开关 |
| wechat_qrcode | string | 微信二维码图片 URL |

### OAuth 提供商

| 字段 | 类型 | 说明 |
|---|---|---|
| github_oauth / github_client_id | bool / string | GitHub OAuth |
| discord_oauth / discord_client_id | bool / string | Discord OAuth |
| linuxdo_oauth / linuxdo_client_id / linuxdo_minimum_trust_level | bool / string / int | LinuxDO OAuth |
| telegram_oauth / telegram_bot_name | bool / string | Telegram OAuth |
| oidc_enabled / oidc_client_id / oidc_authorization_endpoint / oidc_display_name | - | OIDC 配置 |
| custom_oauth_providers | array | 已启用的自定义 OAuth 提供商列表（`{id,name,slug,icon,client_id,authorization_endpoint,scopes}`），仅当存在时返回 |

### 品牌 / 展示

| 字段 | 类型 | 说明 |
|---|---|---|
| system_name | string | 系统名称 |
| logo | string | Logo URL |
| footer_html | string | 页脚 HTML |
| theme | string | 固定 `default` |
| server_address | string | 服务端地址 |
| quota_per_unit | float | 单位额度 |
| display_in_currency | bool | 是否以货币展示（兼容旧前端） |
| quota_display_type | string | 额度展示类型 |
| custom_currency_symbol / custom_currency_exchange_rate | string / float | 自定义货币符号/汇率 |
| usd_exchange_rate / price / stripe_unit_price | float | 美元汇率 / 价格 / Stripe 单价 |

### 功能开关

| 字段 | 类型 | 说明 |
|---|---|---|
| enable_batch_update | bool | 批量更新 |
| enable_drawing | bool | 绘图 |
| enable_task | bool | 任务 |
| enable_data_export | bool | 数据导出 |
| data_export_default_time | string | 数据导出默认时间 |
| default_collapse_sidebar | bool | 默认折叠侧边栏 |
| mj_notify_enabled | bool | MJ 通知 |
| chats | string | 对话配置 |
| demo_site_enabled | bool | 演示站点模式 |
| self_use_mode_enabled | bool | 自用模式 |
| default_use_auto_group | bool | 默认使用自动分组 |
| checkin_enabled | bool | 签到开关 |

### 面板启用开关与模块配置

| 字段 | 类型 | 说明 |
|---|---|---|
| api_info_enabled / uptime_kuma_enabled / announcements_enabled / faq_enabled | bool | 面板各区块启用开关 |
| api_info / announcements / faq | object/array | 对应区块内容（仅当对应 `*_enabled=true` 时返回） |
| HeaderNavModules / SidebarModulesAdmin | - | 模块管理配置 |
| docs_link | string | 文档链接 |

### Passkey

| 字段 | 类型 | 说明 |
|---|---|---|
| passkey_login | bool | Passkey 登录开关 |
| passkey_display_name / passkey_rp_id / passkey_origins / passkey_allow_insecure / passkey_user_verification / passkey_attachment | - | Passkey 详细配置 |

### 法务

| 字段 | 类型 | 说明 |
|---|---|---|
| user_agreement_enabled | bool | 是否启用用户协议 |
| privacy_policy_enabled | bool | 是否启用隐私政策 |

## 错误码

无。始终返回 HTTP 200。
