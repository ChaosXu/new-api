# 全局异步任务
> `GET /api/task/`
- **鉴权**：AdminAuth（管理员）
- **用途**：分页查询全局异步任务。

## 请求
Query 参数：
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| platform | string | 平台 |
| task_id | string | 任务 ID |
| status | string | 状态 |
| action | string | 动作 |
| channel_id | string | 渠道 ID |
| start_timestamp / end_timestamp | int64 | 时间范围 |
| p / page_size | int | 分页 |

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data | PageQuery | 分页对象，含 items（TaskDto[]）与 total |

示例：
```json
{ "success": true, "message": "", "data": { "total": 0, "items": [] } }
```

## 错误码
无
