# 获取权限目录
> `GET /api/authz/catalog`
- **鉴权**：AdminAuth（管理员）
- **用途**：获取系统权限目录，含全部资源与角色定义，供权限管理界面使用。

## 请求
无

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data.resources | object[] | 资源目录（authz.Catalog） |
| data.roles | object[] | 角色目录（authz.Roles） |

示例：
```json
{
  "success": true,
  "message": "",
  "data": { "resources": [], "roles": [] }
}
```

## 错误码
无
