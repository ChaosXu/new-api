# About API

> 路由前缀：`/api`，公开接口（无鉴权）。返回后台配置的静态文案 / HTML 内容字符串。

## 端点清单

| 文件 | 方法 | 路径 | 用途 |
|---|---|---|---|
| [获取关于内容](./获取关于内容.md) | GET | /api/about | 返回「关于」页面内容 |
| [获取首页内容](./获取首页内容.md) | GET | /api/home_page_content | 返回自定义首页内容 |
| [获取用户协议](./获取用户协议.md) | GET | /api/user-agreement | 返回用户协议内容 |
| [获取隐私政策](./获取隐私政策.md) | GET | /api/privacy-policy | 返回隐私政策内容 |
