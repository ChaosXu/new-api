# 订阅产品选项
> `GET /api/option/waffo-pancake/subscription-product-options`
- **鉴权**：RootAuth（超级管理员）
- **用途**：从 Pancake 网关拉取可用作订阅套餐的产品列表。需先完成网关绑定。

## 请求
无

## 响应
非标准信封：
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| message | string | `success` / `error` |
| data | array | 产品选项列表；失败时为错误描述 |

示例：
```json
{ "message": "success", "data": [] }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | Waffo Pancake 未完成配置，请先在支付设置中完成网关绑定 | 未配对 |
| 200 | 拉取产品列表失败 | 网关调用失败 |
