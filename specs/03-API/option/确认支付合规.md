# 确认支付合规
> `POST /api/option/payment_compliance`
- **鉴权**：RootAuth（超级管理员，且必须为 dashboard 会话登录，不允许 API access token）
- **用途**：确认支付合规声明，记录确认人、IP、时间与条款版本。

## 请求
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| confirmed | bool | 是 | 必须为 true |

示例：
```json
{ "confirmed": true }
```

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data.confirmed | bool | 固定 true |
| data.terms_version | string | 当前合规条款版本 |
| data.confirmed_at | int64 | 确认时间戳（秒） |
| data.confirmed_by | int | 确认人用户 ID |

示例：
```json
{
  "success": true,
  "message": "",
  "data": { "confirmed": true, "terms_version": "1.0", "confirmed_at": 1722739200, "confirmed_by": 1 }
}
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 403 | This operation requires dashboard session authentication... | 使用 access token 调用被拒绝 |
| 200 | 参数错误 | 请求体解析失败 |
| 200 | 请确认合规声明 | confirmed 非 true |
