# 清除渠道亲和缓存
> `DELETE /api/option/channel_affinity_cache`
- **鉴权**：RootAuth（超级管理员）
- **用途**：清除渠道亲和缓存：按规则名清除，或 `all=true` 清空全部。

## 请求
Query 参数（二选一）：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| all | string | 否 | 为 `true` 时清空全部 |
| rule_name | string | 否 | 指定规则名清除；当 all 非 true 时必填 |

示例：`DELETE /api/option/channel_affinity_cache?rule_name=my_rule`

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data.deleted | int | 删除条数 |

示例：
```json
{ "success": true, "message": "", "data": { "deleted": 12 } }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 400 | 缺少参数：rule_name，或使用 all=true 清空全部 | 未传 all 且 rule_name 为空 |
| 400 | （service 错误） | ClearChannelAffinityCacheByRuleName 失败 |
