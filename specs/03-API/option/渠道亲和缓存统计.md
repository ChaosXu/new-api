# 渠道亲和缓存统计
> `GET /api/option/channel_affinity_cache`
- **鉴权**：RootAuth（超级管理员）
- **用途**：获取渠道亲和（channel affinity）缓存的统计信息。

## 请求
无

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data | object | 渠道亲和缓存统计（由 service.GetChannelAffinityCacheStats 返回） |

示例：
```json
{ "success": true, "message": "", "data": {} }
```

## 错误码
无
