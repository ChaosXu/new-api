# 创建订阅产品
> `POST /api/option/waffo-pancake/subscription-product`
- **鉴权**：RootAuth（超级管理员）
- **用途**：在 Pancake 网关创建订阅套餐产品。需先完成网关绑定。

## 请求
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| name | string | 是 | 套餐名称 |
| amount | string | 是 | 套餐价格 |

示例：
```json
{ "name": "月度套餐", "amount": "9.99" }
```

## 响应
非标准信封：
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| message | string | `success` / `error` |
| data | object/string | 创建结果；失败时为错误描述 |

示例：
```json
{ "message": "success", "data": {} }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | 参数错误 | 请求体解析失败 |
| 200 | 套餐名称不能为空 | name 为空 |
| 200 | 套餐价格不能为空 | amount 为空 |
| 200 | Waffo Pancake 未完成配置，请先在支付设置中完成网关绑定 | 未配对 |
| 200 | 创建套餐产品失败 | 网关调用失败 |
