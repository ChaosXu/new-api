# 获取系统设置
> `GET /api/option/`
- **鉴权**：RootAuth（超级管理员）
- **用途**：获取全部系统设置项；自动过滤敏感项（以 Token/Secret/Key 等结尾的键）。

## 请求
无

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data | Option[] | 设置项数组；末尾追加合成的 `CompletionRatioMeta` |

Option：
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| key | string | 设置键 |
| value | string | 设置值（字符串化） |

示例：
```json
{
  "success": true,
  "message": "",
  "data": [ { "key": "ServerAddress", "value": "https://..." }, { "key": "CompletionRatioMeta", "value": "..." } ]
}
```

## 错误码
无
