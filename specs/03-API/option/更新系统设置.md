# 更新系统设置
> `PUT /api/option/`
- **鉴权**：RootAuth（超级管理员）
- **用途**：更新单个系统设置项。不同 key 走对应更新逻辑，返回各自的提示信息。

## 请求
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| key | string | 是 | 设置键 |
| value | any | 是 | 设置值 |

示例：
```json
{ "key": "ServerAddress", "value": "https://api.example.com" }
```

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| success | bool | 是否成功 |
| message | string | 处理结果提示（随 key 变化） |

示例：
```json
{ "success": true, "message": "设置成功" }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 400 | （参数错误） | 请求体解析失败 |
| 200 | 支付合规声明未确认（MsgPaymentComplianceRequired） | 修改支付相关 key 时未合规 |
| 200 | 合规确认字段不允许通过通用设置接口修改 | 试图修改 compliance 字段 |
