# 重置模型倍率
> `POST /api/option/rest_model_ratio`
- **鉴权**：RootAuth（超级管理员）
- **用途**：将 ModelRatio 设置重置为内置默认值（写库 + 内存）。

## 请求
无

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| success | bool | 是否成功 |
| message | string | 成功为「重置模型倍率成功」 |

示例：
```json
{ "success": true, "message": "重置模型倍率成功" }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | （错误信息） | 写库或内存更新失败 |
