# 重新生成备用码

> `POST /api/user/2fa/backup_codes`

- **鉴权**：`UserAuth`，附加 `DisableCache`
- **用途**：用 TOTP 验证码确认身份后重新生成一次性备用码，原子推进会话鉴权版本。

## 请求

Body（JSON）：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| code | string | 是 | 6 位 TOTP 验证码（仅接受 TOTP，不接受备用码） |
| flow_token | string | 否 | 流程令牌（结构体保留） |

```json
{ "code": "123456" }
```

## 响应

| 字段 | 类型 | 说明 |
|---|---|---|
| success | bool | `true` |
| message | string | `备用码重新生成成功` |
| data.access_token | string | 新访问令牌 |
| data.token_type | string | `Bearer` |
| data.access_expires_at | int64 | 过期时间（Unix 秒） |
| data.session | object | 当前会话视图 |
| data.backup_codes | string[] | 新的一次性备用码列表 |

```json
{
  "success": true,
  "message": "备用码重新生成成功",
  "data": {
    "access_token": "eyJ...",
    "token_type": "Bearer",
    "access_expires_at": 1700000000,
    "session": { "sid": "sess_abc", "current": true },
    "backup_codes": ["new1abcd", "new2efgh", "..."]
  }
}
```

## 错误码

| 场景 | message |
|---|---|
| 参数错误 | `参数错误` |
| 未启用 2FA | `用户未启用2FA` |
| 验证码格式错误 | 透传 `ValidateNumericCode` 错误 |
| 验证码错误 | `验证码或备用码错误，请重试` |
| 生成备用码失败 | `生成备用码失败` |
| 保存备用码失败 | `保存备用码失败` |
| 当前认证方式不支持安全验证 | 硬编码错误 |
