# 强制禁用用户 2FA

> `DELETE /api/user/:id/2fa`

- **鉴权**：`AdminAuth`（管理员）
- **用途**：管理员强制禁用指定用户的 2FA，同时吊销该用户所有会话。不可操作同级或更高权限用户。

## 请求

Path：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| id | int | 是 | 目标用户 ID |

## 响应

| 字段 | 类型 | 说明 |
|---|---|---|
| success | bool | `true` |
| message | string | `用户2FA已被强制禁用` |

```json
{ "success": true, "message": "用户2FA已被强制禁用" }
```

## 错误码

| 场景 | message |
|---|---|
| 用户 ID 格式错误 | `用户ID格式错误` |
| 无权操作同级/更高 | `无权操作同级或更高级用户的2FA设置` |
| 用户未启用 2FA | `用户未启用2FA` |
