# 删除指定会话

> `DELETE /api/user/sessions/:sid`

- **鉴权**：`UserAuth`（需浏览器登录会话）
- **用途**：吊销当前用户的指定登录会话。若吊销的是当前 Cookie 对应会话，会清除刷新 Cookie。

## 请求

Path：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| sid | string | 是 | 目标会话 ID |

## 响应

| 字段 | 类型 | 说明 |
|---|---|---|
| success | bool | `true` |
| message | string | 空 |
| data.revoked_sid | string | 被吊销的会话 ID |
| data.current | bool | 是否为当前会话 |

```json
{
  "success": true,
  "message": "",
  "data": { "revoked_sid": "sess_xyz", "current": false }
}
```

## 错误码

| 场景 | HTTP | code/message |
|---|---|---|
| 非浏览器会话 | 403 | `AUTH_SESSION_REQUIRED` |
| 未传 sid | 400 | `AUTH_SESSION_ID_REQUIRED` / `session id is required` |
| 会话不存在 | 404 | `AUTH_SESSION_NOT_FOUND` / `session not found` |
| 内部错误 | 500 | `AUTH_INTERNAL_ERROR` |
