# 吊销其他会话

> `POST /api/user/sessions/revoke-others`

- **鉴权**：`UserAuth`（需浏览器登录会话）
- **用途**：吊销当前用户除当前会话外的所有其他登录会话。

## 请求

无 Body。

## 响应

| 字段 | 类型 | 说明 |
|---|---|---|
| success | bool | `true` |
| message | string | 空 |
| data.revoked_count | int | 被吊销的会话数量 |

```json
{
  "success": true,
  "message": "",
  "data": { "revoked_count": 3 }
}
```

## 错误码

| 场景 | HTTP | code | message |
|---|---|---|---|
| 非浏览器会话 | 403 | `AUTH_SESSION_REQUIRED` | `a dashboard login session is required` |
| 内部错误 | 500 | `AUTH_INTERNAL_ERROR` | `Internal Server Error` |
