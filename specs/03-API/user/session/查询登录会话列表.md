# 查询登录会话列表

> `GET /api/user/sessions`

- **鉴权**：`UserAuth`（需浏览器登录会话；纯 PAT 不行——`requireBrowserSession` 要求会话身份）
- **用途**：列出当前用户所有活跃登录会话，标记当前会话。

## 请求

无参数。

## 响应

| 字段 | 类型 | 说明 |
|---|---|---|
| success | bool | `true` |
| message | string | 空 |
| data | array | 会话视图列表（`LoginSessionView`） |

每个会话视图字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| sid | string | 会话 ID |
| current | bool | 是否当前请求所在会话 |
| login_method | string | 登录方式（`password`/`2fa`/`passkey`/`oauth:*` 等） |
| ip | string | 登录 IP |
| user_agent | string | User-Agent |
| created_at | int64 | 创建时间（Unix 秒） |
| last_active_at | int64 | 最近活跃时间（Unix 秒） |
| expires_at | int64 | 过期时间（Unix 秒） |

```json
{
  "success": true,
  "message": "",
  "data": [
    {
      "sid": "sess_abc",
      "current": true,
      "login_method": "password",
      "ip": "1.2.3.4",
      "user_agent": "Mozilla/5.0",
      "created_at": 1699999000,
      "last_active_at": 1699999900,
      "expires_at": 1700603800
    }
  ]
}
```

## 错误码

| 场景 | HTTP | code | message |
|---|---|---|---|
| 非浏览器会话（PAT 调用） | 403 | `AUTH_SESSION_REQUIRED` | `a dashboard login session is required` |
| 内部错误 | 500 | `AUTH_INTERNAL_ERROR` | `Internal Server Error` |
