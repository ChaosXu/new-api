# 搜索用户
> `GET /api/user/search`
- **鉴权**：AdminAuth（管理员）
- **用途**：按关键字、分组、角色、状态搜索用户，支持排序。

## 请求
Query 参数：
| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| keyword | string | 否 | 用户名/显示名等关键字 |
| group | string | 否 | 用户分组 |
| role | string | 否 | 角色数字字符串 |
| status | string | 否 | 状态数字字符串 |
| p | int | 否 | 页码 |
| page_size | int | 否 | 每页条数，最大 100 |
| sort_by | string | 否 | 排序字段：`id` / `username` / `quota` / `group` / `created_at` / `last_login_at` |
| sort_order | string | 否 | `asc` / `desc` |

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| page | int | 当前页码 |
| page_size | int | 每页条数 |
| total | int | 总条数 |
| items | array | `model.User` 列表 |

示例：
```json
{
  "success": true,
  "message": "",
  "data": {
    "page": 1, "page_size": 10, "total": 3,
    "items": [ { "id": 2, "username": "alice", "role": 1, "status": 1 } ]
  }
}
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | （数据库错误信息） | 搜索失败 |
