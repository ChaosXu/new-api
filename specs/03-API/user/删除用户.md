# 删除用户
> `DELETE /api/user/:id`
- **鉴权**：AdminAuth（管理员）
- **用途**：硬删除指定用户（不可恢复），并记录审计日志。调用者角色必须高于目标用户。

## 请求
路径参数：
| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| id | int | 是 | 目标用户 ID |

## 响应
```json
{ "success": true, "message": "" }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | （错误信息） | id 格式非法或用户不存在 |
| 200 | 无权限操作更高等级用户（MsgUserNoPermissionHigherLevel） | 调用者角色 ≤ 目标角色 |
| 200 | （错误信息） | `HardDeleteUserById` 失败 |

实现说明：调用 `model.HardDeleteUserById(id)` 执行物理删除，并通过 `recordManageAuditFor` 记录 `user.delete` 审计。
