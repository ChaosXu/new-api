# 用户列表
> `GET /api/user/`
- **鉴权**：AdminAuth（管理员）
- **用途**：分页查询全平台用户列表，支持排序。

## 请求
Query 参数：
| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| p | int | 否 | 页码，默认 1（兼容 `p`） |
| page_size | int | 否 | 每页条数，默认 `ItemsPerPage`，最大 100（兼容 `ps`/`size`） |
| sort_by | string | 否 | 排序字段，可选：`id` / `username` / `quota` / `group` / `created_at` / `last_login_at`；非法默认 `id` |
| sort_order | string | 否 | `asc` / `desc`；非 asc 一律按 desc 处理 |

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| page | int | 当前页码 |
| page_size | int | 每页条数 |
| total | int | 总条数 |
| items | array | `model.User` 列表 |

示例：
```json
{
  "success": true,
  "message": "",
  "data": {
    "page": 1,
    "page_size": 10,
    "total": 50,
    "items": [
      {
        "id": 2, "username": "alice", "display_name": "Alice",
        "role": 1, "status": 1, "email": "alice@example.com",
        "quota": 500000, "used_quota": 100000, "group": "default"
      }
    ]
  }
}
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | （数据库错误信息） | 查询失败 |
