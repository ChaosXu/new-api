# 刷新登录态

> `POST /api/user/auth/refresh`

- **鉴权**：`UserAuth`（实际依赖刷新令牌 Cookie），叠加 `SessionCookieOriginGuard` + `CriticalRateLimit` + `DisableCache`
- **用途**：凭刷新令牌轮换出新的访问令牌与刷新令牌，续期当前登录会话，并返回最新用户信息。

## 请求

无请求体。凭证来自：

| 位置 | 字段 | 说明 |
|---|---|---|
| Cookie | `<RefreshCookieName>` | 刷新令牌（必需） |
| Header | `X-Auth-Session` | 可选；会话 SID，与刷新令牌绑定的 SID 做一致性校验 |

## 响应

| 字段 | 类型 | 说明 |
|---|---|---|
| success | bool | `true` |
| message | string | 空 |
| data.access_token | string | 新的访问令牌（Bearer） |
| data.token_type | string | 令牌类型，如 `Bearer` |
| data.access_expires_at | int64 | 新访问令牌过期时间（Unix 秒） |
| data.user | object | 当前用户信息 DTO（`buildSelfUserData`） |
| data.session | object | 当前登录会话视图（`LoginSessionView`） |

同时通过 `Set-Cookie` 下发轮换后的刷新令牌。

```json
{
  "success": true,
  "message": "",
  "data": {
    "access_token": "eyJhbGciOi...",
    "token_type": "Bearer",
    "access_expires_at": 1700000000,
    "user": {
      "id": 1,
      "username": "alice",
      "display_name": "Alice",
      "role": 1,
      "status": 1,
      "group": "default",
      "quota": 500000
    },
    "session": {
      "sid": "sess_abc123",
      "current": true,
      "login_method": "password",
      "ip": "1.2.3.4",
      "last_active_at": 1699999000,
      "expires_at": 1700603800
    }
  }
}
```

## 错误码

| 场景 | 说明 |
|---|---|
| 刷新令牌缺失/无效 | 返回 `ErrRefreshTokenInvalid`，并清除 Cookie |
| 会话已被吊销 | 返回 `ErrLoginSessionRevoked`，并清除 Cookie |
| 会话 SID 不匹配 | `X-Auth-Session` 与刷新令牌绑定的 SID 不一致时返回 `ErrLoginSessionMismatch` |

> 该端点对所有失败分支设置 `Cache-Control: no-store`，并通过 `writeAuthSessionError` 返回标准信封错误。
