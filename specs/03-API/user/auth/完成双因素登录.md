# 完成双因素登录

> `POST /api/user/login/2fa`

- **鉴权**：无（公开），经过 `CriticalRateLimit` + `DisableCache` + 请求体大小限制
- **用途**：在用户名密码登录返回 `require_2fa` 后，使用 TOTP 验证码或备用码 + 流程令牌完成登录。

## 请求

Body（JSON）：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| code | string | 是 | 6 位 TOTP 验证码或一次性备用码 |
| flow_token | string | 是 | 登录接口返回的 2FA 流程令牌（5 分钟有效） |

```json
{
  "code": "123456",
  "flow_token": "fl_abcdef"
}
```

## 响应

校验通过后等同普通登录成功响应（见「用户名密码登录」成功分支），返回访问令牌、会话、用户信息，并下发刷新令牌 Cookie。

| 字段 | 类型 | 说明 |
|---|---|---|
| success | bool | `true` |
| message | string | 空 |
| data.access_token | string | 访问令牌 |
| data.token_type | string | `Bearer` |
| data.access_expires_at | int64 | 过期时间（Unix 秒） |
| data.session | object | 当前会话视图 |
| data.user | object | 用户信息 DTO |

```json
{
  "success": true,
  "message": "",
  "data": {
    "access_token": "eyJhbGciOi...",
    "token_type": "Bearer",
    "access_expires_at": 1700000000,
    "session": { "sid": "sess_abc123", "current": true, "login_method": "2fa" },
    "user": { "id": 1, "username": "alice", "role": 1 }
  }
}
```

## 错误码

| 场景 | message |
|---|---|
| 参数错误 | `参数错误` |
| 流程令牌过期/无效 | `会话已过期，请重新登录` |
| 用户不存在 | `用户不存在` |
| 用户被禁用 | `用户已被禁用` |
| 流程版本不匹配（凭据已变更） | `会话已过期，请重新登录` |
| 用户未启用 2FA | `用户未启用2FA` |
| 验证码或备用码错误 | `验证码或备用码错误，请重试` |
