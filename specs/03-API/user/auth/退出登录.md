# 退出登录

> `POST /api/user/auth/logout`

- **鉴权**：`UserAuth`，叠加 `SessionCookieOriginGuard` + `CriticalRateLimit` + `DisableCache`
- **用途**：吊销当前登录会话（含访问令牌与会话记录），并清除刷新令牌 Cookie，完成登出。

## 请求

无请求体。客户端需携带以下凭证之一：

| 位置 | 字段 | 说明 |
|---|---|---|
| Header | `Authorization` | 访问令牌，`Bearer <access_token>` |
| Header | `X-Auth-Session` | 可选；指定要登出的会话 SID，用于与 Cookie/令牌中的 SID 做一致性校验 |
| Cookie | `<RefreshCookieName>` | 可选；刷新令牌，若其 SID 与访问令牌 SID 一致则一并吊销并清除 |

## 响应

当通过访问令牌成功登出时：

| 字段 | 类型 | 说明 |
|---|---|---|
| success | bool | `true` |
| message | string | 空 |
| data.revoked_sid | string | 被吊销的会话 SID |
| data.cookie_cleared | bool | 是否清除并吊销了刷新令牌 Cookie |

```json
{
  "success": true,
  "message": "",
  "data": {
    "revoked_sid": "sess_abc123",
    "cookie_cleared": true
  }
}
```

当未携带访问令牌（仅 Cookie 存在或已缺失）时，仍返回成功并清除 Cookie：

```json
{ "success": true, "message": "" }
```

## 错误码

| 场景 | 说明 |
|---|---|
| 会话不匹配 | `X-Auth-Auth-Session` 与令牌/Cookie 中的 SID 不一致时返回 `ErrLoginSessionMismatch` |
| 会话吊销失败 | 数据库或会话存储错误（如 `ErrLoginSessionRevoked`） |

> 该端点对所有失败分支设置 `Cache-Control: no-store`，并通过 `writeAuthSessionError` 返回标准信封错误。
