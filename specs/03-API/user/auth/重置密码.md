# 重置密码

> `POST /api/user/reset`

- **鉴权**：无（公开），经过 `CriticalRateLimit` + 请求体大小限制
- **用途**：凭邮件收到的重置令牌重置账户密码，服务端生成新密码并返回。

## 请求

Body（JSON）：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| email | string | 是 | 注册邮箱（自动规范化大小写） |
| token | string | 是 | 邮件中的密码重置令牌 |

```json
{
  "email": "alice@example.com",
  "token": "reset-token-from-email"
}
```

## 响应

| 字段 | 类型 | 说明 |
|---|---|---|
| success | bool | `true` |
| message | string | 空 |
| data | string | 服务端生成的 12 位新密码（明文，仅此一次返回） |

```json
{
  "success": true,
  "message": "",
  "data": "aB3dE9fK2mNp"
}
```

成功后服务端会删除该重置令牌（一次性）。新密码长度 12，由 `GenerateVerificationCode(12)` 生成。

## 错误码

| 场景 | message |
|---|---|
| 参数为空 / 解析失败 | `msg_invalid_params` |
| 令牌无效或已过期 | `msg_user_password_reset_link_invalid` |
| 邮箱不存在 / 不唯一 | `msg_user_password_reset_link_invalid` |
