# 用户名密码登录

> `POST /api/user/login`

- **鉴权**：无（公开），经过 `CriticalRateLimit` + `TurnstileCheck` + 请求体大小限制（`AnonymousRequestBodyLimit`）
- **用途**：用户名密码登录；若账户启用 2FA，则返回 `require_2fa` 流程令牌，需调用「完成双因素登录」收尾。

## 请求

Body（JSON）：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| username | string | 是 | 用户名 |
| password | string | 是 | 密码 |

```json
{
  "username": "alice",
  "password": "p@ssw0rd"
}
```

## 响应

### 未启用 2FA（直接登录成功）

| 字段 | 类型 | 说明 |
|---|---|---|
| success | bool | `true` |
| message | string | 空 |
| data.access_token | string | 访问令牌（Bearer） |
| data.token_type | string | 令牌类型，如 `Bearer` |
| data.access_expires_at | int64 | 访问令牌过期时间（Unix 秒） |
| data.session | object | 当前登录会话视图（见 `LoginSessionView`） |
| data.user | object | 当前用户信息 DTO（`buildSelfUserData`，含 `id`/`username`/`display_name`/`role`/`status`/`email`/`group`/`quota`/`used_quota`/`request_count`/`aff_code`/`aff_quota`/`permissions` 等） |

同时通过 `Set-Cookie` 下发刷新令牌（`RefreshCookieName`）。

```json
{
  "success": true,
  "message": "",
  "data": {
    "access_token": "eyJhbGciOi...",
    "token_type": "Bearer",
    "access_expires_at": 1700000000,
    "session": {
      "sid": "sess_abc123",
      "current": true,
      "login_method": "password",
      "ip": "1.2.3.4",
      "user_agent": "Mozilla/5.0",
      "created_at": 1699999000,
      "last_active_at": 1699999000,
      "expires_at": 1700603800
    },
    "user": {
      "id": 1,
      "username": "alice",
      "display_name": "Alice",
      "role": 1,
      "status": 1,
      "email": "alice@example.com",
      "group": "default",
      "quota": 500000,
      "used_quota": 0,
      "request_count": 0,
      "permissions": { "sidebar_settings": true, "admin_permissions": [] }
    }
  }
}
```

### 已启用 2FA（需二次验证）

| 字段 | 类型 | 说明 |
|---|---|---|
| success | bool | `true` |
| message | string | 提示需要 2FA |
| data.require_2fa | bool | `true` |
| data.flow_token | string | 2FA 流程令牌，5 分钟有效 |
| data.expires_at | int64 | 流程令牌过期时间（Unix 秒） |

```json
{
  "success": true,
  "message": "需要双因素验证",
  "data": {
    "require_2fa": true,
    "flow_token": "fl_abcdef",
    "expires_at": 1699998300
  }
}
```

## 错误码

| 场景 | message |
|---|---|
| 密码登录被禁用 | `msg_user_password_login_disabled` |
| 参数为空 / 解析失败 | `msg_invalid_params` |
| 数据库错误 | `msg_database_error` |
| 用户名或密码错误 | `msg_user_username_or_password_error` |
| 用户被禁用 | `msg_auth_user_banned` |
