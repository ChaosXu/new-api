# 用户名密码注册

> `POST /api/user/register`

- **鉴权**：无（公开），经过 `CriticalRateLimit` + 请求体大小限制 + `TurnstileCheck`
- **用途**：以用户名 + 密码注册新账户。需系统开启注册（`RegisterEnabled` 且 `PasswordRegisterEnabled`）。

## 请求

Body（JSON，对应 `model.User`）：

| 字段 | 类型 | 必填 | 校验 | 说明 |
|---|---|---|---|---|
| username | string | 是 | `max=20`，trim 后非空 | 用户名 |
| password | string | 是 | `min=8,max=20` | 密码 |
| email | string | 视配置 | `max=50` | 邮箱；开启邮箱验证时必填 |
| verification_code | string | 视配置 | - | 邮箱验证码；开启邮箱验证时必填 |
| aff_code | string | 否 | - | 邀请人邀请码 |

```json
{
  "username": "alice",
  "password": "p@ssw0rd1",
  "email": "alice@example.com",
  "verification_code": "123456",
  "aff_code": "abcd"
}
```

## 响应

| 字段 | 类型 | 说明 |
|---|---|---|
| success | bool | `true` |
| message | string | 空 |

```json
{
  "success": true,
  "message": ""
}
```

注册流程说明：服务端只取白名单字段（`Username`/`Password`/`DisplayName`=用户名/`InviterId`/`Role`=普通用户，开启邮箱验证时附 `Email`）；若 `GenerateDefaultToken` 开启，会为新用户创建一条默认令牌。

## 错误码

| 场景 | message |
|---|---|
| 注册被禁用 | `msg_user_register_disabled` |
| 密码注册被禁用 | `msg_user_password_register_disabled` |
| 参数错误 / 用户名空 | `msg_invalid_params` |
| 字段校验失败 | `msg_user_input_invalid`（带 `Error`） |
| 需要邮箱验证 | `msg_user_email_verification_required` |
| 验证码错误 | `msg_user_verification_code_error` |
| 邮箱已被占用 | `msg_user_email_already_taken` |
| 用户已存在 | `msg_user_exists` |
| 注册失败 | `msg_user_register_failed` |
| 默认令牌生成失败 | `msg_user_default_token_failed` / `msg_create_default_token_err` |
