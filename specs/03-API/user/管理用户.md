# 管理用户
> `POST /api/user/manage`
- **鉴权**：AdminAuth（管理员）
- **用途**：对指定用户执行管理操作（禁用/启用/删除/提升/降级/调整额度）。

## 请求
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| id | int | 是 | 目标用户 ID |
| action | string | 是 | 操作：`disable` / `enable` / `delete` / `promote` / `demote` / `add_quota` |
| value | int | 条件必填 | `action=add_quota` 时为额度数量 |
| mode | string | 条件必填 | `action=add_quota` 时为 `add` / `subtract` / `override` |

action 语义：
- `disable`：将状态置为禁用（不可禁用 root）
- `enable`：将状态置为启用
- `delete`：软删除用户（不可删 root），并清理该用户令牌缓存
- `promote`：提升为管理员（仅 root 可操作；不可对已是管理员操作）
- `demote`：降级为普通用户（不可降 root；清理管理员授权、吊销会话）
- `add_quota`：按 `mode` 增加/减少/覆盖额度

示例（加额度）：
```json
{ "id": 2, "action": "add_quota", "value": 100000, "mode": "add" }
```

## 响应
通用成功（非 add_quota 分支返回变更后的 `{role, status}`）：
```json
{ "success": true, "message": "", "data": { "role": 1, "status": 1 } }
```
add_quota 分支：
```json
{ "success": true, "message": "" }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | 参数错误（MsgInvalidParams） | 解析失败 / action 未知 / mode 未知 |
| 200 | 用户不存在（MsgUserNotExists） | id 无对应用户 |
| 200 | 无权限操作更高等级用户（MsgUserNoPermissionHigherLevel） | 调用者角色不高于目标 |
| 200 | 无法禁用超级管理员（MsgUserCannotDisableRootUser） | disable 目标为 root |
| 200 | 无法删除超级管理员（MsgUserCannotDeleteRootUser） | delete 目标为 root |
| 200 | 无法降级超级管理员（MsgUserCannotDemoteRootUser） | demote 目标为 root |
| 200 | 管理员无法执行此操作（MsgUserAdminCannotPromote） | 非 root 执行 promote |
| 200 | 该用户已经是管理员（MsgUserAlreadyAdmin） | promote 目标已是管理员 |
| 200 | 该用户已经是普通用户（MsgUserAlreadyCommon） | demote 目标已是普通用户 |
| 200 | 额度变动不能为零（MsgUserQuotaChangeZero） | add/subtract value <= 0 |
| 200 | （错误信息） | 数据库更新失败等 |
