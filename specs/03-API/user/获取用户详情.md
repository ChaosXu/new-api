# 获取用户详情
> `GET /api/user/:id`
- **鉴权**：AdminAuth（管理员）
- **用途**：按 ID 获取单个用户详情（含管理员权限 capabilities）。

## 请求
路径参数：
| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| id | int | 是 | 用户 ID |

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data | object | `model.User` 对象，附加 `admin_permissions` 字段（authz.Capabilities 计算结果） |

示例：
```json
{
  "success": true,
  "message": "",
  "data": {
    "id": 2, "username": "alice", "display_name": "Alice",
    "role": 1, "status": 1, "email": "alice@example.com",
    "quota": 500000, "group": "default",
    "admin_permissions": {}
  }
}
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | （错误信息） | id 格式非法或用户不存在 |
| 200 | 无权限操作同级用户（i18n MsgUserNoPermissionSameLevel） | 调用者角色不高于目标用户角色 |
