# 执行签到

> `POST /api/user/checkin`

- **鉴权**：`UserAuth`，附加 `TurnstileCheck`
- **用途**：当前用户执行每日签到，随机奖励额度（区间由 `min_quota`~`max_quota` 决定）。

## 请求

无 Body。

> 路由层附加 `TurnstileCheck`，开启人机验证时需带 Turnstile token。

## 响应

| 字段 | 类型 | 说明 |
|---|---|---|
| success | bool | `true` |
| message | string | `签到成功` |
| data.quota_awarded | int | 本次奖励额度 |
| data.checkin_date | string | 签到日期（`YYYY-MM-DD`） |

```json
{
  "success": true,
  "message": "签到成功",
  "data": { "quota_awarded": 500, "checkin_date": "2026-08-04" }
}
```

## 错误码

| 场景 | message |
|---|---|
| 签到功能未启用 | `签到功能未启用` |
| 今日已签到 / 其他签到错误 | 透传 `UserCheckin` 错误信息 |
