# 查询签到状态

> `GET /api/user/checkin`

- **鉴权**：`UserAuth`
- **用途**：查询签到功能配置及当前用户指定月份的签到统计与历史。

## 请求

Query：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| month | string | 否 | 月份，格式 `YYYY-MM`，默认当前月 |

## 响应

| 字段 | 类型 | 说明 |
|---|---|---|
| success | bool | `true` |
| data.enabled | bool | 签到功能是否启用 |
| data.min_quota | int | 单次最小奖励额度 |
| data.max_quota | int | 单次最大奖励额度 |
| data.stats | object | 用户当月签到统计（由 `GetUserCheckinStats` 返回） |

```json
{
  "success": true,
  "data": {
    "enabled": true,
    "min_quota": 100,
    "max_quota": 1000,
    "stats": { "checked_days": 3, "total_awarded": 1500, "last_checkin_date": "2026-08-03" }
  }
}
```

## 错误码

| 场景 | message |
|---|---|
| 签到功能未启用 | `签到功能未启用` |
| 统计查询失败 | 透传错误信息 |
