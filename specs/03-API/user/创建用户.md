# 创建用户
> `POST /api/user/`
- **鉴权**：AdminAuth（管理员）
- **用途**：管理员手动创建用户（可指定角色，但不能创建等于或高于自身角色的用户）。

## 请求
请求体为 `model.User`：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| username | string | 是 | 用户名（trim 后非空，校验 max=20） |
| password | string | 是 | 密码（校验 min=8,max=20） |
| display_name | string | 否 | 显示名，空则取 username（max=20） |
| role | int | 否 | 角色，须小于调用者角色 |
| admin_permissions | map[string]map[string]bool | 否 | 管理员细粒度权限（仅 root 可设置） |

示例：
```json
{ "username": "newuser", "password": "12345678", "display_name": "New", "role": 1 }
```

## 响应
```json
{ "success": true, "message": "" }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | 参数错误（MsgInvalidParams） | 请求体解析失败 / username 空 / password 空 |
| 200 | 用户输入无效：<错误>（MsgUserInputInvalid） | 字段校验失败 |
| 200 | 无法创建比自己等级更高的用户（MsgUserCannotCreateHigherLevel） | role ≥ 调用者角色 |
| 200 | （错误信息） | 插入失败、权限 reload 失败等 |
