# 易支付下单
> `POST /api/user/pay`
- **鉴权**：UserAuth + CriticalRateLimit
- **用途**：通过易支付（epay）拉起支付，创建充值订单并返回跳转 URL 与表单参数。

## 请求
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| amount | int64 | 是 | 充值数量（USD/CNY 为金额单位；TOKENS 模式为 tokens） |
| payment_method | string | 是 | 支付方式标识，需在 `ContainsPayMethod` 列表中 |

示例：
```json
{ "amount": 10, "payment_method": "alipay" }
```

## 响应
非标准信封 `{message, data, url}`（注意无 `success` 字段）：
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| message | string | `"success"` 表示成功，`"error"` 表示失败 |
| data | object | 易支付返回的表单参数（键值对，用于提交跳转） |
| url | string | 易支付跳转网关 URL |

示例：
```json
{
  "message": "success",
  "data": { "out_trade_no": "USR2NOabc123", "type": "alipay" },
  "url": "https://pay.example.com/submit.php"
}
```

## 错误码
所有错误均 HTTP 200，`message:"error"`，`data` 为中文错误描述：
| data 文案 | 触发条件 |
| --- | --- |
| 参数错误 | 请求体解析失败 |
| 充值数量不能小于 N | amount 低于最低充值 |
| 获取用户分组失败 | 无法读取用户分组 |
| 充值金额过低 | 计算后支付金额 < 0.01 |
| 支付方式不存在 | payment_method 不在配置列表 |
| 当前管理员未配置支付信息 | epay client 未初始化 |
| 拉起支付失败 | epay Purchase 调用失败 |
| 创建订单失败 | 本地订单插入失败 |
