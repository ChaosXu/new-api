# 更新个人资料

> `PUT /api/user/self`

- **鉴权**：`UserAuth`，附加 `CriticalRateLimit` + `DisableCache`
- **用途**：根据请求体键名分三种模式更新：① 侧边栏模块；② 语言偏好；③ 用户名/显示名/密码。修改密码需会话二次确认并返回新令牌。

## 请求

Body（JSON，`map[string]interface{}`）。按出现的键路由到不同分支：

### 模式 ① 更新侧边栏模块

| 字段 | 类型 | 说明 |
|---|---|---|
| sidebar_modules | string | 侧边栏模块配置（JSON 字符串） |

```json
{ "sidebar_modules": "{\"console\":{...}}" }
```

### 模式 ② 更新语言偏好

| 字段 | 类型 | 说明 |
|---|---|---|
| language | string | 语言代码，如 `zh`、`en` |

```json
{ "language": "zh" }
```

### 模式 ③ 更新资料 / 改密码

| 字段 | 类型 | 校验 | 说明 |
|---|---|---|---|
| username | string | `max=20` | 新用户名 |
| display_name | string | `max=20` | 显示名 |
| password | string | `min=8,max=20` | 新密码（留空表示不改） |
| original_password | string | - | 改密码时必填，校验原密码 |

```json
{
  "username": "alice2",
  "display_name": "Alice Renamed",
  "password": "newp@ssw0rd",
  "original_password": "oldp@ssw0rd"
}
```

## 响应

模式 ①② 与模式 ③（不改密码）：返回通用成功。

```json
{ "success": true, "message": "" }
```

模式 ③ 修改密码成功后，会推进会话鉴权版本并返回新令牌：

| 字段 | 类型 | 说明 |
|---|---|---|
| success | bool | `true` |
| message | string | 空 |
| data.access_token | string | 新访问令牌 |
| data.token_type | string | `Bearer` |
| data.access_expires_at | int64 | 过期时间（Unix 秒） |
| data.session | object | 当前会话视图 |

```json
{
  "success": true,
  "message": "",
  "data": {
    "access_token": "eyJ...",
    "token_type": "Bearer",
    "access_expires_at": 1700000000,
    "session": { "sid": "sess_abc", "current": true }
  }
}
```

## 错误码

| 场景 | message |
|---|---|
| 参数解析失败 | `msg_invalid_params` |
| 设置更新失败 | `msg_update_failed` / `msg_update_success`（成功） |
| 字段校验失败 | `msg_invalid_input` |
| 用户未设置密码（无法改密） | `msg_user_password_unset` |
| 原密码错误 | `msg_user_original_password_error` |
| 当前认证方式不支持安全验证（改密） | 硬编码错误 |
