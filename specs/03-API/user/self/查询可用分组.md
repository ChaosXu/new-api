# 查询可用分组

> `GET /api/user/self/groups` 与 `GET /api/user/groups`

- **鉴权**：`UserAuth`（`/self/groups`）；`/api/user/groups` 同样挂在 `selfRoute` 下需登录（两条路由均调用 `controller.GetUserGroups`）
- **用途**：返回当前用户可用分组及其倍率与描述。

## 请求

无参数（两条路由等价）。

## 响应

`data` 为对象，key 为分组名，value 含：

| 字段 | 类型 | 说明 |
|---|---|---|
| ratio | string/number | 该分组倍率；`auto` 分组为字符串 `"自动"` |
| desc | string | 分组描述 |

```json
{
  "success": true,
  "message": "",
  "data": {
    "default": { "ratio": 1, "desc": "默认分组" },
    "vip": { "ratio": 0.5, "desc": "VIP 分组" },
    "auto": { "ratio": "自动", "desc": "自动分组" }
  }
}
```

## 错误码

无业务错误码。
