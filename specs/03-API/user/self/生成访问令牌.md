# 生成访问令牌

> `GET /api/user/token`

- **鉴权**：`UserAuth`，附加 `DisableCache`
- **用途**：为当前用户生成（或覆盖）个人访问令牌（PAT），用于脚本/API 调用鉴权。

## 请求

无参数。

## 响应

| 字段 | 类型 | 说明 |
|---|---|---|
| success | bool | `true` |
| message | string | 空 |
| data | string | 新生成的访问令牌（长度 29~32 的随机 key） |

```json
{
  "success": true,
  "message": "",
  "data": "sk-xxxxxxxxxxxxxxxxxxxxxxxxxx"
}
```

生成后会覆盖用户已有 PAT，并落库唯一性校验。

## 错误码

| 场景 | message |
|---|---|
| 生成失败 | `msg_generate_failed` |
| 令牌重复（碰撞） | `msg_uuid_duplicate` |
