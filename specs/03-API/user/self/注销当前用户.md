# 注销当前用户

> `DELETE /api/user/self`

- **鉴权**：`UserAuth`
- **用途**：当前用户注销自己的账户（软删除）。超级管理员不可自我注销。

## 请求

无参数。

## 响应

| 字段 | 类型 | 说明 |
|---|---|---|
| success | bool | `true` |
| message | string | 空 |

```json
{ "success": true, "message": "" }
```

## 错误码

| 场景 | message |
|---|---|
| 超级管理员尝试自删 | `msg_user_cannot_delete_root_user` |
| 数据库错误 | 透传错误信息 |
