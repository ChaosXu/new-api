# 查询邀请码

> `GET /api/user/aff`

- **鉴权**：`UserAuth`
- **用途**：获取当前用户的邀请码；若不存在则生成一个 4 位随机码并落库。

## 请求

无参数。

## 响应

| 字段 | 类型 | 说明 |
|---|---|---|
| success | bool | `true` |
| message | string | 空 |
| data | string | 邀请码（4 位随机字符串） |

```json
{
  "success": true,
  "message": "",
  "data": "abcd"
}
```

## 错误码

| 场景 | message |
|---|---|
| 用户不存在 | 透传错误 |
| 落库失败 | 返回 `success:false` + 错误信息 |
