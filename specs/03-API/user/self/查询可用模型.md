# 查询可用模型

> `GET /api/user/models`

- **鉴权**：`UserAuth`
- **用途**：查询当前用户可用模型列表，可按分组过滤；支持 `auto` 自动分组展开。

## 请求

Query：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| group | string | 否 | 指定分组名；空表示所有可用分组；`auto` 展开自动分组 |

## 响应

| 字段 | 类型 | 说明 |
|---|---|---|
| success | bool | `true` |
| message | string | 空 |
| data | array | 可用模型 ID 列表 |

```json
{
  "success": true,
  "message": "",
  "data": ["gpt-4", "gpt-3.5-turbo", "claude-3-opus"]
}
```

## 错误码

无业务错误码。
