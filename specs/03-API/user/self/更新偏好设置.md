# 更新偏好设置

> `PUT /api/user/setting`

- **鉴权**：`UserAuth`
- **用途**：更新用户偏好（额度预警通知、webhook、Bark、Gotify、上游模型更新通知等）。请求体对应 `UpdateUserSettingRequest`。

## 请求

Body（JSON）：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| notify_type | string | 是 | 通知类型：`email` / `webhook` / `bark` / `gotify` |
| quota_warning_threshold | float | 是 | 预警阈值，须 > 0 |
| webhook_url | string | 视类型 | `notify_type=webhook` 时必填，合法 URL |
| webhook_secret | string | 否 | webhook 签名密钥 |
| notification_email | string | 视类型 | `notify_type=email` 时的通知邮箱（含 `@`） |
| bark_url | string | 视类型 | `notify_type=bark` 时必填，`http(s)://` URL |
| gotify_url | string | 视类型 | `notify_type=gotify` 时必填，`http(s)://` URL |
| gotify_token | string | 视类型 | `notify_type=gotify` 时必填 |
| gotify_priority | int | 否 | Gotify 优先级 0-10，超出范围默认 5 |
| upstream_model_update_notify_enabled | bool | 否 | 仅管理员生效，是否通知上游模型更新 |
| accept_unset_model_ratio_model | bool | 否 | 是否接受未设倍率的模型 |
| record_ip_log | bool | 否 | 是否记录 IP 日志 |

```json
{
  "notify_type": "email",
  "quota_warning_threshold": 1000,
  "notification_email": "alice@example.com",
  "accept_unset_model_ratio_model": false,
  "record_ip_log": false
}
```

## 响应

| 字段 | 类型 | 说明 |
|---|---|---|
| success | bool | `true` |
| message | string | `msg_setting_saved` |

```json
{ "success": true, "message": "设置已保存" }
```

## 错误码

| 场景 | message |
|---|---|
| 参数错误 | `msg_invalid_params` |
| 通知类型非法 | `msg_setting_invalid_type` |
| 阈值需大于 0 | `msg_quota_threshold_gt_zero` |
| webhook 地址空 / 非法 | `msg_setting_webhook_empty` / `msg_setting_webhook_invalid` |
| 邮箱非法 | `msg_setting_email_invalid` |
| Bark 地址空 / 非法 / 非 http(s) | `msg_setting_bark_url_empty` / `msg_setting_bark_url_invalid` / `msg_setting_url_must_http` |
| Gotify 地址/Token 空 / 非法 | `msg_setting_gotify_url_empty` / `msg_setting_gotify_token_empty` / `msg_setting_gotify_url_invalid` |
| 更新失败 | `msg_update_failed` |
