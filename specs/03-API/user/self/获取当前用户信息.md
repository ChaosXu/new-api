# 获取当前用户信息

> `GET /api/user/self`

- **鉴权**：`UserAuth`（已登录用户）
- **用途**：返回当前登录用户的个人资料 DTO（`buildSelfUserData`），含权限矩阵。

## 请求

无参数。

## 响应

| 字段 | 类型 | 说明 |
|---|---|---|
| success | bool | `true` |
| message | string | 空 |
| data.id | int | 用户 ID |
| data.username | string | 用户名 |
| data.display_name | string | 显示名 |
| data.role | int | 角色（1 普通用户 / 10 管理员 / 100 超管） |
| data.status | int | 状态（1 启用 / 2 禁用） |
| data.email | string | 邮箱 |
| data.github_id / discord_id / oidc_id / wechat_id / telegram_id / linux_do_id | string | 第三方绑定 ID |
| data.group | string | 当前分组 |
| data.quota | int | 剩余额度 |
| data.used_quota | int | 已用额度 |
| data.request_count | int | 请求总数 |
| data.aff_code | string | 邀请码 |
| data.aff_count / aff_quota / aff_history_quota | int | 邀请相关统计 |
| data.inviter_id | int | 邀请人 ID |
| data.stripe_customer | string | Stripe 客户 ID |
| data.setting | string | 用户设置（原始 JSON 字符串） |
| data.sidebar_modules | object/string | 侧边栏模块配置 |
| data.permissions | object | 权限矩阵（`sidebar_settings`、`sidebar_modules`、`admin_permissions`） |

## 错误码

无业务错误码；仅在用户不存在时返回数据库错误。
