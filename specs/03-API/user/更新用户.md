# 更新用户
> `PUT /api/user/`
- **鉴权**：AdminAuth（管理员）
- **用途**：更新指定用户信息。不允许通过此接口修改角色（保留原角色）。

## 请求
请求体为 `model.User`，必须含 `id`：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| id | int | 是 | 目标用户 ID |
| username | string | 是 | 用户名（trim 后非空，校验 max=20） |
| password | string | 否 | 新密码（非空则更新密码，校验 min=8,max=20） |
| display_name | string | 否 | 显示名（max=20） |
| email | string | 否 | 邮箱 |
| group | string | 否 | 分组 |
| remark | string | 否 | 备注（max=255） |
| admin_permissions | map[string]map[string]bool | 否 | 管理员细粒度权限（仅 root） |

示例：
```json
{ "id": 2, "username": "alice", "display_name": "Alice2", "group": "vip" }
```

注意：若 `role` 既非 guest 又与原角色不同，直接报「参数错误」。最终以原角色为准。

## 响应
```json
{ "success": true, "message": "" }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | 参数错误（MsgInvalidParams） | 解析失败 / id=0 / username 空 / 角色被篡改 |
| 200 | 用户输入无效：<错误>（MsgUserInputInvalid） | 字段校验失败 |
| 200 | 无权限操作更高等级用户（MsgUserNoPermissionHigherLevel） | 调用者角色 ≤ 目标角色 |
| 200 | （错误信息） | 用户不存在、更新失败、策略 reload 失败等 |
