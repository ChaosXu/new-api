# 管理员补单
> `POST /api/user/topup/complete`
- **鉴权**：AdminAuth（管理员）
- **用途**：对一笔未完成的充值订单手动补单（发放额度）。

## 请求
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| trade_no | string | 是 | 充值订单号 |

示例：
```json
{ "trade_no": "USR2NOabc123" }
```

## 响应
```json
{ "success": true, "message": "", "data": null }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | 参数错误 | trade_no 为空或请求体解析失败 |
| 200 | 充值订单不存在 | 订单号无对应记录 |
| 200 | （其他错误信息） | 订单状态异常、补单失败等（由 ManualCompleteTopUp 返回） |

实现说明：调用 `model.ManualCompleteTopUp(tradeNo, clientIP)`，订单级互斥（LockOrder）防止并发补单。
