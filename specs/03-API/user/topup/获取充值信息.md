# 获取充值信息
> `GET /api/user/topup/info`
- **鉴权**：UserAuth（用户登录态）
- **用途**：获取充值页所需的全部配置信息（启用的支付渠道、支付方式、最低充值、折扣、Creem 产品等）。

## 请求
无

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| enable_online_topup | bool | 是否启用易支付（在线充值） |
| enable_stripe_topup | bool | 是否启用 Stripe |
| enable_creem_topup | bool | 是否启用 Creem |
| enable_waffo_topup | bool | 是否启用 Waffo |
| enable_waffo_pancake_topup | bool | 是否启用 Waffo Pancake |
| enable_redemption | bool | 是否启用兑换码（等于合规确认状态） |
| payment_compliance_confirmed | bool | 支付合规是否已确认 |
| payment_compliance_terms_version | string | 当前合规条款版本 |
| waffo_pay_methods | array\|null | Waffo 服务端支付方式列表（未启用时为 null） |
| creem_products | string | Creem 产品配置（JSON 字符串） |
| pay_methods | array | 支付方式列表，元素结构 `{name,type,color,min_topup}`，含动态追加的 stripe / waffo / waffo_pancake |
| min_topup | int | 易支付最低充值数量 |
| stripe_min_topup | int | Stripe 最低充值数量 |
| waffo_min_topup | int | Waffo 最低充值数量 |
| waffo_pancake_min_topup | int | Waffo Pancake 最低充值数量 |
| amount_options | array | 充值金额可选项 |
| discount | map | 按原始金额预设的折扣表（amount→折扣） |
| topup_link | string | 外部充值链接（common.TopUpLink） |
