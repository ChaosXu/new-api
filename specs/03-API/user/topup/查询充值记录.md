# 查询充值记录
> `GET /api/user/topup/self`
- **鉴权**：UserAuth（用户登录态）
- **用途**：分页查询当前用户的充值订单，支持关键字搜索。

## 请求
Query 参数：
| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| keyword | string | 否 | 按订单号模糊搜索 |
| p | int | 否 | 页码，默认 1 |
| page_size | int | 否 | 每页条数，默认 `ItemsPerPage`，最大 100（兼容 `ps`/`size`） |

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| page | int | 当前页码 |
| page_size | int | 每页条数 |
| total | int | 总条数 |
| items | array | `model.TopUp` 列表 |

TopUp 结构：
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | int | 订单 ID |
| user_id | int | 用户 ID |
| amount | int64 | 充值额度数量 |
| money | float64 | 支付金额 |
| trade_no | string | 订单号 |
| payment_method | string | 支付方式 |
| payment_provider | string | 支付网关 |
| create_time | int64 | 创建时间（秒） |
| complete_time | int64 | 完成时间（秒） |
| status | string | 订单状态 |

示例：
```json
{
  "success": true,
  "message": "",
  "data": {
    "page": 1,
    "page_size": 10,
    "total": 1,
    "items": [
      {
        "id": 1,
        "user_id": 2,
        "amount": 10,
        "money": 1.00,
        "trade_no": "USR2NOabc123",
        "payment_method": "alipay",
        "payment_provider": "epay",
        "create_time": 1700000000,
        "complete_time": 1700000100,
        "status": "success"
      }
    ]
  }
}
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | （数据库错误信息） | 查询/搜索失败时原样回传错误 |
