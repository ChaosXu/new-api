# 获取全部充值记录
> `GET /api/user/topup`
- **鉴权**：AdminAuth（管理员）
- **用途**：管理员分页查询全平台充值订单，支持关键字搜索。

## 请求
Query 参数：
| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| keyword | string | 否 | 按订单号模糊搜索 |
| p | int | 否 | 页码，默认 1 |
| page_size | int | 否 | 每页条数，默认 `ItemsPerPage`，最大 100 |

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| page | int | 当前页码 |
| page_size | int | 每页条数 |
| total | int | 总条数 |
| items | array | `model.TopUp` 列表（结构同「查询充值记录」） |

示例：
```json
{
  "success": true,
  "message": "",
  "data": {
    "page": 1,
    "page_size": 10,
    "total": 25,
    "items": [
      {
        "id": 1, "user_id": 2, "amount": 10, "money": 1.0,
        "trade_no": "USR2NOabc123", "payment_method": "alipay",
        "payment_provider": "epay", "create_time": 1700000000,
        "complete_time": 1700000100, "status": "success"
      }
    ]
  }
}
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | （数据库错误信息） | 查询/搜索失败时原样回传错误 |
