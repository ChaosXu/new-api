# 兑换码兑换
> `POST /api/user/topup`
- **鉴权**：UserAuth（用户登录态）+ CriticalRateLimit
- **用途**：使用兑换码为当前用户增加额度。

## 请求
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| key | string | 是 | 兑换码 |

示例：
```json
{ "key": "ABCD-1234-EFGH" }
```

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data | int | 本次兑换获得的额度数量 |

示例：
```json
{
  "success": true,
  "message": "",
  "data": 500000
}
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | 支付合规声明未确认（i18n: MsgPaymentComplianceRequired） | 管理员未确认支付合规 |
| 200 | 正在处理中，请稍后再试（MsgUserTopUpProcessing） | 同一用户并发兑换被 TryLock 拒绝 |
| 200 | 兑换失败（MsgRedeemFailed） | 兑换码无效/已用等（不向用户暴露细分原因） |
| 200 | （其他错误信息） | 请求解析失败等 |
