# 延长部署
> `POST /api/deployments/:id/extend`
- **鉴权**：AdminAuth（管理员）
- **用途**：延长指定部署的时长。

## 请求
路径参数：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| id | string | 是 | 部署 ID |

请求体：ionet.ExtendDurationRequest（按上游 io.net 规范，含延长时长等）。

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data | object | 延长后的部署信息（id、status、compute_minutes_served/remaining 等） |

示例：
```json
{ "success": true, "message": "", "data": { "id": "d-1", "status": "running" } }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | deployment id is required | id 为空 |
| 200 | （错误信息） | 请求体解析失败或上游调用失败 |
