# 搜索部署
> `GET /api/deployments/search`
- **鉴权**：AdminAuth（管理员）
- **用途**：按关键词与状态搜索部署（关键词按名称模糊匹配，内存过滤）。

## 请求
Query 参数：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| keyword | string | 否 | 名称关键词 |
| status | string | 否 | 状态筛选 |
| p / page_size | int | 否 | 分页 |

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data.page / data.page_size | int | 分页信息 |
| data.total | int | 过滤后总数 |
| data.items | object[] | 部署列表 |

示例：
```json
{ "success": true, "message": "", "data": { "page": 0, "page_size": 10, "total": 0, "items": [] } }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | （错误信息） | 未配置 API Key 或上游调用失败 |
