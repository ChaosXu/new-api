# 删除部署
> `DELETE /api/deployments/:id`
- **鉴权**：AdminAuth（管理员）
- **用途**：请求终止并删除指定部署。

## 请求
路径参数：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| id | string | 是 | 部署 ID |

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data.status | string | 状态 |
| data.deployment_id | string | 部署 ID |
| data.message | string | 提示信息 |

示例：
```json
{ "success": true, "message": "", "data": { "status": "...", "deployment_id": "d-1", "message": "Deployment termination requested successfully" } }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | deployment id is required | id 为空 |
| 200 | （错误信息） | 上游调用失败 |
