# 部署列表
> `GET /api/deployments/`
- **鉴权**：AdminAuth（管理员）
- **用途**：分页获取 io.net 部署列表，按创建时间倒序。

## 请求
Query 参数：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| status | string | 否 | 状态筛选 |
| p / page_size | int | 否 | 分页 |

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data.page / data.page_size | int | 分页信息 |
| data.total | int | 总数 |
| data.items | object[] | 部署列表（映射后） |
| data.status_counts | object | 各状态计数 |

示例：
```json
{ "success": true, "message": "", "data": { "page": 0, "page_size": 10, "total": 0, "items": [], "status_counts": {} } }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | （错误信息） | 未配置 API Key 或上游调用失败 |
