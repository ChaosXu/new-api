# 检查名称
> `GET /api/deployments/check-name`
- **鉴权**：AdminAuth（管理员）
- **用途**：检查部署名称是否可用。

## 请求
Query 参数：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| name | string | 是 | 待检查的名称 |

示例：`GET /api/deployments/check-name?name=my-cluster`

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data.available | bool | 是否可用 |
| data.name | string | 检查的名称 |

示例：
```json
{ "success": true, "message": "", "data": { "available": true, "name": "my-cluster" } }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | name parameter is required | name 为空 |
| 200 | （错误信息） | 上游调用失败 |
