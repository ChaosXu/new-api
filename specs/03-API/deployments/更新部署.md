# 更新部署
> `PUT /api/deployments/:id`
- **鉴权**：AdminAuth（管理员）
- **用途**：更新指定部署的配置。

## 请求
路径参数：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| id | string | 是 | 部署 ID |

请求体：ionet.UpdateDeploymentRequest（按上游 io.net 规范）。

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data.status | string | 状态 |
| data.deployment_id | string | 部署 ID |

示例：
```json
{ "success": true, "message": "", "data": { "status": "...", "deployment_id": "d-1" } }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | deployment id is required | id 为空 |
| 200 | （错误信息） | 请求体解析失败或上游调用失败 |
