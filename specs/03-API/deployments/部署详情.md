# 部署详情
> `GET /api/deployments/:id`
- **鉴权**：AdminAuth（管理员）
- **用途**：获取指定部署的详情。

## 请求
路径参数：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| id | string | 是 | 部署 ID |

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data | object | 部署详情（id、status、total_gpus、total_containers、hardware_name、brand_name、compute_minutes_served/remaining、locations、container_config 等） |

示例：
```json
{ "success": true, "message": "", "data": { "id": "d-1", "status": "running", "total_gpus": 1, "total_containers": 1 } }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | deployment id is required | id 为空 |
| 200 | （错误信息） | 未配置 API Key 或上游调用失败 |
