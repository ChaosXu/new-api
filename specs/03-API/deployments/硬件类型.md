# 硬件类型
> `GET /api/deployments/hardware-types`
- **鉴权**：AdminAuth（管理员）
- **用途**：获取 io.net 可用硬件类型列表。

## 请求
无

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data.hardware_types | object[] | 硬件类型列表 |
| data.total | int | 硬件类型总数 |
| data.total_available | int | 可用总量 |

示例：
```json
{ "success": true, "message": "", "data": { "hardware_types": [], "total": 0, "total_available": 0 } }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | （错误信息） | 未配置 API Key 或上游调用失败 |
