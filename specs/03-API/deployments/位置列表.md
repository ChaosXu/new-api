# 位置列表
> `GET /api/deployments/locations`
- **鉴权**：AdminAuth（管理员）
- **用途**：获取 io.net 可用部署位置列表。

## 请求
无

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data.locations | object[] | 位置列表 |
| data.total | int | 总数 |

示例：
```json
{ "success": true, "message": "", "data": { "locations": [], "total": 0 } }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | （错误信息） | 未配置 API Key 或上游调用失败 |
