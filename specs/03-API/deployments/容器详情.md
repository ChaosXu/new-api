# 容器详情
> `GET /api/deployments/:id/containers/:container_id`
- **鉴权**：AdminAuth（管理员）
- **用途**：获取指定部署下某容器的详情。

## 请求
路径参数：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| id | string | 是 | 部署 ID |
| container_id | string | 是 | 容器 ID |

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data | object | 容器详情（含事件、状态、硬件等） |

示例：
```json
{ "success": true, "message": "", "data": {} }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | deployment id is required | 部署 id 为空 |
| 200 | container id is required | 容器 id 为空 |
| 200 | container details not found | 容器详情不存在 |
| 200 | （错误信息） | 上游调用失败 |
