# 部署设置
> `GET /api/deployments/settings`
- **鉴权**：AdminAuth（管理员）
- **用途**：获取模型部署（io.net）的配置状态。

## 请求
无

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data.provider | string | 供应商（`io.net`） |
| data.enabled | bool | 是否启用 |
| data.configured | bool | 是否已配置 API Key |
| data.can_connect | bool | enabled && configured |

示例：
```json
{ "success": true, "message": "", "data": { "provider": "io.net", "enabled": true, "configured": true, "can_connect": true } }
```

## 错误码
无
