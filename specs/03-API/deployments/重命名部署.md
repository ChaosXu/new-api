# 重命名部署
> `PUT /api/deployments/:id/name`
- **鉴权**：AdminAuth（管理员）
- **用途**：修改部署名称（先校验名称可用性）。

## 请求
路径参数：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| id | string | 是 | 部署 ID |

请求体：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| name | string | 是 | 新名称（须可用） |

示例：
```json
{ "name": "new-name" }
```

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data.status | string | 状态 |
| data.message | string | 提示 |
| data.id | string | 部署 ID |
| data.name | string | 新名称 |

示例：
```json
{ "success": true, "message": "", "data": { "status": "ok", "message": "", "id": "d-1", "name": "new-name" } }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | deployment id is required | id 为空 |
| 200 | deployment name cannot be empty | name 为空 |
| 200 | deployment name is not available, please choose a different name | 名称已被占用 |
| 200 | （错误信息） | 上游调用失败 |
