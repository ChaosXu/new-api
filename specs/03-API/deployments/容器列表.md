# 容器列表
> `GET /api/deployments/:id/containers`
- **鉴权**：AdminAuth（管理员）
- **用途**：列出指定部署的全部容器（workers）。

## 请求
路径参数：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| id | string | 是 | 部署 ID |

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data.total | int | 容器总数 |
| data.containers | object[] | 容器数组（container_id、device_id、status、hardware、brand_name、created_at、uptime_percent、gpus_per_container、public_url、events） |

示例：
```json
{ "success": true, "message": "", "data": { "total": 0, "containers": [] } }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | deployment id is required | id 为空 |
| 200 | （错误信息） | 上游调用失败 |
