# 部署日志
> `GET /api/deployments/:id/logs`
- **鉴权**：AdminAuth（管理员）
- **用途**：获取指定部署某容器的日志。

## 请求
路径参数：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| id | string | 是 | 部署 ID |

Query 参数：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| container_id | string | 是 | 容器 ID |
| level | string | 否 | 日志级别 |
| stream | string | 否 | 流类型 |
| cursor | string | 否 | 分页游标 |
| limit | int | 否 | 条数，默认 100，最大 1000 |
| follow | string | 否 | `true` 时持续跟踪 |
| start_time / end_time | string(RFC3339) | 否 | 时间范围 |

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data | object | 上游返回的原始日志（raw） |

示例：
```json
{ "success": true, "message": "", "data": {} }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | deployment id is required | id 为空 |
| 200 | container_id parameter is required | 缺少 container_id |
| 200 | （错误信息） | 上游调用失败 |
