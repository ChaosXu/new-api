# 价格估算
> `POST /api/deployments/price-estimation`
- **鉴权**：AdminAuth（管理员）
- **用途**：估算部署价格。

## 请求
ionet.PriceEstimationRequest（按上游 io.net 规范，含硬件、GPU 数量、时长等）。

示例：
```json
{ "hardware_id": "rtx-4090", "gpu_count": 1, "duration_hours": 24 }
```

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data | object | 上游返回的价格估算结果 |

示例：
```json
{ "success": true, "message": "", "data": {} }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | （错误信息） | 请求体解析失败或上游调用失败 |
