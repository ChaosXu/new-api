# 创建部署
> `POST /api/deployments/`
- **鉴权**：AdminAuth（管理员）
- **用途**：在 io.net 创建一个新部署。

## 请求
ionet.DeploymentRequest（按上游 io.net 规范）：含硬件、GPU 数量、镜像、命令等字段。

示例：
```json
{ "name": "my-cluster", "hardware_id": "rtx-4090", "gpu_count": 1 }
```

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data.deployment_id | string | 新部署 ID |
| data.status | string | 状态 |
| data.message | string | 提示信息 |

示例：
```json
{ "success": true, "message": "", "data": { "deployment_id": "d-2", "status": "...", "message": "Deployment created successfully" } }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | （错误信息） | 请求体解析失败或上游调用失败 |
