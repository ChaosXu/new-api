# 可用副本
> `GET /api/deployments/available-replicas`
- **鉴权**：AdminAuth（管理员）
- **用途**：按硬件与 GPU 数量查询可用副本。

## 请求
Query 参数：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| hardware_id | int | 是 | 硬件 ID（须 >0） |
| gpu_count | int | 否 | GPU 数量，默认 1 |

示例：`GET /api/deployments/available-replicas?hardware_id=10&gpu_count=2`

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data | object | 可用副本信息（由上游返回） |

示例：
```json
{ "success": true, "message": "", "data": {} }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | hardware_id parameter is required | 缺少 hardware_id |
| 200 | invalid hardware_id parameter | hardware_id 非法 |
| 200 | （错误信息） | 上游调用失败 |
