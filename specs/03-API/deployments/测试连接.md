# 测试连接
> `POST /api/deployments/settings/test-connection`
- **鉴权**：AdminAuth（管理员）
- **用途**：测试 io.net API Key 连通性（请求体提供 key 或使用已保存 key）。

## 请求
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| api_key | string | 否 | 待测试的 API Key；为空则用已保存 key |

示例：
```json
{ "api_key": "iona-xxx" }
```

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data.hardware_count | int | 硬件类型数 |
| data.total_available | int | 可用总量 |

示例：
```json
{ "success": true, "message": "", "data": { "hardware_count": 50, "total_available": 1000 } }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | invalid request payload | 请求体格式错误 |
| 200 | api_key is required | 未提供且无已保存 key |
| 200 | （上游错误信息 / failed to validate api key） | API Key 校验失败 |
