# 删除无效兑换码
> `DELETE /api/redemption/invalid`
- **鉴权**：AdminAuth（管理员）
- **用途**：删除所有未使用且已失效的兑换码。

## 请求
无

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data | int | 删除行数 |

示例：
```json
{ "success": true, "message": "", "data": 12 }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | （错误信息） | 删除失败 |
