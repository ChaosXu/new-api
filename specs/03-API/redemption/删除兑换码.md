# 删除兑换码
> `DELETE /api/redemption/:id`
- **鉴权**：AdminAuth（管理员）
- **用途**：删除指定兑换码。

## 请求
路径参数：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| id | int | 是 | 兑换码 ID |

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data | null | 删除成功 |

示例：
```json
{ "success": true, "message": "", "data": null }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | （错误信息） | id 解析失败或删除失败 |
