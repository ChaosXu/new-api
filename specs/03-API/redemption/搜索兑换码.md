# 搜索兑换码
> `GET /api/redemption/search`
- **鉴权**：AdminAuth（管理员）
- **用途**：按关键词和状态搜索兑换码。

## 请求
Query 参数：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| keyword | string | 否 | 关键词（名称/Key） |
| status | string | 否 | 状态筛选 |

另含分页参数（p、page_size）。

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data | PageQuery | 分页对象，含 items 与 total |

示例：
```json
{ "success": true, "message": "", "data": { "items": [] } }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | （错误信息） | 搜索失败 |
