# 兑换码列表
> `GET /api/redemption/`
- **鉴权**：AdminAuth（管理员）
- **用途**：分页获取全部兑换码。

## 请求
Query 参数（分页）：p、page_size。

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data | PageQuery | 分页对象，含 items（Redemption[]）与 total |

示例：
```json
{ "success": true, "message": "", "data": { "total": 1, "items": [ { "id": 1, "name": "n", "key": "...", "quota": 500000, "status": 1 } ] } }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | （错误信息） | 查询失败 |
