# 获取兑换码
> `GET /api/redemption/:id`
- **鉴权**：AdminAuth（管理员）
- **用途**：获取指定兑换码详情。

## 请求
路径参数：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| id | int | 是 | 兑换码 ID |

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data | Redemption | 兑换码详情（id、name、key、quota、status、expired_time 等） |

示例：
```json
{ "success": true, "message": "", "data": { "id": 1, "name": "n", "key": "...", "quota": 500000, "status": 1 } }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | （错误信息） | id 解析失败或兑换码不存在 |
