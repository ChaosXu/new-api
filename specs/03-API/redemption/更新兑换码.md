# 更新兑换码
> `PUT /api/redemption/`
- **鉴权**：AdminAuth（管理员）
- **用途**：更新兑换码；支持 `status_only` 仅更新状态。

## 请求
Query 参数：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| status_only | string | 否 | 非空时仅更新 status |

请求体：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| id | int | 是 | 兑换码 ID |
| status | int | status_only 时必填 | 状态 |
| name | string | 否 | 名称（非 status_only 时） |
| quota | int | 否 | 额度 |
| expired_time | int64 | 否 | 过期时间戳 |

示例（仅改状态）：
```json
{ "id": 1, "status": 2 }
```

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data | Redemption | 更新后的兑换码 |

示例：
```json
{ "success": true, "message": "", "data": { "id": 1, "status": 2 } }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | （错误信息） | 解析失败或兑换码不存在 |
| 200 | （过期时间校验消息） | 非 status_only 时 expired_time 非法 |
