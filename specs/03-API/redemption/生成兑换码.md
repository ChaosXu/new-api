# 生成兑换码
> `POST /api/redemption/`
- **鉴权**：AdminAuth（管理员）
- **用途**：批量生成兑换码。需管理员已确认支付合规。

## 请求
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| name | string | 是 | 兑换码名称（1-20 字符） |
| count | int | 是 | 生成数量（1-100） |
| quota | int | 是 | 单张额度 |
| expired_time | int64 | 否 | 过期时间戳（0 或 -1 表示不过期） |

示例：
```json
{ "name": "活动码", "count": 5, "quota": 500000, "expired_time": -1 }
```

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data | string[] | 生成的兑换码 Key 列表 |

示例：
```json
{ "success": true, "message": "", "data": ["uuid1", "uuid2", "uuid3", "uuid4", "uuid5"] }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | 支付合规声明未确认（MsgPaymentComplianceRequired） | 管理员未确认支付合规 |
| 200 | （i18n: MsgRedemptionNameLength） | 名称长度非法 |
| 200 | （i18n: MsgRedemptionCountPositive / MsgRedemptionCountMax） | count 非法 |
| 200 | （过期时间校验失败） | expired_time 校验未通过 |
| 200 | （i18n: MsgRedemptionCreateFailed） | 写入失败，data 携带已生成 keys |
