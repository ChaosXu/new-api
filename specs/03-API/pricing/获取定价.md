# 获取定价

> `GET /api/pricing`

- **鉴权**：HeaderNavModuleAuth("pricing")（顶栏「pricing」模块访问鉴权；已登录用户的额度信息会影响结果）
- **用途**：返回面向用户过滤后的模型定价表、分组倍率、可用分组、供应商列表与支持的端点映射。响应结构非标准信封。

## 请求

无参数。若调用方携带有效登录态，将按其用户分组计算个性化 `group_ratio` 与 `usable_group`。

## 响应

> 注意：此端点**不使用** `{success, message, data}` 标准信封，顶层直接为业务字段。

| 字段 | 类型 | 说明 |
|---|---|---|
| success | bool | 固定 `true` |
| data | array | 模型定价列表（已按当前用户可用分组过滤，见下表） |
| vendors | array | 供应商列表（`{id,name,description,icon}`） |
| group_ratio | object | 分组倍率映射（已按当前用户分组与可用分组裁剪） |
| usable_group | object | 当前用户可用分组映射（`{分组名: 分组名}`） |
| supported_endpoint | object | 模型 → 支持端点信息的映射 |
| auto_groups | - | 当前用户的自动分组配置 |
| pricing_version | string | 定价版本哈希，固定 `a42d372ccf0b5dd13ecf71203521f9d2` |

### `data` 元素（Pricing）

| 字段 | 类型 | 说明 |
|---|---|---|
| model_name | string | 模型名 |
| description | string | 描述（可省略） |
| icon | string | 图标（可省略） |
| tags | string | 标签（可省略） |
| vendor_id | int | 供应商 ID（可省略） |
| quota_type | int | 计费类型 |
| model_ratio | float | 模型倍率 |
| model_price | float | 按次计费价格 |
| owner_by | string | 归属 |
| completion_ratio | float | 补全倍率 |
| cache_ratio | float\* | 缓存倍率（可省略） |
| create_cache_ratio | float\* | 创建缓存倍率（可省略） |
| image_ratio | float\* | 图像倍率（可省略） |
| audio_ratio | float\* | 音频倍率（可省略） |
| audio_completion_ratio | float\* | 音频补全倍率（可省略） |
| enable_groups | array | 启用分组列表（包含 `all` 则对所有分组可用） |
| supported_endpoint_types | array | 支持的端点类型 |
| billing_mode | string | 计费模式（可省略） |
| billing_expr | string | 计费表达式（可省略） |
| pricing_version | string | 定价版本（可省略） |

```json
{
  "success": true,
  "data": [
    {
      "model_name": "gpt-4o",
      "quota_type": 0,
      "model_ratio": 2.5,
      "model_price": 0,
      "owner_by": "openai",
      "completion_ratio": 4,
      "enable_groups": ["all"],
      "supported_endpoint_types": ["chat"]
    }
  ],
  "vendors": [
    { "id": 1, "name": "OpenAI" }
  ],
  "group_ratio": { "default": 1, "vip": 0.8 },
  "usable_group": { "default": "default", "vip": "vip" },
  "supported_endpoint": { "gpt-4o": { "type": "chat" } },
  "auto_groups": {},
  "pricing_version": "a42d372ccf0b5dd13ecf71203521f9d2"
}
```

## 错误码

无业务错误返回。模块鉴权失败由 `HeaderNavModuleAuth` 中间件处理（通常返回 403）。
