# 渠道亲和缓存统计
> `GET /api/log/channel_affinity_usage_cache`
- **鉴权**：AdminAuth（管理员）
- **用途**：查询渠道亲和用量缓存统计，按规则名与 Key 指纹过滤。

## 请求
Query 参数：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| rule_name | string | 是 | 规则名 |
| key_fp | string | 是 | Key 指纹 |
| using_group | string | 否 | 使用分组 |

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data | object | 渠道亲和用量缓存统计 |

示例：
```json
{ "success": true, "message": "", "data": {} }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 400 | missing param: rule_name | 未传 rule_name |
| 400 | missing param: key_fp | 未传 key_fp |
