# 用户日志统计
> `GET /api/log/self/stat`
- **鉴权**：UserAuth（用户登录态）
- **用途**：按条件统计当前用户日志的额度、RPM、TPM。

## 请求
Query 参数：type、start_timestamp、end_timestamp、token_name、model_name、channel、group。

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data.quota | int | 总额度消耗 |
| data.rpm | int | 每分钟请求数 |
| data.tpm | int | 每分钟 token 数 |

示例：
```json
{ "success": true, "message": "", "data": { "quota": 50000, "rpm": 0, "tpm": 0 } }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | （错误信息） | 统计失败 |
