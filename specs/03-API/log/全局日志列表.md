# 全局日志列表
> `GET /api/log/`
- **鉴权**：AdminAuth（管理员）
- **用途**：分页查询全局日志，支持多条件过滤。

## 请求
Query 参数：
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| type | int | 日志类型 |
| start_timestamp / end_timestamp | int64 | 时间范围（秒） |
| username | string | 用户名 |
| token_name | string | 令牌名 |
| model_name | string | 模型名 |
| channel | int | 渠道 ID |
| group | string | 分组 |
| request_id | string | 请求 ID |
| upstream_request_id | string | 上游请求 ID |
| p / page_size | int | 分页 |

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data | PageQuery | 分页对象，含 items 与 total |

示例：
```json
{ "success": true, "message": "", "data": { "total": 0, "items": [] } }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | （错误信息） | 查询失败 |
