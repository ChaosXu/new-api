# 用户日志
> `GET /api/log/self`
- **鉴权**：UserAuth（用户登录态）
- **用途**：分页查询当前用户的日志。

## 请求
Query 参数：type、start_timestamp、end_timestamp、token_name、model_name、group、request_id、upstream_request_id、p、page_size。

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data | PageQuery | 分页对象，含 items 与 total |

示例：
```json
{ "success": true, "message": "", "data": { "total": 0, "items": [] } }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | （错误信息） | 查询失败 |
