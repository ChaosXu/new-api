# 日志统计
> `GET /api/log/stat`
- **鉴权**：AdminAuth（管理员）
- **用途**：按条件统计全局日志的额度、RPM、TPM。

## 请求
Query 参数：type、start_timestamp、end_timestamp、token_name、username、model_name、channel、group。

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data.quota | int | 总额度消耗 |
| data.rpm | int | 每分钟请求数 |
| data.tpm | int | 每分钟 token 数 |

示例：
```json
{ "success": true, "message": "", "data": { "quota": 500000, "rpm": 0, "tpm": 0 } }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | （错误信息） | 统计失败 |
