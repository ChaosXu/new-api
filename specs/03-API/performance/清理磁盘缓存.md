# 清理磁盘缓存
> `DELETE /api/performance/disk_cache`
- **鉴权**：RootAuth（超级管理员）
- **用途**：清理超过 10 分钟未活跃的磁盘缓存文件。

## 请求
无

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| success | bool | 是否成功 |
| message | string | 成功为「不活跃的磁盘缓存已清理」 |

示例：
```json
{ "success": true, "message": "不活跃的磁盘缓存已清理" }
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | （错误信息） | 清理过程发生错误 |
