# 性能统计
> `GET /api/performance/stats`
- **鉴权**：RootAuth（超级管理员）
- **用途**：获取服务性能统计，含磁盘缓存、内存、磁盘空间与监控配置。

## 请求
无

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data.cache_stats | DiskCacheStats | 磁盘缓存命中/未命中计数 |
| data.memory_stats | object | alloc、total_alloc、sys、num_gc、num_goroutine |
| data.disk_cache_info | object | path、exists、file_count、total_size |
| data.disk_space_info | object | 磁盘使用信息 |
| data.config | object | 磁盘缓存与监控阈值配置 |

示例：
```json
{
  "success": true,
  "data": {
    "cache_stats": {},
    "memory_stats": { "alloc": 12345678, "total_alloc": 0, "sys": 0, "num_gc": 0, "num_goroutine": 10 },
    "disk_cache_info": { "path": "/tmp/cache", "exists": true, "file_count": 0, "total_size": 0 },
    "disk_space_info": {},
    "config": { "disk_cache_enabled": true, "monitor_enabled": false }
  }
}
```

## 错误码
无
