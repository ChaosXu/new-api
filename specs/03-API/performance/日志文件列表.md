# 日志文件列表
> `GET /api/performance/logs`
- **鉴权**：RootAuth（超级管理员）
- **用途**：列出日志目录下的日志文件及其大小、修改时间。

## 请求
无

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| data.log_dir | string | 日志目录路径 |
| data.enabled | bool | 是否启用日志目录；未配置时为 false |
| data.file_count | int | 文件数量 |
| data.total_size | int64 | 总字节数 |
| data.oldest_time | string? | 最早修改时间（RFC3339） |
| data.newest_time | string? | 最新修改时间 |
| data.files | LogFileInfo[] | 文件数组（name、size、mod_time） |

示例：
```json
{
  "success": true,
  "message": "",
  "data": {
    "log_dir": "/var/log/new-api",
    "enabled": true,
    "file_count": 2,
    "total_size": 1024,
    "oldest_time": "2026-08-01T00:00:00Z",
    "newest_time": "2026-08-04T00:00:00Z",
    "files": [ { "name": "api.log", "size": 1024, "mod_time": "2026-08-04T00:00:00Z" } ]
  }
}
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | （错误信息） | 读取日志目录失败 |
