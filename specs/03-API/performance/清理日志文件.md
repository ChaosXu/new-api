# 清理日志文件
> `DELETE /api/performance/logs`
- **鉴权**：RootAuth（超级管理员）
- **用途**：按数量或天数清理过期日志文件（跳过当前活跃日志）。

## 请求
Query 参数：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| mode | string | 是 | `by_count`（保留最新 N 个）或 `by_days`（删除 N 天前） |
| value | int | 是 | 正整数，对应 mode 的数量/天数 |

示例：`DELETE /api/performance/logs?mode=by_days&value=7`

## 响应
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| success | bool | 是否全部成功 |
| message | string | 成功为空；部分失败时给出统计 |
| data.deleted_count | int | 已删除文件数 |
| data.freed_bytes | int64 | 释放字节数 |
| data.failed_files | string[] | 删除失败的文件名 |

示例：
```json
{
  "success": true,
  "message": "",
  "data": { "deleted_count": 5, "freed_bytes": 10240, "failed_files": [] }
}
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 200 | invalid mode, must be by_count or by_days | mode 非法 |
| 200 | invalid value, must be a positive integer | value 非正整数 |
| 200 | log directory not configured | 未配置日志目录 |
