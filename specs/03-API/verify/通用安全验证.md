# 通用安全验证

> `POST /api/verify`

- **鉴权**：UserAuth（登录用户）+ CriticalRateLimit（严格限流）+ DisableCache
- **用途**：对敏感操作进行二次安全验证。当前支持 2FA 方式，验证通过后签发一个一次性 `proof_token`，供后续敏感接口（如读取渠道密钥、注册/删除 Passkey）作为凭据。

## 请求

JSON Body：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| method | string | 是 | 验证方式，当前仅支持 `"2fa"`（Passkey 须走专门的 verify 流程） |
| code | string | 是 | 2FA 验证码（trim 后不能为空） |
| scope | string | 是 | 安全验证范围，取值见下表 |

`scope` 允许值：

| 值 | 含义 |
|---|---|
| `channel.key.read` | 读取渠道密钥 |
| `passkey.register` | 注册 Passkey |
| `passkey.delete` | 删除 Passkey |

```json
{
  "method": "2fa",
  "code": "123456",
  "scope": "channel.key.read"
}
```

## 响应

标准信封 `{success, message, data}`。`data`：

| 字段 | 类型 | 说明 |
|---|---|---|
| proof_token | string | 一次性安全验证凭据，供后续敏感接口使用 |
| expires_at | int | 凭据过期时间戳 |
| method | string | 验证方式（回显，如 `2fa`） |
| scope | string | 验证范围（回显） |

```json
{
  "success": true,
  "message": "验证成功",
  "data": {
    "proof_token": "<token>",
    "expires_at": 1700000600,
    "method": "2fa",
    "scope": "channel.key.read"
  }
}
```

## 错误码

错误通过 `common.ApiError` 返回（HTTP 200，`success=false`）：

| 场景 | message |
|---|---|
| 当前认证方式不支持安全验证 | HTTP 401，`当前认证方式不支持安全验证` |
| 请求体解析失败 | `参数错误: <err>` |
| method 非 `2fa` | `Passkey 验证必须使用 Passkey verify 流程` |
| scope 非法 | `不支持的安全验证范围` |
| code 为空 | `验证码不能为空` |
| 用户未启用 2FA | `用户未启用2FA` |
| 验证码错误 | `验证失败，请检查验证码` |
| 签发 proof 失败 | 透传底层错误 |
