# 查询令牌用量
> `GET /api/usage/token/`
- **鉴权**：TokenAuthReadOnly（令牌只读鉴权，Bearer sk-...）+ CriticalRateLimit + CORS
- **用途**：用令牌 Key 查询自身额度与用量信息。注意响应使用非标准信封（`code` 而非 `success`）。

## 请求
Header：
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| Authorization | string | 是 | `Bearer sk-xxxx` 形式的令牌 |

## 响应
非标准信封：
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| code | bool | 固定 true（非布尔成功标志位） |
| message | string | `ok` |
| data.object | string | 固定 `token_usage` |
| data.name | string | 令牌名称 |
| data.total_granted | int | 已授予总额度（剩余+已用） |
| data.total_used | int | 已用额度 |
| data.total_available | int | 剩余额度 |
| data.unlimited_quota | bool | 是否无限额度 |
| data.model_limits | object | 模型限制映射 |
| data.model_limits_enabled | bool | 是否启用模型限制 |
| data.expires_at | int64 | 过期时间戳（-1 视为 0） |

示例：
```json
{
  "code": true,
  "message": "ok",
  "data": {
    "object": "token_usage",
    "name": "my-token",
    "total_granted": 500000,
    "total_used": 100000,
    "total_available": 400000,
    "unlimited_quota": false,
    "model_limits": {},
    "model_limits_enabled": false,
    "expires_at": 0
  }
}
```

## 错误码
| HTTP | message | 说明 |
| --- | --- | --- |
| 401 | No Authorization header | 缺少鉴权头 |
| 401 | Invalid Bearer token | 鉴权头格式错误 |
| 200 | （i18n: MsgTokenGetInfoFailed） | 令牌不存在或查询失败 |
