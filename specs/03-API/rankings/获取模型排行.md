# 获取模型排行

> `GET /api/rankings`

- **鉴权**：HeaderNavModuleAuth("rankings")（顶栏「rankings」模块访问鉴权）
- **用途**：返回指定时间段的模型用量排行榜、厂商排行、涨跌幅榜单、模型与厂商份额历史时序。结果按周期缓存（5 分钟）。

## 请求

Query 参数：

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| period | string | 否 | 统计周期，可选 `today` / `week` / `month` / `year`，默认 `week`。其他值返回 400 |

## 响应

标准信封 `{success, data}`。`data` 为 `RankingsResponse`：

| 字段 | 类型 | 说明 |
|---|---|---|
| models | array | 模型排行榜（按用量降序） |
| vendors | array | 厂商排行榜 |
| top_movers | array | 涨幅榜 |
| top_droppers | array | 跌幅榜 |
| models_history | object | 模型用量历史时序 |
| vendor_share_history | object | 厂商份额历史时序 |

### `models` 元素（RankedModel）

| 字段 | 类型 | 说明 |
|---|---|---|
| rank | int | 当前排名 |
| previous_rank | int\* | 上期排名（首上榜时省略） |
| model_name | string | 模型名 |
| vendor | string | 厂商 |
| vendor_icon | string | 厂商图标（可省略） |
| category | string | 分类 |
| total_tokens | int | 总 token 数 |
| share | float | 份额 |
| growth_pct | float | 同比增长百分比 |

### `vendors` 元素（RankedVendor）

| 字段 | 类型 | 说明 |
|---|---|---|
| rank / vendor / vendor_icon / total_tokens / share / growth_pct | - | 同上 |
| models_count | int | 该厂商上榜模型数 |
| top_model | string | 该厂商用量最高的模型 |

### `top_movers` / `top_droppers` 元素（RankingMover）

| 字段 | 类型 | 说明 |
|---|---|---|
| model_name | string | 模型名 |
| vendor | string | 厂商 |
| vendor_icon | string | 厂商图标（可省略） |
| rank_delta | int | 排名变化（正为上升） |
| current_rank | int | 当前排名 |
| growth_pct | float | 增长百分比 |

### `models_history`（ModelHistorySeries）

| 字段 | 类型 | 说明 |
|---|---|---|
| points | array | 时序点（`{ts,label,model,vendor,tokens}`） |
| models | array | 涉及模型（`{name,vendor,total}`） |
| buckets | int | 桶数量 |

### `vendor_share_history`（VendorShareSeries）

| 字段 | 类型 | 说明 |
|---|---|---|
| points | array | 时序点（`{ts,label,vendor,share,tokens}`） |
| vendors | array | 涉及厂商（`{name,total,share}`） |
| buckets | int | 桶数量 |

```json
{
  "success": true,
  "data": {
    "models": [
      {
        "rank": 1,
        "previous_rank": 2,
        "model_name": "gpt-4o",
        "vendor": "OpenAI",
        "category": "chat",
        "total_tokens": 1200000000,
        "share": 0.35,
        "growth_pct": 12.5
      }
    ],
    "vendors": [],
    "top_movers": [],
    "top_droppers": [],
    "models_history": { "points": [], "models": [], "buckets": 10 },
    "vendor_share_history": { "points": [], "vendors": [], "buckets": 10 }
  }
}
```

## 错误码

| HTTP 状态 | 场景 | 说明 |
|---|---|---|
| 400 | period 取值非法 | `success=false`，`message=<err>`（如 `invalid period`） |
